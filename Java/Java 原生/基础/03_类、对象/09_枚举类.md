# 枚举类

## 什么是枚举类？

枚举是编译器已知所有实例的类。 它们用于创建只能具有几个可能值的类型。

可以像创建类一样创建枚举。

如下：

```java
public enum DayOfWeek {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}
```

所有枚举都隐式继承了 `java.lang.Enum`，并且不能有任何子类，但可以实现接口。

## 访问、计算和比较枚举

枚举的值可以用作常量。 为了检查一个枚举的两个实例是否相同，可以使用运算符。`==`

```java
DayOfWeek weekStart = DayOfWeek.MONDAY;

if (weekStart == DayOfWeek.MONDAY) {
    System.out.println("The week starts on Monday.");
}
```

枚举类同样也可以用于`switch`表达式，如下：

```java
DayOfWeek someDay = DayOfWeek.FRIDAY;

switch (someDay) {
    case MONDAY ->
        System.out.println("The week just started.");
    case TUESDAY, WEDNESDAY, THURSDAY ->
        System.out.println("We are somewhere in the middle of the week.");
    case FRIDAY ->
        System.out.println("The weekend is near.");
    case SATURDAY, SUNDAY ->
        System.out.println("Weekend");
    default ->
        throw new AssertionError("Should not happen");
}
```

使用 `switch` 表达式时， 编译器可以检查是否处理了 Enum 的所有值。 如果 switch 表达式中缺少任何可能的值，则会出现编译器错误。=> **这被叫做穷举性**。

## 向枚举添加成员

枚举也可以有自己的构造函数、方法、字段，如下：

```java
public enum DayOfWeek {
    MONDAY("MON"), TUESDAY("TUE"), WEDNESDAY("WED"), THURSDAY("THU"), FRIDAY("FRI"), SATURDAY("SAT"), SUNDAY("SUN");
    
    private final String abbreviation;
    
    public DayOfWeek(String abbreviation) {
        this.abbreviation = abbreviation;
    }
    
    public String getAbbreviation() {
        return abbreviation;
    }
}
```

虽然代码中没有显式定义构造函数，但枚举常量后面的参数表明这个枚举有一个带有字符串参数的构造函数。这个构造函数用于初始化枚举实例的属性。

这个枚举隐含了一个私有的字符串属性，用于存储缩写（如 "MON"），并且有一个对应的构造函数和访问方法。

示列：

```java
DayOfWeek today = DayOfWeek.MONDAY;
System.out.println(today); // 输出: MONDAY
System.out.println(today.getAbbreviation()); // 输出: MON
```

## 特殊方法

所有枚举都有一些隐式添加的方法，这是因为一开始就已经说了所有的枚举类，都隐式继承`java.lang.Enum`。

### 实例方法

`name()`返回当前枚举实例对应的常量名。

`ordinal()`返回当前枚举实例所对应的常量在枚举中的位置。

如下：

```java
System.out.println(DayOfWeek.MONDAY.name());    // prints "MONDAY"
System.out.println(DayOfWeek.MONDAY.ordinal()); // prints "0" because MONDAY is the first constant in the DayOfWeek enum
```

### 静态方法

之前已经讲述过，静态方法归整个类所有，所以想要调用，直接使用`类名.方法名`调用即可。

`values()`返回一个数组，里面包含整个枚举的常量。

`valueOf()`接受枚举中的一个参数，返回其特定实例。

如下：

```java
DayOfWeek[] days = DayOfWeek.values(); // all days of the week
DayOfWeek monday = DayOfWeek.valueOf("MONDAY");
```

### 补充

枚举实现接口 `Comparable`。 默认情况下，枚举根据其序号进行排序 即按照枚举 constant 的出现顺序。同时这也说明了，枚举实现`Comparable`，所以枚举中的常量可以进行对比、排序。

对比如下：

```java
public void compareDayOfWeek(DayOfWeek dayOfWeek){
    
    // compareTo()比较的是两变量之间的差值是多少
    int comparison = dayOfWeek.compareTo(DayOfWeek.WEDNESDAY);
    if (comparison < 0) {
        System.out.println("在星期三之前");
    } else if (comparison > 0){
        System.out.println("在星期三之后");
    } else {
        System.out.println("星期三");
    }
}

```

排序如下：

```java
List<DayOfWeek> days = new ArrayList<>(List.of(DayOfWeek.FRIDAY, DayOfWeek.TUESDAY, DayOfWeek.SATURDAY));
// 排序
Collections.sort(days);
```

## 枚举的抽象方法

**枚举是没有扩展的**，这也就意味着枚举是没有继承、实现接口等功能，**即枚举没有多态**。

但是枚举本身是可以有抽象方法的，如下：

```java
enum MyEnum {
    A() {
        @Override
        void doSomething() {
            System.out.println("a");
        }
    },
    B() {
        @Override
        void doSomething() {
            System.out.println("b");
        }
    };
    
    abstract void doSomething();
}
```

定义好了抽象方法后，**枚举中的所有常量都必须实现其方法**。

## 建议

1. **使用枚举表达固定不变的概念**：如一周的天数、HTTP 状态码、性别等。
2. **使用配置文件存储可变参数**：如服务器地址、超时时间等。
3. **避免交叉污染**：不要将枚举定义分散到配置文件中，保持代码与配置的分离。
4. **使用映射层**：如果需要从配置值关联到枚举，通过代码显式映射。
