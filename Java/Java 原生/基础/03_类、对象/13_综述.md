# 综述

在一最初的学习开始，介绍了Java语言的特性，可能读者并不太明白，Java语言的特性，经过类、对象的学习，多少对其有点理解了，下面会详细说哪里体现Java语言的特性。

主要是面向对象的三大特性：封装、继承、多态。

**封装**：

封装是指将数据（属性）和操作数据的方法绑定在一起，并通过访问控制修饰符（如`private`、`public`）隐藏内部实现细节。外部只能通过公开的方法（如`getter`和`setter`）访问和修改数据，从而保证数据的安全性和完整性。

```java
public class Person {
    // 私有属性（封装）
    private String name;
    private int age;

    // 公共访问方法
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

}
```

**继承、多态**后面会随着知识量的增加，自然会讲述到。
