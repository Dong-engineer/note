# 对象的比较

在 Java 中，`==`运算符比较的是两个对象的引用是否相同（即是否指向同一个内存地址），而不是内容是否相等。不过，有几类数据可以使用`==`来比较内容，具体如下：

### 1. **基本数据类型（Primitive Types）**

- **适用情况**：所有基本类型（`byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`）都可以使用`==`比较值。

- 示例：

  ```java
  int a = 5;
  int b = 5;
  System.out.println(a == b); // true，值相等
  ```

### 2. **字符串常量池中的字符串（String Literals）**

- **适用情况**：当两个字符串是通过字面量赋值（而非`new String()`）创建时，JVM 会将它们放入字符串常量池，此时`==`比较的是内容。

- **示例**：

  ```java
  String s1 = "hello";
  String s2 = "hello";
  System.out.println(s1 == s2); // true，指向常量池中的同一个对象
  ```

- **注意**：使用`new String()`

  创建的字符串会在堆中分配新内存，此时`==`

  比较的是引用而非内容：

  ```java
  String s3 = new String("hello");
  System.out.println(s1 == s3); // false，引用不同
  ```

### 3. **包装类的缓存对象**

- **适用情况**：部分包装类（如`Integer`、`Byte`、`Short`、`Long`、`Character`）会缓存 [-128, 127] 范围内的值，使用`==`比较这些范围内的缓存对象时会返回`true`。

- **示例**：

  ```java
  Integer i1 = 100; // 自动装箱，实际调用 Integer.valueOf(100)
  Integer i2 = 100;
  System.out.println(i1 == i2); // true，缓存对象
  
  Integer i3 = 200;
  Integer i4 = 200;
  System.out.println(i3 == i4); // false，超出缓存范围，创建新对象
  ```

- **注意**：手动通过`new Integer(...)`

  创建的对象不会使用缓存，`==`

  **始终比较引用**：

  ```java
  Integer i5 = new Integer(100);
  Integer i6 = new Integer(100);
  System.out.println(i5 == i6); // false
  ```

### 4. **枚举常量（Enum Constants）**

- **适用情况**：枚举类的实例是单例的，同一个枚举常量在 JVM 中只有一个实例，因此可以使用`==`比较。

- **示例**：

  ```java
  enum Color { RED, GREEN, BLUE }
  Color c1 = Color.RED;
  Color c2 = Color.RED;
  System.out.println(c1 == c2); // true，同一个枚举常量
  ```

### 总结表格

| 数据类型       | `==`比较的内容               | 示例                                                         |
| -------------- | ---------------------------- | ------------------------------------------------------------ |
| 基本类型       | 值是否相等                   | `int a = 5; int b = 5; a == b → true`                        |
| 字符串常量     | 是否指向常量池中的同一个对象 | `String s1 = "a"; String s2 = "a"; s1 == s2 → true`          |
| 包装类缓存对象 | 是否为缓存范围内的同一个对象 | `Integer i1 = 100; Integer i2 = 100; i1 == i2 → true`        |
| 枚举常量       | 是否为同一个枚举实例         | `Color c1 = Color.RED; Color c2 = Color.RED; c1 == c2 → true` |

### 建议

- **基本类型和枚举**：可以安全使用`==`。

- **字符串和包装类**：建议使用`equals()`

  方法比较内容，避免因引用不同导致的意外结果。例如：

  ```java
  String s1 = new String("test");
  String s2 = new String("test");
  System.out.println(s1.equals(s2)); // true，内容相等
  System.out.println(s1 == s2); // false，引用不同
  ```
