# 接口、抽象类、类

本节讲述三者之间的关系。

## 抽象类实现接口

如果一个类被声明为**抽象类**（`abstract`），它**不必实现接口中的所有抽象方法**。未实现的方法会被继承到子类中，直到某个子类成为普通类时才必须全部实现。

```java
interface MyInterface {
    void method1();
    void method2();
}

// 抽象类可以选择性实现接口方法
abstract class MyAbstractClass implements MyInterface {
    @Override
    public void method1() {
        System.out.println("实现method1");
    }
    
    // 未实现method2()，由子类实现
}
```

## 普通类继承抽象类

上面讲述过，如果抽象类没有完全实现接口中的方法，那么子类会完成剩余的细节实现，如下：

```java
// 普通子类必须实现所有未实现的抽象方法
class MyChildClass extends MyAbstractClass {
    @Override
    public void method2() {
        System.out.println("实现method2");
    }
}
```
