# 一、常用正则表达式模式

| 模式    | 描述                                 |
| ------- | ------------------------------------ |
| `.`     | 匹配除换行符之外的任意字符           |
| `^`     | 匹配字符串的开始位置                 |
| `$`     | 匹配字符串的结束位置                 |
| `*`     | 匹配前面的字符 0 次或多次            |
| `+`     | 匹配前面的字符 1 次或多次            |
| `?`     | 匹配前面的字符 0 次或 1 次           |
| `{n}`   | 匹配前面的字符恰好 n 次              |
| `{n,}`  | 匹配前面的字符至少 n 次              |
| `{n,m}` | 匹配前面的字符至少 n 次，至多 m 次   |
| `[]`    | 匹配方括号中指定的任意一个字符       |
| `[^]`   | 匹配不在方括号中的任意一个字符       |
| `|`     | 匹配两个或多个模式中的任意一个       |
| `()`    | 分组匹配，将括号内的模式作为一个整体 |
| `\d`    | 匹配数字字符，等价于 `[0-9]`         |
| `\D`    | 匹配非数字字符，等价于 `[^0-9]`      |
| `\s`    | 匹配空白字符（空格、制表符等）       |
| `\S`    | 匹配非空白字符                       |
| `\w`    | 匹配单词字符（字母、数字、下划线）   |
| `\W`    | 匹配非单词字符                       |

# 二、re模块常用方法

| 方法                            | 功能描述                         | 示例代码片段                                                 |
| ------------------------------- | -------------------------------- | ------------------------------------------------------------ |
| `re.search(pattern, string)`    | 在字符串中搜索第一个匹配的模式   | `result = re.search(r'a.*c', 'abc')` → 返回匹配对象 `abc`    |
| `re.match(pattern, string)`     | 从字符串起始位置匹配模式         | `result = re.match(r'a.*c', 'abc')` → 起始位置匹配，返回 `abc` |
| `re.findall(pattern, string)`   | 查找所有匹配的模式，返回列表     | `re.findall(r'\d+', '123 abc 456')` → `['123', '456']`       |
| `re.finditer(pattern, string)`  | 返回所有匹配对象的迭代器         | `for match in re.finditer(r'\d+', '123 abc 456')` → 迭代输出 `123`、`456` |
| `re.sub(pattern, repl, string)` | 替换匹配的模式为指定字符串       | `re.sub(r'\d+', 'num', '123 abc 456')` → `'num abc num'`     |
| `re.split(pattern, string)`     | 根据匹配模式分割字符串           | `re.split(r'\s+', 'hello world')` → `['hello', 'world']`     |
| `re.compile(pattern)`           | 编译正则表达式，提高重复使用效率 | `p = re.compile(r'\d+')` → 之后可用 `p.findall('123 abc 456')` |

# 三、匹配对象常用方法

| 方法       | 功能描述                               | 示例（基于 `result = re.search(r'(\d+)-(\w+)', '123-abc')`） |
| ---------- | -------------------------------------- | ------------------------------------------------------------ |
| `group()`  | 返回匹配的字符串（默认返回全部匹配）   | `result.group()` → `'123-abc'`                               |
| `group(n)` | 返回第 n 个捕获组的匹配结果（n≥1）     | `result.group(1)` → `'123'`；`result.group(2)` → `'abc'`     |
| `start()`  | 返回匹配开始的索引位置                 | `result.start()` → `0`                                       |
| `end()`    | 返回匹配结束的索引位置（不包含该索引） | `result.end()` → `7`                                         |
| `span()`   | 返回匹配的起止索引元组 `(start, end)`  | `result.span()` → `(0, 7)`                                   |
