# 浏览器交互

浏览器交互，即用户使用浏览器进行的操作，比如：在地址栏输入地址、后退、刷新等等。

前面所学为元素交互，其主要是开发者与 HTML 页面内容进行交互。

## 使用示例

### 导航地址
```python
driver.get("https://www.baidu.com")
```

### 后退

```python
driver.back()
```

### 前进

```python
driver.forward()
```

### 刷新

```python
driver.refush()
```

### 警告框

#### `alert()` 警示框

```python
# 点击按钮
element = driver.find_element(By.ID, "XXX")
element.click()

# 这里建议添加一个显示等待，并不知道警示框何时弹出，如果直接调用关闭警示框的操作，那么其很有可能会发生 NoAlertPresentExcepiton
wait = WebDriverWait(driver, timeout=2)

# 使用 switch_to.alert，切换至警告框操作
alert = wait.until(lambda d : d.switch_to.alert)
# 获取文本内容
text = alert.text
# 确认警告框信息
alert.accept()
```

#### `confirm()` 确认框

确认框在 `alert()` 警告框之上添加了一个取消按钮。

```python
# 点击按钮
element = driver.find_element(By.ID, "XXX")
element.click()

# 这里建议添加一个显示等待，并不知道确认框何时弹出，如果直接调用关闭确认框的操作，那么其很有可能会发生 NoAlertPresentExcepiton
wait = WebDriverWait(driver, timeout=2)

# 使用 switch_to.alert，切换至警告框操作
alert = wait.until(lambda d : d.switch_to.alert)
# 获取文本内容
text = alert.text
# alert.accept()
# 取消警告框
alert.dismiss()
```

#### `prompt()` 提示框

提示框在 `confirm()` 确认框上面添加了一个文本输入框。

```python
# 点击按钮
element = driver.find_element(By.ID, "XXX")
element.click()

wait = WebDriverWait(driver, timeout=2)
alert = wait.until(lambda d : d.switch_to.alert)
# 向提示框内输入文本信息
alert.send_keys("Selenium")
text = alert.text
alert.accept()
```

### Cookies

#### 添加 cookie

```python
driver = webdriver.Edge()
driver.get("http://www.baidu.com")

# 添加
driver.add_cookie({"name": "foo", "value": "bar"})
```

#### 获取 cookie

```python
# 获取单个 cookie，根据 cookie 的名称匹配 cookie
cookie = driver.get_cookie("foo")
print(cookie)

# 获取全部 cookie
cookies = driver.get_cookies()
```

#### 删除 cookie

```python
# 删除单个 cookie，根据 cookie 的名称匹配 cookie
driver.delete_cookie("foo")

# 删除所有 cookie
driver.delete_all_cookies()
```

### 窗口

当开发者在进行自动化测试时，点击了某个链接跳转到了其他页面，那么屏幕会聚焦在新窗口或新标签页上，但 WebDriver 并不知道哪个窗口是需要进行操作的。在 `selenium` 3 之前（包含 `selenium` 3），需要遍历 `WebDriver` 找出窗口或标签页，然后选中开发者所要聚焦的窗口或标签页。

这很麻烦，在 `selenium` 4 中，提供了新的 API 供给开发者，下面以完整的代码示例展示，如下：

```python
from selenium import webdriver
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

# 启动驱动程序
with webdriver.Firefox() as driver:
    # 打开网址
    driver.get("https://seleniumhq.github.io")

    # 设置等待
    wait = WebDriverWait(driver, 10)

    # 存储原始窗口的 ID
    original_window = driver.current_window_handle

    # 检查一下，我们还没有打开其他的窗口
    assert len(driver.window_handles) == 1

    # 单击在新窗口中打开的链接
    driver.find_element(By.LINK_TEXT, "new window").click()

    # 等待新窗口或标签页
    wait.until(EC.number_of_windows_to_be(2))

    # 循环执行，直到找到一个新的窗口句柄
    for window_handle in driver.window_handles:
        if window_handle != original_window:
            driver.switch_to.window(window_handle)
            break

# 等待新标签页完成加载内容
wait.until(EC.title_is("SeleniumHQ Browser Automation"))

# 关闭标签页或窗口
driver.close()

# 切回到之前的标签页或窗口
driver.switch_to.window(original_window)
```

该代码是 `selenium` 官方所示代码，开发者可以制作一个简单的页面，然后使用以上代码进行测试。

#### 创建新窗口(或)新标签页并且切换

```python
# 打开新标签页并切换到新标签页
driver.switch_to.new_window('tab')

# 打开一个新窗口并切换到新窗口
driver.switch_to.new_window('window')
```

#### 窗口管理

```python
# 获取窗口大小
width = driver.get_window_size().get("width")
height = driver.get_window_size().get("height")
```

```python
# 设置窗口大小
driver.set_window_size(1024, 768)
```

```python
# 获取窗口左上角坐标位置
x = driver.get_window_position().get('x')
y = driver.get_window_position().get('y')
```

```python
# 设置窗口坐标位置
driver.set_window_position(0, 0)
```

```python
# 窗口最大化
driver.maximize_window()
# 窗口最小化
driver.minimize_window()
```

```python
# 窗口全屏
driver.fullscreen_window()
```

以上所有内容其实在 Options 类中讲述过，而这些函数的实现原理也是根据浏览器参数来进行设置的。
