## 什么是基元数据类型？

基元数据类型也就是所谓的八大基本数据类型。

如下，为官方文档介绍：

- `byte`：数据类型是 8 位有符号 2 补码整数。它的最小值为 -128，最大值为 127（含）。该数据类型可用于在大型数组中节省内存，其中内存节省实际上很重要。它们也可以用来代替它们的 limits 有助于阐明您的代码;变量的范围是有限的这一事实可以作为一种文档形式。
- `short`：数据类型为 16 位有符号 2 补码整数。它的最小值为 -32,768，最大值为 32,767（含）。与 一样，相同的准则适用：在内存节省实际上很重要的情况下，您可以使用 short 在大型数组中节省内存。`short``byte`
- `int`：默认情况下，数据类型是 32 位有符号二进制补码整数，最小值为 -2`int`31最大值为 231-1.
- `long`：数据类型为 64 位 2 补码整数。有符号 long 的最小值为 -2`long`63最大值为 263-1.

## 为什么创建基元数据类型？

当我们在做运算，查找等等一系列操作时，我们如果直接用具体的字符串、数字等等来进行操作，在后期的修改、重复使用和阅读是及其不方便的，所以我们用变量来进行保存。便于修改、阅读、使用。

## 怎么创建基元数据类型？

前面学习过创建变量，基元数据类型的变量如创建变量一样。

如下：

```java
private int i;
// 关键字（可不要） 数据类型 变量名称
```

这就声明了一个私有的int类型的变量名为i的变量（实列变量）。

## 补充

在 Java SE 7 及更高版本中，任意数量的下划线字符 （） 可以出现在数字文字中数字之间的任何位置。例如，此功能使您能够。分隔数字文本中的数字组，这可以提高代码的可读性。

例如：

```java
public class test_01 {
	public static void main(String args[]) {
		long creditCardNumber = 1234_5678_9012_3456L;
		long socialSecurityNumber = 999_99_9999L;
        System.out.println(creditCardNumber);	// 结果为1234567890123456
        System.out.println(socialSecurityNumber);	// 999999999
	}
}
```

以下示例演示了数字文本中有效和无效的下划线位置：

```java
// Invalid: cannot put underscores（不能放在小数点前）
// adjacent to a decimal point
float pi1 = 3_.1415F;
// Invalid: cannot put underscores（不能放在小数点后）
// adjacent to a decimal point
float pi2 = 3._1415F;
// Invalid: cannot put underscores（不能放在数字尾椎前）
// prior to an L suffix
long socialSecurityNumber1 = 999_99_9999_L;

// OK (decimal literal)（这样没问题）
int x1 = 5_2;
// Invalid: cannot put underscores（禁止放在最后）
// At the end of a literal
int x2 = 52_;
// OK (decimal literal)（这样没问题）
int x3 = 5_______2;

// Invalid: cannot put underscores（禁止放在字符和数字之间）
// in the 0x radix prefix
int x4 = 0_x52;
// Invalid: cannot put underscores（禁止放在字符和数字之间）
// at the beginning of a number
int x5 = 0x_52;
// OK (hexadecimal literal)（这样没问题）
int x6 = 0x5_2;
// Invalid: cannot put underscores（禁止放在最后）
// at the end of a number
int x7 = 0x52_;
```
