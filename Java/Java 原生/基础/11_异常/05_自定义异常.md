# 自定义异常

## 自定义异常类

自定义异常类很简单直接继承开发者选好的异常类。

如下：

```java
public class CustomBusinessException extends Exception {
    // 无参构造方法
    public CustomBusinessException() {
        super();
    }

    // 带消息构造方法
    public CustomBusinessException(String message) {
        super(message);
    }

    // 带消息和原始异常的构造方法
    public CustomBusinessException(String message, Throwable cause) {
        super(message, cause);
    }

    // 带原始异常的构造方法
    public CustomBusinessException(Throwable cause) {
        super(cause);
    }
}
```

## 关于异常类的选择

自定义异常类所继承的异常类怎么选择呢？

首先，**任何 `Exception`) 的子类都可以用作自定义异常类的父类。**

其次，自定义的异常类根据自定义异常类本身的性质去选择继承的异常类，以上代码很明显 `CustomBusinessException` 不能继承 `NullPointExceprion` 因为其本质和 *空指针* 没有任何关系。经过仔细挑选开发者会发现**大多数 `Exception` 的子类并不适合作为继承类**，因为它们都太专业。

所以干脆直接继承 `Exception` （前提是选择不到合适父类）。

大多数应用程序都会抛出作为 `Exception` 实例的对象。

上面为什么说是大部分呢？

**因为非 `RuntimeException` 及其子类是运行时的异常类，在编译时不会去进行检测。**

**当开发者需要一个运行时异常的时候可以选择继承 `RuntimeException`**
