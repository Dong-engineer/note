# 比较运算符

比较运算符用于对比两个操作数的值，最终表达式结果为 `true` 或 `false`。 下面示例使用**严格相等运算符** **`===`** 对比 `2 + 2` 和数字 `4`；两边值与类型完全一致，表达式结果为 `true`：

```js
2 + 2 === 4
// true
```

## 类型转换与相等判断

最常用的两类相等运算符：宽松相等 `==`、严格相等 `===`。 `==` 属于宽松对比，会自动转换两边操作数的数据类型再比较。如下：

```js
2 == 2		// true

2 == "2"	// true
```

`!=` 是宽松不等，仅当两边宽松对比不相等时返回 `true`：

```js
2 != 3		// true

2 != "2"	// false
```

`===` / `!==` 严格对比**不会自动转换类型**，只有两边数据类型、值完全一致才返回 `true`。 因此 `2 == "2"` 为真，但 `2 === "2"` 为假：

```js
2 === 3		// false

2 === "2"	// false
```

为了避免自动类型转换带来的逻辑歧义，开发中**优先使用** **`===`**。

| 运算符 | 说明       | 示例      | 结果 |
| ------ | ---------- | --------- | ---- |
| `===`  | 严格相等   | 2 === 2   | true |
| `!==`  | 严格不相等 | 2 !== "2" | true |
| `==`   | 宽松相等   | 2 == "2"  | true |
| `!=`   | 宽松不相等 | 2 != "3"  | true |
| `>`    | 大于       | 3 > 2     | true |
| `>=`   | 大于等于   | 2 >= 2    | true |
| `<`    | 小于       | 2 < 3     | true |
| `<=`   | 小于等于   | 2 <= 3    | true |

## 真值与假值

JS 中所有值都能隐式转为布尔值（宽松比较时会自动转换）。仅有少量值转换后为 `false`，称为**假值**：

- `0`
- `null`
- `undefined`
- `NaN`
- 空字符串 `""`

其余所有值转换后均为 `true`，称为**真值**，包括非空字符串、所有非 0 数字：

```js
"My string" == true		// true

100 == true		// true

0 == true		// false
```

## 逻辑运算符

使用逻辑与 `&&`、逻辑或 `||`、逻辑非 `!`，根据条件真假控制代码执行逻辑：

```js
2 === 3 || 5 === 5;
// true

2 === 2 && 2 === "2"
// false

2 === 2 && !"My string."
// false
```

逻辑非 `!` 会反转操作数的布尔状态：原值为假则返回 `true`，原值为真则返回 `false`

```js
true	// true

!true	// false

!false	// true
```

对数字、字符串等非布尔值使用 `!`，会先将其转为布尔再取反：

```js
"string"	// "string"

!"string"	// false

0	// 0

!0	// true
```

开发常用**双非** **`!!`** 快速将任意值转为标准布尔：

```js
!!"string"	// true

!!0		// false
```

逻辑与、逻辑或本身不会做类型转换，它们会直接返回两个操作数其中之一，返回规则由真假判定决定。

### 逻辑与 `&&`

规则：如果第一个操作数可转为假，直接返回第一个值；否则返回第二个值。 仅当两边都为真时，整体布尔结果为 `true`；任意一边为假则整体为 `false`。

```js
true && false		// false

false && true		// false

false && false		// false

true && true		// true
```

非布尔值示例：

```js
false && "My string"		// false

null && "My string"		// null

"My string" && false		// false

"My string" && "My second string"		// "My second string"

2 === 2 && "My string"		// "My string"
```

### 逻辑或 `||`

规则：如果第一个操作数可转为真，直接返回第一个值；否则返回第二个值。 任意一边为真，整体布尔结果为 `true`；两边全假才为 `false`。

```js
true || false		// true

false || true		// true

true || true		// true

false || false		// false
```

非布尔值示例：

```js
false || "My string"		// "My string"

null || "My string"		// "My string"

"My string" || false		// "My string"

"My string" || "My second string"		// "My string"

2 === 2 || "My string"		// true
```

## 空值合并运算符 `??`

仅当第一个操作数为 `null` / `undefined` 时，返回第二个值；否则直接返回第一个值。

```js
null ?? "My string"		// "My string"

undefined ?? "My string"	// "My string"

true ?? "My string";	// true
```

`??` 和 `||` 功能相似但判定标准更严格： `||` 只要第一个值是假值（0、false、"" 等）就返回第二个值； `??` 仅在 `===` 情况下 `null` / `undefined` 时才走兜底，0、false、空字符串都会正常保留：

```js
0 ?? "My string";	// 0

false ?? "My string";	// false

undefined ?? "My string";	// "My string"
```
