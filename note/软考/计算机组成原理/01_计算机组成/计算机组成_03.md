# 计算机组成

## 计算机的性能指标

计算机系统的性能是硬件各部分能力的综合体现，不同层级的硬件对应不同的量化评价指标。本节从整机、CPU、存储器、总线与 I/O 四个维度，梳理计算机组成的核心性能指标。

### 整机综合性能指标

整机指标反映计算机系统整体的任务处理能力，是用户最直观感知的性能维度。

1. **吞吐量** 指系统在单位时间内能够处理的任务或请求总量，体现系统的批量处理能力。吞吐量越高，系统同时承载业务的能力越强。
2. **响应时间** 也叫执行时间，指从用户提交任务到系统返回最终结果的总耗时，包含 CPU 执行时间、存储器访问等待时间、I/O 处理时间等所有环节的开销。响应时间越短，单任务的执行效率越高。

### CPU 核心性能指标

CPU 是计算机的运算与控制核心，其性能直接决定程序的执行速度，核心指标围绕时钟节拍、指令执行效率展开。

1. **时钟周期与主频**
   1. **时钟周期**：CPU 操作的最小时间单位，是 CPU 主频的倒数，所有 CPU 操作都以时钟周期为基准节拍。
   2. **主频（时钟频率）**：CPU 内核工作的脉冲频率，单位为 Hz（赫兹），常用单位为 GHz。主频越高，单位时间内 CPU 可完成的基础操作越多。
2. **CPI（Clock cycles Per Instruction）** 即每条指令执行的平均时钟周期数，反映指令执行的效率。
   1. CPI 受指令集架构、流水线设计、Cache 命中率等因素影响；
   2. 不同类型指令的 CPI 存在差异，系统整体 CPI 是各类指令的加权平均值。
3. **CPU 执行时间** 指 CPU 真正用于执行程序指令的时间，是衡量 CPU 性能的核心公式： $$CPU执行时间 = 指令总数 × CPI × 时钟周期 = \frac{指令总数 × CPI}{主频$$ 由此可知：CPU 性能由指令总数、CPI、主频三者共同决定，仅靠主频无法完全代表 CPU 的真实性能。
4. **MIPS（Million Instructions Per Second）** 即每秒执行百万条指令数，用于衡量 CPU 的整数运算处理速度。
   1. 计算公式：$$MIPS = \frac{主频}{CPI × 10^6$$
   2. 特点：仅适合同架构 CPU 的性能对比，不同指令集的机器之间参考价值有限。
5. **MFLOPS / GFLOPS** 即每秒百万 / 十亿次浮点运算次数，专门用于衡量浮点运算性能。
   1. 特点：不受指令集架构差异的影响，更适合评价科学计算、图形处理等场景的 CPU 性能。

### 存储器性能指标

主存储器（内存）是 CPU 交互的核心存储部件，其性能直接影响程序的整体运行效率。

1. **存储容量** 指主存储器能够存储的二进制信息总量，基本单位为字节（Byte）。

   1. 计算公式：$$存储容量 = 存储单元个数 × 存储字$$

   2. 常用单位：KB、MB、GB、TB，换算关系为 
      $$
      1TB=1024GB，1GB=1024M。
      $$
      

2. **存取时间（存储器访问时间）** 指从启动一次存储器读写操作，到操作完成、数据稳定输出的总时间，分为读出时间和写入时间。

3. **存储周期** 指连续两次独立的存储器操作之间的最小时间间隔。

   1. 存储周期通常大于存取时间，因为存储器完成一次操作后，需要短暂的恢复时间才能接收下一次访问。

4. **存储器带宽** 指单位时间内存储器能够读写的最大数据量，反映主存的数据传输能力，单位通常为 MB/s 或 GB/s。

   1. 带宽越高，CPU 与内存之间的数据传输瓶颈越小。

### 总线与 I/O 性能指标

总线是连接各部件的信息传输通道，I/O 是计算机与外部交互的接口，二者的性能决定系统的数据交互效率。

1. **总线宽度** 指数据总线一次能够并行传输的二进制位数，即位宽。常见的总线宽度有 32 位、64 位等，位宽越高，单次传输的数据量越大。
2. **总线时钟频率** 总线工作的基准时钟频率，单位为 MHz，决定总线传输的速率基准。
3. **总线带宽** 指单位时间内总线能够传输的最大数据量，是总线性能的核心指标。
   1. 计算公式：$$总线带宽 = 总线工作频率 × 总线宽度 ÷ $$（单位：字节 / 秒）
4. **I/O 吞吐率** 指单位时间内 I/O 设备与主机之间交互的数据总量，反映输入输出系统的整体数据处理能力。
