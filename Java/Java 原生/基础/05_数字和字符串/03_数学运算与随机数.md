# 数学运算

基本的算数，如：加减乘除。在之前符号运算已经学过了，这节要讲述的运算是超越基本运算的算术，如：开方、平方、对数、等等。

## Math

既然提到算术那么，`Math`类是不可错过的。`Math`类是 Java 专门提供的更高级的数学运算的类。

其中有很多的静态常量来表示平常数学运算中常用的数：

### 静态常量

| 变量名    | 对应数学常量                             |
| --------- | ---------------------------------------- |
| `Math.E`  | 自然对数的基数，e = 2.718281828459045... |
| `Math.PI` | 圆周率                                   |

### 静态方法

#### 计算绝对值

- `double abs(double d)`
- `float abs(float f)`
- `int abs(int i)`
- `long abs(long lng)`

针对不同类型的值进行绝对值转化。

#### 对值进行取整

- `double ceil（double d）`：返回大于或等于参数的最小整数。（向上取整）返回类型 `double`
- `double floor（double d）：`返回小于或等于参数的最大整数。（向下取整）返回类型 `double`
- `double rint（double d）`：返回值最接近参数的整数。（四舍五入）返回类型`double`
- `long round（double d）` ：返回最接近参数的整数。（四舍五入）返回类型`long`
- `int round（float f）：`返回最接近参数的整数。（四舍五入）返回类型`int`

#### 计算 min

在所接受的参数中找到最小值，只能接收两个相同的参数

- `double min(double arg1, double arg2)`
- `float min(float arg1, float arg2)`
- `int min(int arg1, int arg2)`
- `long min(long arg1, long arg2)`

#### 计算最大值

在所接受的参数中找到最大值，只能接收两个相同的参数

- `double max(double arg1, double arg2)`
- `float max(float arg1, float arg2)`
- `int max(int arg1, int arg2)`
- `long max(long arg1, long arg2)`

#### 指数和对象方法

- `double exp（double d）`：返回值e的d次幂。
- `double log（double d）`：返回参数的自然对数。
- `double pow（double base， double exponent）：` 返回的值为base为底数exponent为幂的结果。
- `double sqrt（double d）：`返回参数的平方根。
