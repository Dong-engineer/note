# 回调超时

在上一节 *05_启动回调与关闭回调* 中讲述过，`Lifecycle` 的回调是委托 `LifecycleProcessor` 来完成的， `SmartLifecycle` 也是如此，因为 `SmarLifecycle` 继承了 `Lifecycle`。

Spring 规定了每个阶段的回调方法等待默认时间是 30s 。如果超时会直接跳过回调进行下一生命周期。等待 30 s，这是因为 `LifecycleProcessor` 的默认实现类 `DefaultLifecycleProcessor` 在其方法中规定了等待 30 s。

如果开发者可以通过以下代码自定义时长，代码如下：

### 基于XML

```xml
<!-- 直接在XML文件中定义即可 -->
<bean id="lifecycleProcessor" class="org.springframework.context.support.DefaultLifecycleProcessor">
    
    <property name="timeoutPerShutdownPhase" value="10000"/>
    
</bean>
```

### 基于注解

```java
@Configuration
public class LifecycleConfig {
    
    @Bean(name = "lifecycleProcessor") // 注意 bean 名称必须是 lifecycleProcessor
    public DefaultLifecycleProcessor lifecycleProcessor() {
        DefaultLifecycleProcessor processor = new DefaultLifecycleProcessor();
        processor.setTimeoutPerShutdownPhase(10000); // 设置关闭阶段超时时间为 10 秒
        return processor;
    }
}
```
