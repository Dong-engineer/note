# 控制流程语句

## if

官方文档把这`if`语句称为`if-then`，即如果...然后就...，后面的学习不会提到`then`，`then`可以理解为`if`的方法体。

之前我们已经介绍过`if`语句的使用方法，如下：

```java
void applyBrakes() {
    if (isMoving){
        currentSpeed--;
    }
}
```

只有当`()`里面的布尔表达式为true才会执行`if`的方法体。

当`if`的方法体只含有一个语句的时候，如上的情况，我们可以简化`{}`，写法如下：

```java
void applyBrakes() {
    if (isMoving)	currentSpeed--;
}
// 也可以这样
void applyBrakes() {
    if (isMoving)
        currentSpeed--;
}
```

## if 、else if、else

上面我们判断了一种情况，那就是`isMoving=ture`的时候，但是我们并没有对`isMoving=false`进行判断。于是又`else`对其进行进行分支。

```java
void applyBrakes() {
    if (isMoving) {
        currentSpeed--;
    } else {
        System.err.println("The bicycle has already stopped!");
    }
}
```

但是`else`也没有对`isMoving=false`进行判断，`else`代表除了`isMoving=ture`所有情况，如果我们要对`isMoving`细节处理我们可以使用`else if()`，如下：

```java
void applyBrakes() {
    if (isMoving) {
        currentSpeed--;
    } 
    else if(!isMoving) {
        currentSpeed++;
    }
    else {
        System.err.println("The bicycle has already stopped!");
    }
}
```

下程序 根据测试分数的值指定等级：A 表示分数为 90% 或更高，B 表示分数为 80% 或更高，依此类推。

```java
class IfElseDemo {
    public static void main(String[] args) {

        int testscore = 76;
        char grade;

        if (testscore >= 90) {
            grade = 'A';
        } else if (testscore >= 80) {
            grade = 'B';
        } else if (testscore >= 70) {
            grade = 'C';
        } else if (testscore >= 60) {
            grade = 'D';
        } else {
            grade = 'F';
        }
        System.out.println("Grade = " + grade);
    }
}
```
## while（条件循环）

这里将`while、do...while`分开叙述，因为在使用do...while时，会有一些小问题容易被忽视。

`while`条件循环语句，当满足布尔表达式是，才会执行方法体。

如下：

```java
// 现在有一个数字1，需求是这个数字每次只能加1，一直加到10
public staitc void main(String arges[]) {
    int i = 1;
    
    // 程序运行到这里就开始判断，正常应该是判断i是否等于10，不等于10就继续循环加1
    while(i != 10) {
        System.out.println(i);
        i++;
    }
}
```

当`i`等10的时候，计算机还是会进行一次判断的，但是方法体不再执行。

可以使用如下代码验证：

```java
int i = 1;
int count = 1; // 循环次数

while(true) {

    count++;
    System.out.println("自增前i:" + i);

    if(i == 10) break; // 先判断
    i++; // 后操作

    System.out.println("自增后i:" + i);
}
System.out.println("最后结果：" + i);
System.out.println("最终循环次数：" + count);
```

`while`的条件一直为`true`，当`i=9`的时候 `i != 10`，循环继续方法体继续被执行，打印9，且`i`自增1，当`i=10`时，直接跳出了循环，不再打印和自增。说明当`i=10`时while的方法体被执行了，但是经过`if`的判断程序直接强制中止了。

## do...while（后测试循环）

前面我们知道while循环会多做一次判断，为了提高效率，让判断次数和执行次数相同，我们可以使用`do...while`循环

`do...while`，先执行，后循环。

如下：

```java
int i = 1;
int count = 1;

do{
    count++;
	System.out.println("自增前：" + i);
    i++;
    System.out.println("自增后：" + i);
}while(i != 10);
System.out.println("最后结果：" + i);
System.out.println("最终循环次数：" + count);
```

## for（步长循环）

步长循环又称`for`循环，`for`循环和while循环相似，`for`增加了变量初始化，且它会重复循环直到满足特定条件。

如下：

```java
int count = 1;
for(int i = 1; i <= 10; i++) {
    count++;
    System.out.println("当前i=" + i);
}
System.out.println("最终循环次数：" + count);

// 也可以自增2
int count = 1;
for (int i = 1; i <= 10; i+=2){
    count++;
    System.out.println("i=" + i);
}
System.out.println("循环次数为：" + count);
```

```cmd
i=1
i=2
i=3
i=4
i=5
i=6
i=7
i=8
i=9
i=10
循环次数为：11
```

for循环模板格式：

```java
for (initialization; termination; increment) {
    statement(s)
}
// initialization：初始化表达式
// termination：条件表达式
// increment：增量表达式
```

- *初始化*表达式初始化循环;当循环开始时，它执行一次。
- 当*条件*表达式的计算结果为 `false` 时，循环终止。
- *增量表达式*在循环的每次迭代后调用;此表达式递增*或*递减值是完全可以接受的。

## continue

`continue`跳过当前循环，进行下一次循环。

如下：

```java
for (int i = 0; i < 10; i++){
    if(i == 3) continue;
    System.out.println(i);
}
```

```cmd
0
1
2
4
5
6
7
8
9
```

由输出结果可见，当`i=3`时跳过了当前循环。

## break

`break`终止本轮循环，且`break`后面的代码不再运行。

如下：

```java
for (int i = 0; i < 10; i++){
    if(i == 5) break;
    System.out.print(i);
}
```

```cmd
01234
```

由输出结果可见，当`i=5`时，整个循环结束，且不再输出5(`break`后面的代码不再运行)。

## yield

在 Java 中，`yield` 关键字在不同版本有着不同的用途和含义。在 Java 13 及以后的版本中，`yield` 主要用于 `switch` 表达式，用于返回一个值。（这样说并不恰当）

官方文档中说明其作用：**从它所在的当前表达式中退出。**（请记住是从他当前的表达式中退出，而不是函数或者方法），在`switch`控制语句中会有介绍。

而在多线程编程中，`Thread.yield()` 方法可以让当前线程让出 CPU 时间片，给其他线程执行的机会。



如下：

```java
class Test {
    enum Day {
        MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
    }

    public int calculate(Day d) {
        return switch (d) {
            case SATURDAY, SUNDAY -> 0;
            default -> {
                int remainingWorkDays = 5 - d.ordinal();
                yield remainingWorkDays;
            }
        };
    }
}
```

以上代码有一些小问题值得注意下。

首先，`return`后面跟的是值表达式，但在以上代码中`return`后面跟的是`switch`表达式，在 Java 13 及以后的版本中，引入了 `switch` 表达式，`yield` 关键字用于在 `switch` 表达式中返回一个值。与传统的 `switch` 语句不同，`switch` 表达式可以作为一个值进行赋值或传递。

然后，`->`符号的使用，这是匿名函数的使用，后面会讲到的，不用着急。

最后，当我们调用`calculate(Day d)`函数的时候，`switch`语句（暂时没讲解到，因为Java更新迭代的原因，`switch`有了更多的用法，所以放后面讲了）会进行分支判断。根据不同的参数d，最终返回的值也不同。

总之，这里我们需要知道`yield`关键字后跟的是一个返回值即可。
