# 元素定位器

从现在开始就要正式学习爬取页面元素的内容了。

开发者应当使用 `WebDrive` 来获取浏览器元素。

这里不再讲述源码，直接以表格的形式呈现更加妥当。

因为在源码中开发者很难发现，其原理是如何实现的。

## 原理

对于元素的交互，其本质并非完全像 `Options` 和 `service` 那样通过 `WebDriver` 即可完成和浏览器的通信。

当然元素的交互还是需要 `WebDriver` 来完成的，除此之外，还需要 `W3c` 协议来协助完成，当开发者使用 `selenium` 模拟用户操作时，其本质还是**通过浏览器驱动与浏览器内核完成通信，然后在 DOM 树中找到指定元素（`fin_element()`），再通过 W3C 中专门向元素进行赋值的接口，直接向目标元素赋值，其赋值过程中开发者可以认为是没有用户进行操作的**。

## `find_element(by=By.ID, value: Optional[str] = None)`

该函数就是元素定位器。

参数：

​	by	=>	元素定位策略

​	value   =>	目标值字段名称

```python
from selenium import webdriver
from selenium.webdriver.common.by import By  # 元素定位方式
from selenium.webdriver.edge.options import Options

options = Options()
# 保持浏览器打开
options.add_experimental_option("detach", True)
# 禁用自动检测提示条
options.add_experimental_option("excludeSwitches", ["enable-automation"])
options.add_experimental_option('useAutomationExtension', False)

driver = webdriver.Edge(options=options)

driver.get("https://www.baidu.com")

# 当有多个元素需要匹配时，请使用 find_elements()
element = driver.find_element(By.ID, "kw")

print(element)
```

**当开发者需要定位多个元素时 => `find_elements()`**。

### 参数 `by` 的值

| 定位器 Locator         | 描述                                                         |
| ---------------------- | ------------------------------------------------------------ |
| `By.CLASS_NAME`        | 定位class属性与搜索值匹配的元素（不允许使用复合类名）        |
| `By.CSS_SELECTOR`      | 定位 CSS 选择器匹配的元素                                    |
| `By.ID`                | 定位 id 属性与搜索值匹配的元素                               |
| `By.NAME`              | 定位 name 属性与搜索值匹配的元素                             |
| `By.LINK_TEXT`         | 定位链接文本可视文本与搜索值完全匹配的锚元素                 |
| `By.PARTIAL_LINK_TEXT` | 定位链接文本可视文本部分与搜索值部分匹配的锚点元素。 如果匹配多个元素，则只选择第一个元素。 |
| `By.TAG_NAME`          | 定位标签名称与搜索值匹配的元素                               |
| `By.XPath`             | 定位与 XPath 表达式匹配的元素                                |

### 元素信息

开发者通过 `find_element()` 获取元素后，可以通过以下函数或属性访问元素信息。

#### 是否显示

```python
driver.get("https://www.baidu.com")

element = driver.find_element(By.ID, "kw")

# 返回一个布尔值
isdisplay = element.is_displayed()
```

### 是否启用

```python
driver.get("https://www.baidu.com")

element = driver.find_element(By.ID, "kw")

# 返回一个布尔值
isdisplay = element.is_enabled()
```

### 是否被选定

```python
driver.get("https://www.baidu.com")

element = driver.find_element(By.ID, "kw")

# 返回一个布尔值
isdisplay = element.is_selected()
```

### 获取元素的标签名

```python
driver.get("https://www.baidu.com")

element = driver.find_element(By.ID, "kw")

# 返回元素的标签名
label_name = element.tag_name
print(label_name)
```

### 获取元素高度

```python
driver.get("https://www.baidu.com")

element = driver.find_element(By.ID, "kw")

"""
返回元素元素左上角的X轴位置
元素左上角的y轴位置
元素的高度
元素的宽度
"""
location_information = element.rect
print(location_information)
```

### 获取元素文本内容

```python
driver.find_element(By.ID, "kw").text
```

### 获取元素 CSS 属性值

```python
# 可接受多个参数
driver.find_element(By.ID, "kw").value_of_css_property("font-size")
```

### 获取元素标签属性值

```python
drive.find_element(By.ID, "kw").get_attribute("value")
```

## 注意事项

这里开发者如果是先去百度页面检查元素，然后将目标元素的字段名传入参数中。这样做开发者发现会程序报错，因为开发者自行打开百度页面和驱动打开百度页面是两个页面，开发者需要在驱动启动后检查页面元素。

元素值不一样是因为百度页面的反爬机制，开发者在使用 `selenium` 进行自动化测试时，其所带浏览器选项参数会不一样，如：`User-Agent、Cookie` 等等，开发者可自行添加这些参数，模拟出用户真实操作的场景。
