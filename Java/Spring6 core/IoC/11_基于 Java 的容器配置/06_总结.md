# 总结

本节对本章节前面的内容进行总结。

本章节的内容和 Spring 官方文档对比，无论是知识点顺序、还是内容都有一些不同。

首先是顺序，知识点顺序并不同，Spring 官方文档优先简述了 `@Bean` 和 `@Configuration`，然后讲述基于注解容器的实例化，然后又详细讲述了 `@Bean` 和 `@Configuration` 。而本章节的顺序优先将 `@Bean、@Configuration`  讲述完，再去讲述了基于注解容器的实例化。

其次是内容，在原文档中 Spring 还讲述了 `AnnotationConfigWebApplication` 和 `web.xml` 文件的配置，在作者的内容里并没有讲述，因为这一块的内容作者认为放在 Spring MVC 的学习中更加适合，也许在那时开发者已经对所学内容的记忆并不完整，所以开发者要勤加复习。
