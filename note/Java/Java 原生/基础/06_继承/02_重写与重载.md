# 重写

在上一节的两段代码中都使用到了 `@Override` ，这种 `@ + "..."` 叫做注解，后面会讲述。

`Override` 重写，表示该方法继承于父类，但是子类的具体实现不同（即方法体不同）需要更改，所以就需要重写。

```java
@Override
public void start() {
    super.start();  // 2. 调用父类被重写的方法
    System.out.println(model + "发出轰鸣声");
}
```

**方法重写核心规则：**

1. **方法签名必须相同**（方法名、参数列表、返回类型）。
2. **访问权限不能更严格**（如父类方法为`protected`，子类重写时不能为`private`）。
3. **抛出异常范围不能更大**（若父类方法抛出`IOException`，子类只能抛出其子类或不抛出）。
4. **静态方法不能被重写**（静态方法属于类，不存在多态）。

这些规则保证了OCP原则，增加代码可读性，降低代码耦合度。

# 重载

上面提到了重写，这里紧接着说一下重载，避免二者混淆。

**重载和重写一点也不一样。**

在一个类中，同一个方法（行为或者函数），有可能会有多种形态，比如创建对象。

如下：

```java
class Animal {
    private String name;
    private int age;
    
    public Animal(){
        
    }
    public Animal(String name){
        this.name = name;
    }
    public Animal(String name, int age){
        this.name = name;
        this.age = age;
    }
    ...
}
```

上面代码就体现创建对象的多种形态模式，有参构造、无参构造。

在有参构造中，开发者考虑到可能在对象的初始化时，并不知道 `Animal` 对象的年龄，于是便将其年龄不在初始化，直接在参数列表中去掉一个参数。

这就叫重载。

**方法重载核心规则**：

1. **参数列表必须不同**（与返回类型、访问修饰符无关）。
2. **目的**：通过不同参数类型提供相似功能的多种实现。
