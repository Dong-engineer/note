# 依赖配置的细节

## 一、简单类型和非简单类型

我们在使用<property>标签的value属性会发现，其将属性或构造函数参数指定为人类可读的字符串表示。

Spring6 的 转换服务 可以将这些值从 `String` 转换成属性或参数的实际类型。

那么哪些类型符合 Spring6 的转换服务呢？

这里简单介绍一下，后面会学习 Spring6 的转换器`Converter`。

以下是BeanUtils类所提供的检验方法。

```java
public static boolean isSimpleValueType(Class<?> type) {
    return Void.class != type && Void.TYPE != type && (ClassUtils.isPrimitiveOrWrapper(type) || 
                                                       Enum.class.isAssignableFrom(type) || 
                                                       CharSequence.class.isAssignableFrom(type) || 
                                                       Number.class.isAssignableFrom(type) || 
                                                       Date.class.isAssignableFrom(type) || 
                                                       Temporal.class.isAssignableFrom(type) || 
                                                       URI.class == type || 
                                                       URL.class == type || 
                                                       Locale.class == type || 
                                                       Class.class == type);
}
```

由源码可知 ClassUtils、Enum（枚举类）、CharSequence、Number、Date、Temporal（时区类）、URI、URL、Locale、Class这些类及其继承类可以使用value来进行赋值，而这些类，根据我的学习，我称其为简单类型。

除此之外其他的类都叫做非简单类型。

但是Date类型注意，Date类型的默认格式不是`2000-01-01`，而是`Thu  Aug  11 15：19：59  CST  2022`（星期 月份 日期 时：分：秒 时区 年份），所以我们在为Date类型赋值时应使用后面那种格式才可以用value赋值。

## 二、注入内部Bean、外部Bean

### 内部Bean

在 `<property/>` 或 `<constructor-arg/`> 元素内的 `<bean/>` 元素定义了一个内部Bean，如下例所示。

```xml
<bean id="outer" class="...">
    <!-- 而不是使用对目标Bean的引用，只需在行内定义目标Bean即可 -->
    <property name="target">
        <bean class="com.example.Person"> <!-- 这是内部Bean -->
            <property name="name" value="Fiona Apple"/>
            <property name="age" value="25"/>
        </bean>
    </property>
</bean>
```

内部 bean 定义不需要定义 ID 或名称。如果指定了，容器不会使用这样的值作为标识符。容器也会忽略创建时的 `scope` 标志，因为内层 bean 总是匿名的，并且总是与外层 bean 一起创建。不可能独立地访问内层 bean，也不可能将它们注入到除包裹 bean 之外的协作 bean 中。

### 外部Bean

又称 合作者。

在 `<constructor-arg/>` 或 `<property/>` 中的`ref`属性，用来引入外部Bean（合作者）。

当有些标签不含`ref`属性时，我们就需要使用`<ref/>`标签来引入外部Bean。

当然也可以`<constructor-arg> <ref/> <constructor-arg/>`、`<property> <ref/> <property/>`这样使用。

如下。

```xml
<!-- Employee_bean -->
<bean id="employee" class="com.Dong.SpringIOC.Employee">
    <property name="name" value="路飞"> </property>
    <property name="age" value="21"> </property>
    <property name="department" ref="department"> </property>
</bean>

<bean id="employee1" class="com.Dong.SpringIOC.Employee">
    <property name="name" value="索隆"> </property>
    <property name="age" value="22"> </property>
    <property name="department" ref="department"> </property>
</bean>

<!-- Department_bean -->
<bean id="department" class="com.Dong.SpringIOC.Department">
    <property name="name" value="卫生部"> </property>
    <property name="employee">
        <list>
            <ref bean="employee"></ref>
            <ref bean="employee1"></ref>
        </list>
    </property>
</bean>
```

## 六、Null and Empty String Values

### 空字符串

Spring将属性等的空参数视为空字符串。下面这个基于XML的配置元数据片段将 `email` 属性设置为空字符串值（""）。

```xml
<bean class="ExampleBean">
    <property name="email" value=""/>
</bean>
```

相当于下面的Java代码:

`exampleBean.setEmail("");`

### null

`<null/>` 元素处理 `null` 值。下面的列表显示了一个例子。

```xml
<bean class="ExampleBean">
    <property name="email">
        <null/>
    </property>
</bean>
```

前面的配置等同于以下Java代码

`exampleBean.setEmail(null);`

## 七、外部文件配置

使用<property></property>

```xml
<!--引入外部文件-->
<context:property-placeholder location="classpath:jdbc.properties"/>

<bean id="druidDataSource" class="com.alibaba.druid.pool.DruidDataSource">
    <property name="url" value="${jdbc.url}"/>
    <property name="driverClassName" value="${jdbc.drive}"/>
    <property name="username" value="${jdbc.user}"/>
    <property name="password" value="${jdbc.password}"/>
</bean>
```

外部配置文件，如下：

```properties
jdbc.username=root
jdbc.password=1146299837wd
jdbc.url=jdbc:mysql://localhost:3306/Dong
jdbc.drive=com.mysql.cj.jdbc.Driver
```

首先我们需要知道 Spring6 在加载配置文件的时候，是先从我们的环境变量开始加载的，如果我们在配置文件中这样写，如下：

```properties
username=root
password=1146299837wd
url=jdbc:mysql://localhost:3306/Dong
drive=com.mysql.cj.jdbc.Driver
```

实例化容器后，getBean()并打印输出Bean的信息会发现username并不是root，这是因为Spring在加载时是从我们的环境变量开始加载的，username优先所对应的是你**管理员的账户名称**，所以我们在写配置文件的时候应在属性前面加上前缀标识（规范标准）。

## 八、总结

```xml
<bean id="moreComplexObject" class="example.ComplexObject">
    <!-- results in a setAdminEmails(java.util.Properties) call -->
    <property name="adminEmails">
        <props>
            <prop key="administrator">administrator@example.org</prop>
            <prop key="support">support@example.org</prop>
            <prop key="development">development@example.org</prop>
        </props>
    </property>
    <!-- results in a setSomeList(java.util.List) call -->
    <property name="someList">
        <list>
            <value>a list element followed by a reference</value>
            <ref bean="myDataSource" />
        </list>
    </property>
    <!-- results in a setSomeMap(java.util.Map) call -->
    <property name="someMap">
        <map>
            <entry key="an entry" value="just some string"/>
            <entry key="a ref" value-ref="myDataSource"/>
        </map>
    </property>
    <!-- results in a setSomeSet(java.util.Set) call -->
    <property name="someSet">
        <set>
            <value>just some string</value>
            <ref bean="myDataSource" />
        </set>
    </property>
</bean>
```

map 的 key 值或 value 值，或 set 值，也可以是以下任何元素。

```tex
bean | ref | idref | list | set | map | props | value | null
```

### 集合、外部文件配置的合并

对于Java中的<list/>、<map/>、<set/>或者<props/>（用这个引入外部配置文件），可以对其进行合并。

在官方的文档中写道，开发者可以定义一个父类，一个子类，如下：

```xml
<beans>
    <bean id="parent" abstract="true" class="example.ComplexObject">
        <property name="adminEmails">
            <props>
                <prop key="administrator">administrator@example.com</prop>
                <prop key="support">support@example.com</prop>
            </props>
        </property>
    </bean>
    <bean id="child" parent="parent">
        <property name="adminEmails">
            <props merge="true">
                <prop key="sales">sales@example.com</prop>
                <prop key="support">support@example.co.uk</prop>
            </props>
        </property>
    </bean>
<beans>
```

首先，父元素`parent`被声明为abstract，所以在Spring容器初始化时，改`parent`元素并没有被创建。

其次，只有继承了这个抽象 bean 的子 bean（例如示例里的`child`），在被请求创建实例时，才会用到这个抽象 bean 定义里的属性和配置。

最后，抽象 bean 没办法单独被实例化，它的主要作用就是减少子 bean 定义时的重复配置。

如下：（注意support元素被重新赋值）

```cmd
administrator=administrator@example.com
sales=sales@example.com
support=support@example.co.uk
```

#### 补充

官方文档只说明了父子元素怎么进行集合合并，并未说明非父子元素怎么进行集合合并（可能说明了，但在依赖那一章节并未有讲解），下面对其进行补充：

##### Java原生

```java
import java.util.ArrayList;
import java.util.List;
import java.util.stream.Collectors;
import java.util.stream.Stream;

public class CollectionMergeExample {
    public static void main(String[] args) {
        // 创建示例集合
        List<String> list1 = List.of("A", "B");
        List<String> list2 = List.of("C", "D");

        // 方式 1：创建新集合（不修改原集合）
        List<String> mergedList = new ArrayList<>(list1);
        mergedList.addAll(list2);
        System.out.println("合并结果：" + mergedList);

        // 方式 2：使用 Stream（Java 8+）
        List<String> mergedByStream = Stream.concat(list1.stream(), list2.stream())
                .collect(Collectors.toList());
        System.out.println("Stream 合并结果：" + mergedByStream);
    }
}
```

##### Spring的CollectionUtils

```java
import org.springframework.util.CollectionUtils;
import java.util.ArrayList;
import java.util.List;

List<String> list1 = new ArrayList<>(List.of("A", "B"));
List<String> list2 = List.of("C", "D");

// 将 list2 合并到 list1（修改原集合）
CollectionUtils.mergeArrayIntoCollection(list2.toArray(), list1);
System.out.println("合并后：" + list1); // 输出 [A, B, C, D]
```



### 集合合并的限制

你不能合并不同的集合类型（例如 `Map` 和 `List`）。如果你试图这样做，会抛出一个适当的 `Exception`。

`merge` 属性必须被指定在较低的、继承的、子定义上。

在父级集合定义上指定 `merge` 属性是多余的，并且不会导致期望的合并。
