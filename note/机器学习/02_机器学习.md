# 机器学习

本节介绍机器学习如何工作、类别，最后会分节简述其各个算法原理。

## 机器学习工作

在学习之前，这里默认开发者对计算机是由一定认知的。

机器学习的核心思想是让机器通过算法

前辈们将整个机器学习的过程拆分为大致以下几个步骤：

1. 收集数据
2. 数据预处理
3. 选择模型
4. 训练模型
5. 模型评估
6. 模型优化
7. 部署模型
8. 反馈循环

总的来说其实就是，将数据收集好并且处理成计算机认识的数据，然后选择合适的算法进行不断迭代循环，而这一个整体就是开发者所创作的模型，最后计算模型的准确率，再根据数据细节不断优化参数，直到模型评估过关即可。

下面介绍一些术语，在以后的日程学习中会用到。

- Labeled Data：标签数据
- Model Training：模型训练
- Test Data：测试数据
- Prediction：预测
- 结构化数据：如：表格数据等等
- 非结构化数据：如：图片、文本、视频等等

接下来对每一个步骤进行详细讲述。

### 数据收集

数据收集，字面意思，开发者应当选择好数据，然后进行采集，至于什么是数据？哪些东西可以是数据？

一句话，万物皆可数据。

数据的采集过程往往需要高精度仪器，花费大量心思，收集完成后仍然需要开发者对这些数据进行处理。

### 数据预处理

数据预处理，其难度的高低是依据数据收集来决定的，如果收集的数据量超级大，那么数据预处理的工作量也会相对提升，数据收集大部分时候需要收集多个维度的数据，这也就导致数据预处理的工作量程几何级增加。

数据预处理主要是将收集到的数据进行整理，整理出有效数据，收集到的数据通常包含”脏、乱“，如：图片数据。收集到的图片数据往往会因噪声、模糊等等问题，最后导致整个模型的评估值很低。

数据预处理有很多的细节操作，而这些操作会影响整个模型的效率、评估。

后面自然会学到。

提到数据的处理，对 Python 熟悉的开发者，肯定想到 Pandas。这也是做机器学习的项目为何常常使用 Python 的原因之一。

### 选择模型

选择模型，与其叫做选择模型，不如称其为选择算法。算法归根到最后，并无牛与不牛之分，合适才是最好。

在以后的开发中，会要养成对问题分析的习惯，遇见的问题是什么样的？这需要开发者心中对问题有一定的理解，然后选择合适的算法去解决问题。

在最初的版本中选择模型这一段内容，作者表示需要将问题拆分后，再分析问题选择出合适的方法，但是AI 给出了不一样的观点，经过阅读思考 AI 的内容，下面重新书写。

在选择模型时，并非要强行（注意是强行）拆解问题，在实际的开发和应用中，要根据需求不同来灵活调整，如：房价和房屋面积，这显然易见是线性的关系，开发者也可以很轻松的选择出对的模型来解决问题。但实际生活中大部分问题是复杂的，也就是非线性的，这时就需要选择随机森林、神经网络等非线性算法来解决问题。

以上均是选择模型时的思想核心之一。除此之外还有 **问题类型（分类、聚类、回归等等）、数据特点（文本、图片、视频、声音等等）**。

选择模型的核心思想是从 **问题类型、数据特点、业务需求** 三点下手。

### 训练模型

训练模型，很好理解就是对选择好的模型进行训练。

但是训练好模型后，需要验证、测试，这是对模型的检测。

这也就要求了开发者对训练集有一定的了解，**划分出合适每一阶段的训练集**。

划分训练集，开发者需要将训练集划分为训练集、验证集、测试集，只有当模型完成了测试，才能对模型进行评估。

### 模型评估

使用测试集来评估模型，开发者需要定义一个指标，常用指标有准确率、召回率、F1分数等等。

### 模型优化

如果选择的模型满足开发者预期或者业务需求，模型评估过关，那么开发者就要优化参数，对模型进行调优，选择出一个合适的参数，使得该模型能最大程度的解决目标问题。

### 部署模型

完成模型的优化后，开发者就可以部署属于自己的模型。
