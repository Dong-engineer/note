# Object

之前已经了解过 `Object` ，在本节会详细说一下。

`java.lang` 包中的 Object 类位于类层次结构树的顶部。每个类都是 `Object` 类的直接或间接后代。您使用或编写的每个类都继承了 `Object` 的实例方法。您不需要使用这些方法中的任何一个，但是，如果您选择这样做，则可能需要使用特定于您的类的代码覆盖它们。本节中讨论的从 `Object` 继承的方法。

## Object 类中的方法

| 方法名              | 描述                                                     | 注意事项                                                     |
| ------------------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| `toString()`        | 返回对象的字符串表示，默认返回类名和哈希码               | 子类通常重写以提供更有意义的信息                             |
| `equals(Object)`    | 判断两个对象是否相等，默认比较引用                       | 重写时必须同时重写`hashCode()`，保证相等对象哈希码相同       |
| `hashCode()`        | 返回对象的哈希码值，用于哈希表操作                       | 若`equals()`返回`true`，则`hashCode()`必须相同               |
| `getClass()`        | 返回对象的运行时类`Class`对象                            | 被`final`修饰，不可重写                                      |
| `clone()`           | 创建并返回对象的副本                                     | 类必须实现`Cloneable`接口，默认浅拷贝，深拷贝需重写          |
| `finalize()`        | 垃圾回收前被调用（已过时）                               | Java 9 + 后弃用，Java 18+后已经删除                          |
| `notify()`          | 唤醒在此对象监视器上等待的单个线程                       | 必须在同步块 / 方法中调用                                    |
| `notifyAll()`       | 唤醒在此对象监视器上等待的所有线程                       | 必须在同步块 / 方法中调用                                    |
| `wait()`            | 使当前线程等待，直到其他线程调用`notify()`/`notifyAll()` | 必须在同步块 / 方法中调用，可被中断（`InterruptedException`） |
| `registerNatives()` | 注册本地方法，在类加载时被调用                           | 私有方法，用于 Java 与本地代码（如 C/C++）连接               |

详细的内容在之前的*类*一节中讲述过，线程相关的方法和`registerNatives()`暂时不讲述。关于`registerNatives()`的使用可以自己搜索寻找一下。
