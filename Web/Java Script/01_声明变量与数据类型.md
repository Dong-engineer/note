# 声明变量和数据类型

## 数据类型

在前言中说到 JS 并没有强类型检查，但是 ECMAScript 标准还是定义了 JS 中的 8 中数据类型。

该 8 种数类型也如同 Java 一样有着**基本数据类型**和**引用数据类型**之分。

7 种基本数据类型、1 种引用数据类型，如下：

### 八种数据类型

1. `Boolean` 。`true` 和 `false`。
2. `null` 。一个表示空值的特殊关键字。（因为 JavaScript 是区分大小写的，所以 `null` 和 `Null`、`NULL` 或其他变体是不一样的。）
3. `undefined` 。一个未定义值的顶级属性。
4. `Number`。整数或浮点数。例如，`42` 或 `3.14159`。
5. `BigInt` 。任意精度的整数。例如，`9007199254740992n`。
6. `String` 。表示文本值的字符序列。例如，`"Howdy"`。
7. `Symbol` 。其实例是唯一且不可变的数据类型。
8. `Object` 。所有的包装类（包括以上 7 种），都默认继承 `Object` 。

> 这里需要开发者注意！！！
>
> 在 V8 引擎的源码中有 5  中原始数据类型类型：boolean、number、string、bigInt、symbol。
>
> 后面会有代码示例，而以上 8 种数据类型中的包装类，就是这 5 种原始类型所对应的包装类，任何的包装类都会继承 Object 。
>
> 在 V8 引擎中 Number（JS 类型） > JSNumber（V8 源码结构体），String > JSString，等等包装类都是继承 JSObject 的，而 Object > JSObject ，所以开发者使用 typeof() 去判断某个包装类，打印输出的结果是 object。
>
> 对于 null ，其本质也是一个 object 对象（所以开发者使用 typeof(null) 的结果为 object），但是其具有空指针的意思。
>
> 对于 undefined ，其是一个特殊值，表明了变量并没有对应的数据结构体，typeof(undefined) 的结果就是 undefined。
>
> 这里开发者可能不容易理解，后面在每个包装类的学习过程中会有代码呈现结果，开发者需要注意阅读。

## 声明变量

在 JS 中并没有强类型检查，所以也就特别对的类型关键字。

在 JS 中的变量的类型是动态的，而声明变量只有**三个关键字**：`var`、`let`、`const`

### var

```js
// 动态类型，根据右值类型从而推断出左变量的类型
// 在 JS 中有很高的书写自由度，每行程序后没有 ';' 也可以
var i = 3;

// function 声明函数，这里函数名随便命名，后续讲述到了再遵守标识符命名规范
function one() {
    console.log(i);
    console.log(typeof(i));
}

one()
```

```cmd
3
number
```

`var` 关键字所声明的变量**可以是局部变量也可以是，全局变量**，具体情况要取决于 `var` 所声明变量所在的上下文。

### let

```js
let i = 5;

function one() {
    console.log(i);
    console.log(typeof(i));
}

one()
```

```cmd
5
number
```

`let` 所声明的变量是局部变量，即在一对 `{}` 中，使用了 `let` 声明某一变量，那么该变量的有效作用域仅限于该 `{}` 中。

如下：

```js
function one() {
    let i = 3;
    console.log(i);
    console.log(typeof(3));
}

console.log(i) // 找不到变量 i
```

```cmd
Uncaught ReferenceError: i is not defined
    at <anonymous>:7:13
```

### const

```js
const i = 5;

function one() {
    console.log(i);
    console.log(typeof(i));
}

one()
```

```cmd
5
number
```

`const` 所声明的变量也是局部变量，但不同的是 `const` 声明的是一个常量，准确的来说，一旦使用了 `const` 声明了某个变量，且初始化后，就无法修改其值了。

如下：

```js
const i = 2;
i = 3; // 抛出异常
```

```cmd
VM424:2 Uncaught TypeError: Assignment to constant variable.
    at <anonymous>:2:3
```

## 注意事项

这里也许有开发者会认为直接使用 `var` 不就行了吗，这样想是错误的，在实际开发中需要灵活应用 `var、let、const` ，根据不同需求来选用不同的关键字，保证变量的线程安全问题，以及性能和后续维护问题。
