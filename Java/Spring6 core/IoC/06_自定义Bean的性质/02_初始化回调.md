# 初始化回调

Bean 的初始化回调，在上一章节已将讲述了其具体什么时间发生。

在 Spring 的原文档的初始会回调一节中是这样描述的：`org.springframework.beans.factory.InitializingBean` 接口让Bean在容器对Bean设置了所有必要的属性后执行初始化工作。`InitializingBean` 接口指定了一个方法。

的确是在 Bean 的依赖注入后执行的初始化回调，但是在 Spring 文档的后面还说明了 `ApplicationContextAware、BeanNameAware` 。所以在上一节有所说明。

总之，Bean 的初始化回调其具体的发生时间是 `BeanPostProcessor` 前置处理后面。

## `afterPropertiesSet()`

这是 Spring 中 `org.springframework.beans.factory.InitializingBean` 接口中的方法，用于实现 Bean 的初始化回调，所以如果开发者想要设置 Bean 的初始化回调就要实现该接口，重写`afterPropertiesSet()`方法。如下：

```java
public class AnotherExampleBean implements InitializingBean {

    @Override
    public void afterPropertiesSet() {
        
    }
    
}
```

但是 Spring 不建议这样做，因为这样会和 Spring 的代码有强耦合。

### 基于XML文件的初始化回调

Spring 基于XML文件提供在 `<bean/>` 中提供了 `init-method==""` 属性用来指定 Bean 的初始化回调方法的名称。

具体代码如下：

假设开发者有一个 Bean 需要在初始化时声明自身已被创建：

```java
public class User {
	
    public User() {
        
    }
    
    public void initUser() {
        System.out.println("User对象已被创建");
    }
    
}
```

```xml
<bean id="user" class="xxx.User" intit-method="intitUser"/>
```

### 基于注解

```java
public class User {
	

    public User() {
        
    }
    
    // 初始化回调方法
    @PostConstruct
    public void initUser() {
        System.out.println("User对象已被创建");
    }

}
```
