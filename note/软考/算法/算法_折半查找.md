# 折半查找（二分查找）

二分查找（折半查找）要求序列是有序的，给定的关键码序列是有序的。其基本思想是：设查找表的元素存储在一维数组 `r[low, ..., high]` 中，首先确定查找区间的中间位置 `mid = (low + high) / 2` ，然后将待查的值 `key` 与 `r[mid]` 比较：

- 若 `key = r[mid]`，则查找成功；
- 若 `key < r[mid]`，则在左子表 `r[low, ..., mid - 1]` 中继续查找；
- 若 `key > r[mid]`，则在右子表 `r[mid + 1, ..., high]` 中继续查找 。

初始序列 `(9, 12, 15, 20, 24, 29, 56, 69, 87)` ，`low = 0`，`high = 8`，计算 `mid = (0 + 8) / 2 = 4`，此时 `r[mid]` 即 `24` ，要查找的 `15 < 24` ，所以接下来在左子表查找。
左子表为 `(9, 12, 15, 20)` ，此时 `low = 0`，`high = 3` ，重新计算 `mid = (0 + 3) / 2 = 1` ，`r[mid]` 即 `12` ，`15 > 12` ，接下来在右子表查找。
右子表为 `(15, 20)` ，`low = 2`，`high = 3` ，计算 `mid = (2 + 3) / 2 = 2` ，`r[mid]` 即 `15` ，查找成功。
