

# 匿名类

在 Java 中，**匿名类（Anonymous Class）** 是一种临时创建的、没有显式命名的类，它允许你在使用的地方直接实现接口或继承抽象类。匿名类通常用于创建一次性的、简单的实现。

### **1. 匿名类的语法**

匿名类的基本语法如下：

```java
new ParentClassOrInterface() {
    // 类体：实现接口方法或重写父类方法
};
```

这里的 `ParentClassOrInterface` 可以是：

- 一个接口（匿名类必须实现该接口的所有方法）。
- 一个抽象类或普通类（匿名类必须实现所有抽象方法，或重写普通方法）。

### **2. 匿名类的使用场景**

#### **场景 1：实现接口**

```java
// 定义一个接口
interface Greeting {
    void sayHello();
}

// 使用匿名类实现接口
Greeting englishGreeting = new Greeting() {
    @Override
    public void sayHello() {
        System.out.println("Hello!");
    }
};

// 使用匿名类创建另一种实现
Greeting spanishGreeting = new Greeting() {
    @Override
    public void sayHello() {
        System.out.println("¡Hola!");
    }
};

// 调用方法
englishGreeting.sayHello(); // 输出: Hello!
spanishGreeting.sayHello(); // 输出: ¡Hola!
```

#### **场景 2：继承抽象类**

```java
// 定义抽象类
abstract class Animal {
    abstract String makeSound();
}

// 使用匿名类继承抽象类
Animal cat = new Animal() {
    @Override
    String makeSound() {
        return "Meow";
    }
};

System.out.println(cat.makeSound()); // 输出: Meow
```

#### **场景 3：重写普通类的方法**

```java
// 定义普通类
class Calculator {
    int add(int a, int b) {
        return a + b;
    }
}

// 使用匿名类重写方法
Calculator advancedCalculator = new Calculator() {
    @Override
    int add(int a, int b) {
        System.out.println("Performing addition...");
        return a + b;
    }
};

System.out.println(advancedCalculator.add(3, 4));
// 输出:
// Performing addition...
// 7
```

### **3. 匿名类的特点**

- **没有显式类名**：无法在其他地方复用，只能在创建时使用一次。

- **可以访问外部变量**：但外部变量必须是 `final` 或实际上不可变的（Java 8+）。

  ```java
  final int factor = 10;
  Calculator multiplier = new Calculator() {
      @Override
      int add(int a, int b) {
          return (a + b) * factor; // 访问外部变量
      }
  };
  ```

- **语法简洁**：适合简单的、一次性的实现，避免创建过多的命名类。
