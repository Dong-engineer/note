# 创建非基元数据类型

什么是非基元数据类型？

为什么创建非基元数据类型？

怎么创建？

## 什么是非基元数据类型？

顾名思义，除了非基元数据类型的一切数据类型都是非基元数据类型。

如String、Date等等。

## 为什么创建非基元数据类型？

非基元数据类型是开发人员所定义的数据类型，包括String，String是Java原生中的一种数据类型，这是Java开发人员所定义好的，我们可以直接拿来用。

非基元数据类型可以由基元数据类型或者非基元数据类型组合而成，其所表示的数据更加复杂，多元化。

## 怎么创建

前面了解过通过Class关键字声明一个类，该类就表示一种非基元数据类型。

如下：

```java
public class A {
    int i;
    String name;
    public A () {
        
    }
    public A(int i, String name) {
        this.i = i;
        this.name = name;
    }
}
```

以上我们就称其是A数据类型，A数据类型包含了两个属性（字段），一个是 int 类型，一个是 String 类型。A数据类型被声明为public（公共的），所以我们可以在其他包中使用A声明变量。声明变量后，我们需要通过new关键字对变量声明对象（可以理解为在堆内存中开辟一片属于其的空间），然后我们可以使用 . 来访问A的属性。

如下：

```java
public class B {
	A a = new A(1, "123");
    public static void main(String args[]) {
        System.out.print(a.i) // 结果为：1
    }
}
```
