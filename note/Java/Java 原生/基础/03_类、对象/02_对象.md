## 创建对象

### 无参构造

#### get()访问字段

上节学习过了类，这节学习将类具体化，也就是创建对象。上节我们学过了要想将抽象类具体化我们需要使用构造器。

创建一个测试类，如下：

#### set()设置字段

运行结果发现，在输出`bicycle.getOwner()`时为null，这是因为我们在调用无参构造时，并没有对其字段进行赋值，下面讲述怎么赋值，如下：

```java
public class Test07 {
    
    public static void main(String[] args) {

        Bicycle bicycle;

        bicycle = new Bicycle();

        System.out.println(bicycle.getOwner());

        bicycle.moving();
        
        // set() 设置cadence字段值
        bicycle.setCadence(20);
        bicycle.setSpeed(10);
        bicycle.setGear(2);
        bicycle.setOwner("Dong");
        
        System.out.println(bicycle.getCadence());
        System.out.println(bicycle.getSpeed());
        System.out.println(bicycle.getGear());
        System.out.println(bicycle.getOwner());
    }
    
}
```

```cmd
20
10
2
Dong
```

#### equals()

紧接上面内容，`bicycle1 == bicycle2`比较的内容是什么呢？先分别将`bicycle1、bicycle2`输出看一下，如下：

```java
public class Test07 {

    public static void main(String[] args) {
    
        Bicycle bicycle1;
    
        bicycle1 = new Bicycle(10, 20 ,30, "Dong");
        
        Bicycle bicycle2;
    
        bicycle2 = new Bicycle(10, 20 ,30, "Dong");
        

        System.out.println(bicycle1);
        System.out.println(bicycle2);

    }

}
```

```cmd
Bicycle@2f4d3709
Bicycle@4e50df2e
```

可以发现输出后的内容如上，`Bicycle@2f4d3709`代表了`bicycle1`的内存地址的哈希值`@`符号来分割前面是类名后面是JVM加工地址后的哈希值，所以`==`比较的实际是对象的内存地址的哈希值，但是有个别情况（比如：基元数据类型）例外，后面会在***03_对象的比较***中详细讲述。

`equals`这是Java提供专门用来比较对象的内容的方法，如下：

```java
public class Test07 {

    public static void main(String[] args) {
    
        Bicycle bicycle1;
    
        bicycle1 = new Bicycle(10, 20 ,30, "Dong");
        
        Bicycle bicycle2;
    
        bicycle2 = new Bicycle(10, 20 ,30, "Dong");


        System.out.println(bicycle1==bicycle2);
    
    }

}
```

```java
false
```

还是`false`，没错，还是`false`，点击源码看一下，如下：

```java
public boolean equals(Object obj) {
    return (this == obj);
}
```

发现`equals()`返回了`this == obj`，这和直接用`==`没什么两样，那为什么还用`equals`呢？

首先，在开发时应当符合开发标准，去使用`equals()`去对比对象。

其次，Java在源码中已经说明当类用到`equals()`时应当重写其方法

最后，知道默认`equals()`是对比对象的哈希值的，开发人员希望对比其字段属性，所以需要重写`equals()`方法。

又有新问题了，怎么重写呢？开发人员希望通过`equals()`去判断俩个对象的内容是否一样，所以，直接使用其字段属性对应的比较方式去对比即可。

重写如下：

```java
class Bicycle {
    private int cadence;
    private int gear;
    private int speed;
    private String owner;
    
    ...

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;

        Bicycle bicycle = (Bicycle) o;

        if (cadence != bicycle.cadence) return false;
        if (gear != bicycle.gear) return false;
        if (speed != bicycle.speed) return false;
        return Objects.equals(owner, bicycle.owner);
    }
}
```

以上代码发现`int`类型字段使用的是`==或!=`进行对比，`String`类型使用的是`equals()`，详情在***03_对象的比较***中讲述。

测试一下：

```java
public static void main(String args[]) {

    Bicycle bicycle1;

    bicycle1 = new Bicycle(10, 20 ,30, "Dong");

    // 注意变量名不要一样
    Bicycle bicycle2;

    bicycle2 = new Bicycle(10, 20 ,30, "Dong");

    System.out.println(bicycle1);
    System.out.println(bicycle2);

    System.out.println("这是equals():" + bicycle1.equals(bicycle2));
}
```

```cmd
Bicycle@2f4d3709
Bicycle@4e50df2e
这是equals():true
```



#### hashCode()

`hashCode()`返回对象或者变量的内存地址的哈希值，目的是去除字段重复的对象。

具体的作用在`equals`里已经讲述，**当开发者希望某一类的对象保持唯一**，那么这个对象的类应当重写`hashCode()`。

在`equals()`测试结果中，可见两个对象内存地址的哈希值还是不一样的，说明`bicycle1、bicycle2`对应的内存地址还是不同的，但是`bicycle1.equals(bicycle2)`已经为`true`了。

为了保证`bicycle1、bicycle2`对应的内存地址相同，重写`hashCode()`。

如下：

```java
class Bicycle {
    private int cadence;
    private int gear;
    private int speed;
    private String owner;

    ...

        @Override
        public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;

        Bicycle bicycle = (Bicycle) o;

        if (cadence != bicycle.cadence) return false;
        if (gear != bicycle.gear) return false;
        if (speed != bicycle.speed) return false;
        return Objects.equals(owner, bicycle.owner);
    }

    @Override
    public int hashCode() {
        int result = cadence;
        result = 31 * result + gear;
        result = 31 * result + speed;
        result = 31 * result + (owner != null ? owner.hashCode() : 0);
        return result;
    }
}
```

测试一下：

```java
public static void main(String args[]) {

    Bicycle bicycle1;
    
    bicycle1 = new Bicycle(10, 20 ,30, "Dong");
    
    // 注意变量名不要一样
    Bicycle bicycle2;
    
    bicycle2 = new Bicycle(10, 20 ,30, "Dong");
    
    System.out.println(bicycle1);
    System.out.println(bicycle2);
    
    System.out.println("这是equals():" + bicycle1.equals(bicycle2));

}
```

```cmd
Bicycle@259664
Bicycle@259664
这是equals():true
```

发现`bicycle1、bicycle2`的内存地址一样了，这是为什么呢？

因为Java的实际底层语言还是C/C++，但是Java隐去指针一概念，记住是隐去了，但还是有的，具体内容应该会在JVM中讲述。

#### toString()

先看看有什么用，如下：

```java
public static void main(String args[]) {

    Bicycle bicycle1;
    
    bicycle1 = new Bicycle(10, 20 ,30, "Dong");
    
    System.out.println(bicycle1.toString());
    System.out.println(bicycle1);

}
```

```cmd
Bicycle@259664
Bicycle@259664
```

所以，`toString()`在默认情况下就是打印了对象的内存地址的哈希值。

但是，在实际开发时，前后端之间要传输对象信息，而传输信息的格式，一般都使用`JSON`格式，如下：

```json
{
  "name": "Alice",
  "age": 30,
  "hobbies": ["reading", "coding"],
  "address": {
    "city": "New York",
    "zip": "10001"
  },
  "isStudent": false,
  "phone": null
}
```

在`Bicycle`中重写`toString()`，如下：

```java
@Override
public String toString() {
    return "Bicycle{" +
        "cadence=" + cadence +
        ", gear=" + gear +
        ", speed=" + speed +
        ", owner='" + owner + '\'' +
        '}';
}
```

测试一下：

```java
public static void main(String args[]) {

    Bicycle bicycle1;
    
    bicycle1 = new Bicycle(10, 20 ,30, "Dong");
    
    System.out.println(bicycle1.toString());
    System.out.println(bicycle1);

}
```

```cmd
Bicycle{cadence=10, gear=30, speed=20, owner='Dong'}
Bicycle{cadence=10, gear=30, speed=20, owner='Dong'}
```

经过以上的测试，发现起始`System.out.println(bicycle1.toString())、 System.out.println(bicycle1)`这两行代码并无区别，这是因为，Java在使用`System.out.println()`，默认调用对象的`toString()`方法。
