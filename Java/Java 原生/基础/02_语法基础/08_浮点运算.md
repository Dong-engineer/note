```java

```

# 块

Java中的块，是机器翻译官方文档过来的，我们叫一般叫做**作用域或域**，这个域和数学中的定义域很像，都是指明了某种范围。在计算机中的域指的是变量的有效范围，我们通常使用`{}`来表示其范围。

如下：

```java
int a = 1;

public boolean testScope() {
        int b = 10;
    System.out.ptintln("a=" + a + " | b=" + b); // 结果为: a=1 | b=10
}
public static void main(String args[]){
    testScope();
    System.out.ptintln("a=" + a); // 结果为：a=1
	// System.out.ptintln("b=" + b); // 这里会报错，会提示没有声明变量b
}
// 以上代码会报错，错误内容如下，小问题，后面讲到类和对象，先理解什么是域。
/* 
test_01.java:48: 错误: 无法从静态上下文中引用非静态 方法 testScope()
        testScope();
        ^
test_01.java:49: 错误: 无法从静态上下文中引用非静态 变量 a
        System.out.println("a=" + a); // 结果为：a=1
*/

// 正确代码如下
static int a = 1;

public static boolean testScope() {
        int b = 10;
    System.out.ptintln("a=" + a + " | b=" + b); // 结果为: a=1 | b=10
}
public static void main(String args[]){
    testScope();
    System.out.ptintln("a=" + a); // 结果为：a=1
	// System.out.ptintln("b=" + b); // 这里会报错，会提示没有声明变量b
}
```

一对`{}`表明一个作用域，在A作用域里面声明一个变量，在B作用域里面是不能用的，如果C作用域包含了A、B作用域，那么在C作用域里面声明的变量，在A、B里面都可以使用。
