# 多态

终于讲到多态了，这也就意味着当前的开发者不再是小白了。

在*引入*部分就介绍了 Java 的语言特性，封装、继承、多态，封装和继承已经学习过，在本节学习多态。

多态是生物学的一个概念或者说原则。即生物体或物种可以具有许多不同的形式或阶段。此原则也可以应用于面向对象的编程和语言，如 Java 语言。类的子类可以定义自己独特的行为，但共享父类的一些相同功能。

继承就是多态的一种体现。

多态是一种思维，在实际开发尤为重要，这能大大降低代码的耦合度。

## final

在继承中讲到了，子类有时候是需要重写父类的方法（字段不可以重写，下面讲），那么当父类和子类以及子类的派生类都统一有一种行为（不是某个类特有的，不要使用 `static`， `static`修饰的是某个类特有的），此时开发者可以将该方法定义为 `final`。

 `final`定义的方法可以被继承，但是不能重写。

如果一个类被声明为`final`，那么该类是不可以被继承的。

如下：

```java
class Parent {
    public final void display() {  // final方法
        System.out.println("Parent's display method");
    }
}

class Child extends Parent {
    // 错误！无法重写final方法
    // public void display() { ... }  // 编译错误
}
```

## 隐藏字段和隐藏静态

这里分开讲述，因为作者本人感觉隐藏静态这一说法没啥用。

### 隐藏字段

在继承一节中学习了，父类的派生类是可以重写父类的方法的（只要不是`final`和`private`、`static`），字段不能被重写，但是当子类里面含有和父类的**类型和名字一样的字段**，那么 Java 会自动隐藏父类字段。在子类对象访问的时候，直接访问子类的字段。

### 隐藏静态

在学习 `static` 关键字的时候，就已经强调了被 `static` 修饰一切是本类特有的，这也就意味着在子类是不能被继承的。重点是本类特有的，所以在上面说可以删去隐藏静态一说，因为**被 `static` 修饰一切是本类特有的**。
