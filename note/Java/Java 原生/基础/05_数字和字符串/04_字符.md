# 字符

在Java中字符用`char`类型表示。

开发者应该都知道计算机中的所有字符都是经过统一的编码标准来进行存储得到，因为计算机只认识0和1。那么这个统一的编码标准就是`Unicode（统一码）`，部分开发者应该还知道`ASCII（美国信息交换标准代码）`。

下面就详细介绍一下。

## ASCII和Unicode

### 1. ASCII（美国信息交换标准代码）

- **诞生时间**：ASCII 于 1963 年问世，是最早被广泛使用的字符编码标准。

- 编码范围：它采用 7 位二进制数对字符进行编码，总共可以表示 128 个字符，具体包括：

  - **控制字符**：从 0 到 31 以及 127（像换行符 `\n`、制表符 `\t` 等）。

  - 可打印字符

    ：从 32 到 126，其中包含：

    - **英文字母**：大写字母 `A-Z`（65 - 90），小写字母 `a-z`（97 - 122）。
    - **数字**：`0-9`（48 - 57）。
    - **标点符号和其他符号**（例如 `!@#$%^&*()` 等）。

- **局限性**：ASCII 仅能表示英语字符，无法对其他语言的字符进行编码。

### 2. Unicode（统一码）

- **诞生目的**：为了对世界上所有语言的字符进行编码，Unicode 应运而生。
- 编码范围：Unicode 目前涵盖了超过 14 万个字符，编码范围从`U+0000` 到 `U+10FFFF`，能够支持包括：
  - **ASCII 字符**：基本拉丁字母（`U+0000` - `U+007F`）。
  - **其他语言的字母**：例如拉丁字母扩展、西里尔字母、希腊字母、汉字（超过 7 万个）、日语假名、韩语 Hangul 等。
  - **特殊符号**：数学符号、货币符号（如 €、¥）、表情符号（Emoji）等。
- **版本更新**：Unicode 会不断更新，以纳入新的字符。截至 2023 年 9 月，Unicode 的版本是 15.0。

### 3. 两者的关系

- **ASCII 是 Unicode 的子集**：Unicode 中的前 128 个字符（`U+0000` - `U+007F`）与 ASCII 完全相同。也就是说，ASCII 字符在 Unicode 中的编码值和在 ASCII 标准里是一样的。

- 编码方式不同：

  - **ASCII**：固定使用 7 位编码，在计算机中通常以 8 位（1 字节）形式存储，最高位为 0。

  - Unicode

    ：只是一个字符集，具体的编码实现有多种，常见的有：

    - **UTF-8**：一种变长编码，ASCII 字符使用 1 字节（与 ASCII 完全相同），其他字符可能占用 2 - 4 字节。
    - **UTF-16**：大多数字符使用 2 字节编码，但有些字符需要 4 字节（代理对）。
    - **UTF-32**：固定使用 4 字节编码每个字符。

- **兼容性**：由于 Unicode 包含 ASCII，所以处理 Unicode 的系统（如采用 UTF-8 编码的系统）能够直接兼容 ASCII 文本。

## Java中的字符

接上文，为了统一全球的符号的编码标准`Unicode`就此诞生，现在，`Unicode`编码仍在更新，同样Java SE 15 支持 Unicode 13.0。

在 Java 里，字符（`char`）属于基本数据类型，其用途是存储单个 Unicode 字符。

### 基本特性

- **占用空间**：`char` 类型在内存中占 16 位（也就是 2 个字节）（因为这是Unicode的原始规范，但是在Unicode 13.0之后，Unicode标准允许表示超过16位字符）。
- **表示范围**：它能够表示的 Unicode 码点范围是 `\u0000`（即十进制的 0）到 `\uFFFF`（也就是十进制的 65535）。
- **默认值**：`char` 类型的默认值为 `\u0000`。

### 声明与初始化

声明字符变量有以下几种常见方式：

```java
char c1 = 'A';          // 直接使用单引号括住单个字符
char c2 = 65;           // 通过十进制 ASCII/Unicode 值来初始化
char c3 = '\u0041';     // 利用 Unicode 转义序列进行初始化
char newline = '\n';    // 存储转义字符
```

### 包装类

`char`对应的包装类`character`，其常用方法已经在*01_包装类*中讲述过。

下面是一些用例：

```java
char c = 'a';
boolean isDigit = Character.isDigit(c);  // 判断字符是否为数字
boolean isLetter = Character.isLetter(c);  // 判断字符是否为字母
boolean isUpperCase = Character.isUpperCase(c);  // 判断字符是否为大写字母
char upper = Character.toUpperCase(c);  // 将字符转换为大写
```

## 转义序列

所谓的转义序列，其实也就是转义字符`\`)（反斜杠）。

| 转义序列 | 描述                           |
| -------- | ------------------------------ |
| `\t`     | 此时，在文本中插入一个制表符。 |
| `\b`     | 此时在文本中插入退格键。       |
| `\n`     | 此时在文本中插入换行符。       |
| `\r`     | 此时，在文本中插入回车。       |
| `\f`     | 此时，在文本中插入表单提要。   |
| `\'`     | 此时，在文本中插入单引号字符。 |
| `\"`     | 此时，在文本中插入双引号字符。 |
| `\\`     | 此时，在文本中插入反斜杠字符。 |

在集成开发环境IDE中，有些符号表示特殊意义，如：`""`，当开发者需要打印输出这个符号时需要加上转义字符`\`。
