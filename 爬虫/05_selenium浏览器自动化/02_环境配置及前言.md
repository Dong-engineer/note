# 环境配置

在使用 `selenium` 进行爬虫前，开发者需要先配置一下开发环境。

开发者先选择一款浏览器，然后去其官网上下载对应版本的浏览器驱动。

开发者还需要安装 `selenium` 类库才可以进行真正开发。

```cmd
pip install selenium
```

后面的内容均以 `selenium` 4.38+ 版本为主。

# 前言

`selenium` 的创作者们的初衷是用户网站测试，但随着版本的更新 `selenium` 逐渐变成了用户与浏览器之间的代理库。用户可以通过 `selenium` 对浏览器的网页进行控制。除此之外 `selenium` 还具备远程操控的功能，这是因为在 Web 端进行测试很有可能需要进行多台计算机并行操作。

在 `selenium` 官方的原文档是这样说的，如下：

> Selenium 的极简设计方法使其具有通用性，可以作为更大应用程序中的组件。 Selenium 保护伞下提供的周边基础设施为您提供了组合自己的 [浏览器 grid](https://www.selenium.dev/zh-cn/documentation/grid/) 的工具， 因此测试就可以跨一系列机器在不同的浏览器和多个操作系统上运行。
>
> 想象一下， 服务器机房或数据中心的一组计算机同时启动浏览器，访问站点的链接、表单和表格 — 全天 24 小时测试应用程序。 通过为最常见的语言提供的简单编程接口， 这些测试将不知疲倦地并行运行， 当错误发生时向您报告。
>
> 通过为用户提供工具和文档， 不仅可以控制浏览器， 还可以方便地扩展和部署这些grid， 从而帮助您实现这一目标。
