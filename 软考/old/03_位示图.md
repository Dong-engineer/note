# 位示图

位示图（bitmap）是一种用于管理文件系统中存储块使用情况的数据结构 ，以比特位为单位进行存储和管理 。其基本原理是用一个位数组来表示存储块的使用情况 ，每个位对应一个存储块：

- **状态标识**：若该位为 0 ，表示对应的存储块未被使用 、处于空闲状态 ；若该位为 1 ，则表示对应的存储块已被使用 、处于占用状态 。例如在管理磁盘空间时 ，可通过位示图知晓每个磁盘块是否被占用 。
- **应用场景**：常用于操作系统对磁盘空间的分配与回收管理 。当用户请求创建文件或目录时 ，操作系统查找位示图找到空闲块进行分配 ；当用户删除文件或目录时 ，对应磁盘块被标记为空闲并更新位示图 。还在索引 、数据压缩 、图像处理（表示像素颜色和透明度等 ）等方面有广泛应用 。
- **优点**：易于实现和处理 ，尤其是像素级图像处理算法 ；能直观表示图像像素 ；对于二值图像 ，存储时非常节省内存空间 ；可高效管理磁盘空间 ，查找空闲块简单高效 。
- **缺点**：对于灰度或真彩色图像 ，需存储大量数据 ，占用内存空间大 ；图像缩放 、旋转等操作易出现锯齿边缘 ，影响质量 ；不能无损压缩 ，频繁编辑会快速占用大量磁盘空间 。

## 例题：

某字长为32位的计算机的文件管理系统采用位示图(bitmap)记录磁盘的使用情况。若磁盘的容量为300GB,物理块的大小为1MB,那么位示图的大小为（）个字。

解析：

首先把磁盘容量换算成MB：300 * 1024 = 307200MB

其次计算需要多少个物理块：307200MB / 1MB = 307200个

然后计算位示图需要的位数（位示图中，每一位对应一个物理块的使用状态（0表示空闲，1表示已占用 ））：307200 / 1 = 307200位

最后计算字的个数，一共是307200位，每个字占32位，则：307200 / 32 = 9600
