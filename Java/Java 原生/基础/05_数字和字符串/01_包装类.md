# 数字

关于数字，开发者肯定都不陌生，声明一个数字也不在话下，小数亦是如此。在 Java 的刚开始学习中，学习过了基元数据类型，八大基元数据类型：`byte、short、int、long、float、double、char、boolean`。

他们的使用如下：

```java
int i = 500;
float gpa = 3.65f;
byte mask = 0x7f;
```

这是开发者常使用的方式，但是在开发时要牢记面向对象来进行开发，为此 Java 提供了八大基本数据的包装类型，如下：

| 基本数据类型 | 包装类（对象类型）                                           |
| ------------ | ------------------------------------------------------------ |
| byte         | Byte                                                         |
| short        | xxxxxxxxxx Integer a = 10; // 装箱int b = a; // 拆箱（等价于 int b = a.intValue();）java |
| int          | Integer                                                      |
| long         | Long                                                         |
| float        | Float                                                        |
| double       | Double                                                       |
| char         | Character                                                    |
| boolean      | Boolean                                                      |

## Number

**以上包装类型全部继承`Number`类**，除此之外，`Nubmer`类还有`BigDecimal` 和 `BigInteger`用于高精度计算。`AtomicInteger` *和* `AtomicLong` 用于多线程应用程序。

## 为什么使用包装类？

其实在刚开始敲代码时，可能会有疑问：基元数据类型够用为什么还要使用包装类呢？

如下：

1. 作为需要对象的方法的参数（通常在作数字集合时使用）。
2. 使用由类定义的常量，例如 `MIN_VALUE` 和 `MAX_VALUE`，这些常量提供数据类型的上限和下限。
3. 使用类方法将值与其他基元类型相互转换，与字符串相互转换，以及在数字系统（十进制、八进制、十六进制、二进制）之间进行转换。
4. **面向对象开发**

## 怎么使用包装类？

### **Byte 类**

| 方法                               | 描述                                                         | 示例代码                                                     |
| ---------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `byte byteValue()`                 | 返回 `Byte` 对象的基本 `byte` 值。                           | `Byte b = 10; byte primitive = b.byteValue(); // 10`         |
| `static byte parseByte(String s)`  | 将字符串解析为 `byte`，要求字符串表示的数值在 `byte` 范围内（-128~127）。 | `byte num = Byte.parseByte("127"); // 127`                   |
| `static Byte valueOf(String s)`    | 返回表示指定 `String` 的 `Byte` 实例，等效于 `Byte.valueOf(Byte.parseByte(s))`。 | `Byte b = Byte.valueOf("100"); // 包装为 Byte 对象`          |
| `int compareTo(Byte anotherByte)`  | 按数值比较两个 `Byte` 对象，返回 `-1/0/1`。                  | `Byte a = 5; Byte b = 10; System.out.println(a.compareTo(b)); // -1` |
| `static String toString(byte b)`   | 返回表示指定 `byte` 的 `String`。                            | `String s = Byte.toString(5); // "5"`                        |
| `static int toUnsignedInt(byte x)` | 将 `byte` 转换为无符号 `int`（通过零扩展）。                 | `byte b = -1; int unsigned = Byte.toUnsignedInt(b); // 255`  |
