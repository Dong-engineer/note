# 常用注解

## Java 原生内置常用注解

```java
@Override       // 检查方法是否正确覆盖父类方法
@Deprecated    // 标记方法或类已过时
@SuppressWarnings  // 抑制编译器警告
@FunctionalInterface  // 声明函数式接口
```

`@Override` 在重写一节已经接触过了。

`@SuppressWarnings` 在泛型一章节也有接触，可以使用其抑制 `Unchecked Warning` 。

`@FunctionalInterface` 函数式接口很少使用，可以自行去搜索用法。

`@Deprecated` 用来标记方法或类是否已过时，很简单。

## 元注解

### 元注解

元注解是 Java 提供给开发者去修饰自定义注解的。

### 常用元注解及其作用

1. **@Retention**：指定注解的保留策略，即注解在什么级别保存。
   - **RetentionPolicy.SOURCE**：注解仅存在于源代码中，编译时会被编译器丢弃。
   - **RetentionPolicy.CLASS**：注解在编译时由编译器保留，但 Java 虚拟机 (JVM) 运行时不保留。这是默认值。
   - **RetentionPolicy.RUNTIME**：注解在运行时由 JVM 保留，因此可以通过反射机制读取注解信息。
2. **@Target**：指定注解可以应用的目标元素类型，如类、方法、字段等。
   - **ElementType.TYPE**：可以应用于类、接口、枚举等类型。
   - **ElementType.FIELD**：可以应用于字段 (类成员变量)。
   - **ElementType.METHOD**：可以应用于方法。
   - **ElementType.PARAMETER**：可以应用于方法参数。
   - **ElementType.CONSTRUCTOR**：可以应用于构造函数。
   - **ElementType.LOCAL_VARIABLE**：可以应用于局部变量。
   - **ElementType.ANNOTATION_TYPE**：可以应用于注解类型。
   - **ElementType.PACKAGE**：可以应用于包声明。
   - **ElementType.TYPE_PARAMETER**：可以应用于类型参数 (Java 8+)。
   - **ElementType.TYPE_USE**：可以应用于任何类型使用的地方 (Java 8+)。
3. **@Documented**：指示注解应该被包含在 Java 文档中。如果一个注解被 @Documented 修饰，那么使用这个注解的元素的文档会包含该注解的信息。
4. **@Inherited**：指示注解是可继承的。如果一个使用了 @Inherited 修饰的注解类型被用于一个类，则这个注解将被该类的所有子类继承。
5. **@Repeatable**：指示注解可以在同一元素上重复使用 (Java 8+)。要使用 @Repeatable，需要定义一个容器注解，它包含一个被注解类型的数组。

### 元注解的使用示例

下面是一个使用元注解定义自定义注解的示例：

```java
import java.lang.annotation.*;

// 定义一个自定义注解@MyAnnotation
@Retention(RetentionPolicy.RUNTIME)  // 注解在运行时保留
@Target(ElementType.TYPE)            // 注解可以应用于类、接口等类型
@Documented                          // 注解会包含在Java文档中
@Inherited                           // 注解可被继承
public @interface MyAnnotation {
    String value() default "";       // 定义一个名为value的成员，默认值为空字符串
    int count() default 1;           // 定义一个名为count的成员，默认值为1
}

// 使用自定义注解
@MyAnnotation(value = "Test", count = 3)
public class MyClass {
    // 类的内容
}

// 继承自MyClass的子类会继承@MyAnnotation注解
public class MySubClass extends MyClass {
    // 子类的内容
}
```
