- SSL协议：
  
  - SSL（Secure Sockets Layer，安全套接字协议 ）是为网络通信提供安全及数据完整性的安全协议，其继任者是传输层安全（TLS）协议 。由于历史原因，人们仍常用 “SSL” 指代 TLS 。
  - **加密**：运用公钥密码学构建安全通信隧道。客户端与服务器交换公钥并生成会话密钥，协商加密算法后，用对称加密算法加密通信数据，防止数据传输时被窃取 。比如，用户在电商网站输入支付信息时，SSL 协议加密这些信息，让第三方即便截获也无法解读。
  - **认证**：借助数字证书验证服务器身份。数字证书含服务器信息，由可信任的证书颁发机构（CA）签名。以访问银行官网为例，通过验证证书，能确认是与真实银行服务器通信，避免连接到钓鱼网站 。
  - **数据完整性保护**：利用消息摘要算法计算数据散列值并附加到数据中。接收方通过验证散列值，可判断数据在传输中是否被篡改 。

  - port是主机的端口号
  - path是文件路径

- 数字签名：
  - 数字签名（又称公钥数字签名 ），是只有信息发送者才能产生、他人无法伪造的一段数字串，也是对信息发送者发送信息真实性的有效证明 ，类似纸上物理签名，但基于公钥加密技术实现，用于鉴别数字信息。
  - 原理：
    - **非对称密钥加密**：使用一对互补的密钥，即公钥和私钥 。私钥由用户秘密持有，公钥可公开。发送方用私钥对数据加密形成数字签名，接收方用对应的公钥解密。因私钥唯一性，能确定数据来源。
    - **数字摘要**：运用哈希函数将任意长度数据转换为固定长度摘要 。发送方先对原文生成摘要，再用私钥加密摘要得数字签名。接收方收到后，对原文生成新摘要，解密签名得发送方摘要，对比二者判断数据完整性。

- 回环地址

  范围是 127.0.0.0 - 127.255.255.255 ，最常用的是 127.0.0.1 ，也叫 localhost 。用于将网络数据包发回源设备，测试网络适配器或本地主机连通性 ，本地运行服务器软件时可借此访问，无需经实际网络 。

- 私有地址

  在内部网络使用，不可在公共互联网直接用 。

  - **A 类**：10.0.0.0 - 10.255.255.255
  - **B 类**：172.16.0.0 - 172.31.255.255
  - **C 类**：192.168.0.0 - 192.168.255.255 ，常见于家庭、企业内网和局域网 。

- 零配置地址（自动配置 IP 地址 ）

  - 一般是 169.254.x.x 形式 ，x.x 随机生成 。当设备无法从 DHCP 服务器获取有效 IP 地址时，会用它连接局域网，进行基本通信 。

- 广播地址

  - **直接广播地址**：主机 ID 各位全为 1 ，用于向指定网络所有主机发送数据 ，如 A 类网络的网络 ID.255.255.255 。
  - **受限广播地址**：32 位全为 1 ，即 255.255.255.255 ，用于本网段内广播 ，路由器不会转发该地址的数据包 。

- 多播地址

  - 范围从 224.0.0.0 - 239.255.255.255 ，如 224.0.0.1 指所有主机 ，224.0.0.2 指所有路由器 ，用于向多播组内设备发送数据包 。

- 0.0.0.0

  - 在刷题时，给出的解释是 0.0.0.0 指的本机，即源地址，但是我去搜索资料发现 0.0.0.0 并不能完全表示以上的意义。即0.0.0.0 并不完全等同于本机。下面才是他严格的意义。
  - 表示所有不清楚的主机和目的网络 ，在本机路由表无特定条目指明如何到达时使用 。若设置了缺省网关，系统会自动产生目的地址为 0.0.0.0 的缺省路由 。也可在网络编程中绑定到所有可用接口监听连接 。

- 域名结构：

  - 三级域名.二级域名.顶级域名

  - 但是有些网站可能是符合域名的，如下：

    以 `news.ifeng.com.cn` 为例，从右到左拆解：

    - 顶级域名（ccTLD）：.cn（中国）   二级域名：ifeng.com（凤凰网的主域名，其中 `ifeng` 是二级域名主体，`.com` 是通用顶级域名，组合为二级域名）   三级域名：news（表示凤凰网的新闻板块）  

- 顶级域名：

  - 域名中最右边的部分，是域名的最高层级，用于标识域名的类型、所属行业或国家 / 地区。

  - **通用顶级域名（gTLD）**

    常见类型：

    - `.com`（商业机构，最常用）
    - `.org`（非营利组织）
    - `.net`（网络服务提供商）
    - `.edu`（教育机构，仅限美国）
    - `.gov`（政府机构，仅限美国）
    - `.int`（国际组织）
    - `.info`（信息类网站）
    - `.biz`（商业）
    - `.name`（个人域名）
    - **特点**：面向全球开放注册，无地域限制。

  - **国家和地区顶级域名（ccTLD）**

    常见类型：

    - `.cn`（中国）
    - `.us`（美国）
    - `.uk`（英国）
    - `.jp`（日本）
    - `.de`（德国）
    - `.hk`（中国香港）
    - `.tw`（中国台湾，需符合中国法律规定）

    - **特点**：标识域名所属的国家或地区，部分 ccTLD 对注册者国籍或机构性质有限制。

  - **新通用顶级域名（New gTLD, nTLD）**

    常见类型：

    - `.app`（应用程序）
    - `.shop`（电商网站）
    - `.tech`（科技领域）
    - `.blog`（博客）
    - `.online`（在线服务）

    - **特点**：2013 年后新增，覆盖更细分的行业或场景，注册限制较少。

- 二级域名：
  - 顶级域名左侧的部分，是域名的核心标识，用于区分同一顶级域名下的不同主体（企业、组织或个人）。
  - **示例**：在 `baidu.com` 中，`baidu` 是二级域名，`.com` 是顶级域名。
  - 特点：
    - 由用户自行注册和管理（需遵守域名注册规则）。
    - 是域名中最具辨识度的部分，通常用于品牌、机构名称或业务标识。
- 三级域名：
  - 二级域名左侧的部分，可根据需要无限扩展层级，用于进一步细分业务或功能。
  - 示例：
    - `mail.qq.com` 中，`mail` 是三级域名，`qq` 是二级域名，`.com` 是顶级域名（表示腾讯的邮件服务）。
    - `blog.csdn.net` 中，`blog` 是三级域名，`csdn` 是二级域名，`.net` 是顶级域名（表示 CSDN 的博客板块）。
  - 特点：
    - 非必须层级，可按需添加（如四级域名、五级域名等）。
    - 常用于标识子业务、功能模块或地域分支（如 `us.amazon.com` 表示亚马逊美国站）。

- 域名和IP地址的关系：
  - 本质：是 IP 地址的 “助记符”，用于替代复杂的数字 IP 地址（如 `192.168.1.1`），方便用户记忆和访问。
  - **解析过程**：通过 **域名系统（DNS）** 将域名解析为对应的 IP 地址，实现网络通信。
