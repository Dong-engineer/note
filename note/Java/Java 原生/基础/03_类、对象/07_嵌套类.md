# 嵌套类

Java 编程语言允许您在另一个类中定义一个类。此类称为嵌套类，如下所示：

```java
class OuterClass {
    ...
    class NestedClass {
        ...
    }
}
```

嵌套类主要分两大类：

非静态类和静态类。**非静态类又称为内部类，静态类被称为静态嵌套类**。

```java
class OuterClass {
    ...
    class InnerClass {
        ...
    }
    static class StaticNestedClass {
        ...
    }
}
```

### 1. 非静态嵌套类（内部类）

- **访问权限**：可以直接访问封闭类的所有成员（包括私有成员，`private`），无论这些成员是否静态。

- **实例依赖**：内部类的实例必须依赖于封闭类的实例存在，即需要先创建封闭类对象，才能创建内部类对象。

- **示例**：

  ```java
  public class OuterClass {
      private int outerField = 10;
      private static int staticOuterField = 20;
      
      // 内部类
      public class InnerClass {
          public void accessOuter() {
              // 可以访问封闭类的非静态和静态成员
              System.out.println(outerField); // 10
              System.out.println(staticOuterField); // 20
          }
      }
  }
  ```

  ​	

### 2. 静态嵌套类（静态内部类）

- **访问权限**：只能访问封闭类的**静态成员**（包括静态字段和静态方法），无法访问非静态成员（因为非静态成员依赖实例，而静态嵌套类不依赖）。

- **实例独立**：静态嵌套类的实例不依赖封闭类的实例，可直接创建（通过 `OuterClass.StaticNestedClass` 形式）。

- **示例**：

  ```java
  public class OuterClass {
      private int outerField = 10; // 非静态成员
      private static int staticOuterField = 20; // 静态成员
      
      // 静态嵌套类
      public static class StaticNestedClass {
          public void accessOuter() {
              // 只能访问静态成员
              System.out.println(staticOuterField); // 20
              // System.out.println(outerField); // 编译错误：无法访问非静态成员
          }
      }
  }
  ```

### 3.创建内部类对象

之前学习了如何创建类的最想，现在学习创建内部类对象。

首先，我们要明白内部类是处于**某一外部类的域中**，这也就意味，想要创建内部类对象需要通过外部类来进行创建。

如下：

```java
public class OuterClass {

    String outerField = "Outer field";
    static String staticOuterField = "Static outer field";

    class InnerClass {
        void accessMembers() {
            System.out.println(outerField);
            System.out.println(staticOuterField);
        }
    }
    
    static class StaticNestedClass {
        void accessMembers(OuterClass outer) {
            // Compiler error: Cannot make a static reference to the non-static
            //     field outerField
            // System.out.println(outerField);
            System.out.println(outer.outerField);
            System.out.println(staticOuterField);
        }
    }
    
    public static void main(String[] args) {
        
        System.out.println("Inner class:");
        System.out.println("------------");
        
        OuterClass outerObject = new OuterClass();
        OuterClass.InnerClass innerObject = outerObject.new InnerClass();
        
        innerObject.accessMembers();
    }
}
```

其次，上节学习了`static`关键字，所以了解到，被`static`关键字修饰的内部类，**不能直接访问外部类的非静态成员变量和函数**，同时，`static`所修饰的变量、函数等等会随着本类的加载而加载。

所以以上代码，当`OuterClass`被加载时，`static class StaticNestedClass`同样也被加载，但是Java给了一个机制`static`所修饰的类可以当作顶级类使用。

> 因为当我们访问`OuterClass`类的静态内部类时，`OuterClass`会自动被创建（在*07_类的生命周中有讲述*），所以我们直接正常创建对象即可。

```java
public static void main(String[] args) {

    System.out.println("\nStatic nested class:");
    System.out.println("--------------------");
    StaticNestedClass staticNestedObject = new StaticNestedClass(); // 这会自动加载OuterClass
    staticNestedObject.accessMembers(outerObject);

}
```



### 4.shadowing（阴影）

如果内部类声明了一个和外部类**变量名一样**的变量，则该声明将隐藏封闭范围。

> 此部分内容不仅仅适用于嵌套类，对于其他语言，当有变量和如下情况一样，会将隐藏封闭范围。

如下：

```java
public class ShadowTest {

    public int x = 0;
    
    class FirstLevel {
    
        public int x = 1;
    
        void methodInFirstLevel(int x) {
            System.out.println("x = " + x);
            System.out.println("this.x = " + this.x);
            System.out.println("ShadowTest.this.x = " + ShadowTest.this.x);
        }
    }
    
    public static void main(String... args) {
        ShadowTest st = new ShadowTest();
        ShadowTest.FirstLevel fl = st.new FirstLevel();
        fl.methodInFirstLevel(23);
    }

}
```

所以，当想要访问外部类或者上一层级的域中变量时，应当 `this.x`、 `ShadowTest.this.x` 如此做。
