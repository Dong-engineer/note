### 文档类

- **.doc / .docx**： Microsoft Word 文档格式，用于保存文本、图片、表格等内容 ，可用于撰写文章、报告等，docx 是 Word 2007 及之后版本默认格式，相比 doc 在结构等方面有优化。
- **.xls / .xlsx**： Microsoft Excel 电子表格格式，用于存储表格数据和计算公式，适用于制作数据统计表、财务报表等，xlsx 是 Excel 2007 起的新格式，基于 XML ，存储效率更高。
- **.ppt / .pptx**： Microsoft PowerPoint 幻灯片格式，用于制作演示文稿和投影片，适用于会议展示、教学演示等场合 ，pptx 是较新格式，在兼容性、文件大小等方面有改进。
- **.pdf**： Portable Document Format（便携式文档格式），可跨平台打开和查看，常用于电子书、合同、报表等的保存和传输，能保证精确的颜色和准确的打印效果。
- **.txt**：纯文本格式，由微软在操作系统附带，主要存储文字信息，可被大多数文本编辑器和软件查看。

### 图像类

- **.jpg / .jpeg**： Joint Photographic Experts Group（联合图像专家小组）格式，压缩率较高，能保留较高图像质量，广泛用于存储照片和图像。
- **.png**： Portable Network Graphics（便携式网络图形）格式，支持透明背景，在网络图片展示和传输中应用广泛。
- **.gif**： Graphics Interchange Format（图形交换格式），支持动画效果，文件体积相对较小，常用于网页小动画、图标等。
- **.bmp**： Bitmap（位图）格式，无损压缩，能完整保留图像原始信息，文件相对较大，常用于图像处理和存档。
- **.svg**： Scalable Vector Graphics（可缩放矢量图形）格式，基于 XML，支持无损缩放和编辑，适用于图标、Logo 等矢量图形设计。

### 音频类

- **.mp3**：MPEG Audio Layer 3 格式，是常见的有损压缩音频格式，压缩率高，文件体积小，在网络音乐、音频存储等方面应用广泛。
- **.wav**： Waveform Audio File Format（波形音频文件格式），利用该格式记录的声音文件能够和原声基本一致，质量非常高，但文件较大。
- **.aac**： Advanced Audio Coding（高级音频编码）格式，是一种高压缩比、高音质的音频格式，常用于苹果设备及一些在线音乐服务。
- 还有一些其他的音频格式：WAVE、SOUND、VOICE、MOD、MP3、RealAudio、CDAudio、MIDI。

### 视频类

- **.mp4**：一种常见的多媒体容器格式，支持多种视频、音频编码，兼容性好，在网络视频、移动设备视频播放等场景广泛应用。
- **.avi**： Audio Video Interleaved（音频视频交错）格式，是较早期且常用的视频格式，支持多种编码方式，兼容性较好。
- **.mov**： Apple 公司开发的视频格式，常用于苹果设备，也可在 Windows 系统通过相关软件播放，支持高质量视频存储。

### 压缩类

- **.zip**：一种常见的压缩文件格式，可将多个文件或文件夹打包成一个文件，便于存储和传输，支持跨平台解压。
- **.rar**：一种专利文件格式的压缩包，由 WinRAR 软件创建和管理，压缩率较高，常用于数据压缩和归档打包。

### 可执行类

- **.exe**： Windows 操作系统下的可执行文件格式，双击此类文件可安装软件或运行程序。
