# 计算机组成原理

## 计算机元器件

正式学习计算组成原理前，先认识一下计算机的各个元器件。

### 冯诺依曼五大部件

1. 运算器：ALU + 通用寄存器，通常情况下可将 ALU 直接默认为运算器。
2. 控制器：CU + 专用寄存器 PC、IR、MAR、MDR，通常情况下可将 CU 直接默认为控制器。
3. 存储器：内存（主存）
4. 输入设备：键盘、鼠标等等，将外界信号转为二进制送入内存的设备
5. 输出设备：显示器等等，可接收并解析二进制数据的设备

补充：**总线，总线通常分为 3 种，地址总线、数据总线、控制总线**。

#### 运算器

上述到，运算器 = ALU + 通用寄存器。这里先不讲述寄存器，读者可认为**运算器 = ALU**。

**ALU：由加法器、多路选择器等组合逻辑电路构成，负责加减与或运算。配套通用寄存器堆存放运算数据**。

**ACC：累加器，累加器不是加法器，加法器只负责运算不存储数据，累加器负责存储数据不进行运算，ACC 是寄存器（属于通用寄存器）**。

注1：读者要注意计算机中是没有减法器的，也没有乘法器等等，只有加法器，而计算机所体现出的数学运算是通过复用加法器实现的，在现在计算机中的乘法器其本质也是通过加法器的阵列实现的。（了解即可）

注2：早期的 CPU ，当程序进行累加操作时， ACC 将暂存的值 x 和内存中的目标值 y 一同送入至 ALU 中进行运算，计算结果再次返回到 ACC 中，但现代 CPU 已经不再强制依赖 ACC 。

#### 控制器

控制器 = CU + 专用寄存器。同样地，读者可认为**控制器 = CU**。

**CU：由时序电路、译码器构成**。（了解即可）

#### 专用寄存器

寄存器就有很多了，如：PC、IR、MAR、MDR 等等。

这里主要介绍 PC、IR、MAR、MDR（这四个是 **CPU 的四大专用寄存器**），这是最主要最常见的。

##### PC

**Program Counter，程序计数器：存储下一条将要执行的指令的内存地址。**

正常顺序：CPU 每取出一条指令，PC 自动自增，指向内存中下一条指令。如果遇见（if 判断跳转）：CU 会直接修改 PC 的值，程序会跳转至新的地址。

##### IR

**Instruction Register，指令寄存器：当前正在执行的指令本身**。

IR 存储的指令本身，即指令的内容，并非地址。

##### MAR

**Memory Address Register，存储器数据寄存器：CPU 和内存之间传输的数据 / 指令，数据中转站连接数据总线**。

1. CPU 想要读写内存，必须先把内存地址放到 MAR。
2. MAR 的输出直接连到地址总线，发给内存芯片。内存收到 MAR 送来的地址，知道要读写哪一个存储单元。
3. MAR 只存地址，不存数据。

##### MDR

**Memory Data Register，存储：CPU 和内存之间传输的数据 / 指令，数据中转站连接数据总线**。

1. 读内存：内存把数据读出来，放到 MDR，CPU 再从 MDR 拿走数据；
2. 写内存：CPU 要写入的数据，先放到 MDR，再通过数据总线写入内存。

#### 取指令的完整流水线

CPU 取下一条指令执行，流程如下：

1. PC 保存下一条指令的内存地址，把地址送入 MAR
2. MAR 将地址通过地址总线发送给主存
3. 主存根据地址，读出对应二进制指令，送到 MDR
4. MDR 把这条指令送到 IR（IR 保存当前要执行的指令）
5. PC 自动 + 1，更新为下一条指令的地址，为下一轮取指做准备
6. CU 控制器解析 IR 里面的指令，发出控制信号，执行指令（可能还要再次访问内存，再次使用 MAR、MDR）
