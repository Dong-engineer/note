- **CRC码**
  - **定义**：循环冗余校验码，是一种常用的差错检测编码。
  - CRC 码是基于模 2 运算建立的编码方法。发送端将待发送的数据比特序列除以一个预先选定的生成多项式，得到的余数作为校验码附加在数据后面一起发送。接收端用同样的生成多项式去除接收到的数据，如果余数为零，则认为数据传输正确；否则，表示数据在传输过程中出现了差错。
- **海明码**

  - **定义**：海明码是一种可以纠正一位差错的编码，是由贝尔实验室的 Richard Hamming 设计的，因此而得名。
  - **原理**：它通过在数据位中插入一些校验位，来实现对数据的检错和纠错。其基本思想是将数据的每一位分配到多个校验位中，使得当某一位数据发生错误时，会影响到多个校验位的值，通过对这些校验位的检查和分析，就可以确定出错的位置并进行纠正。
  - **应用场景**：常用于计算机内存、数据传输等领域，以提高数据的可靠性和准确性，确保数据在存储和传输过程中不出现错误或能够及时纠正错误。
- **BCD 码**

  - **定义**：BCD 码（Binary-Coded Decimal）是一种用二进制编码表示十进制数的编码方式，也称为二 - 十进制编码。
  - **原理**：它用 4 位二进制数来表示 1 位十进制数，从 0000 到 1001 分别表示十进制的 0 到 9，而 1010 到 1111 这 6 种组合在 BCD 码中是无效的。例如，十进制数 37 用 BCD 码表示就是 0011 0111。
  - **应用场景**：在计算机的输入输出设备中经常使用，如键盘输入、打印机输出等，因为它可以方便地将十进制数转换为计算机能够处理的二进制数，同时也便于人们直观地理解和使用十进制数。在一些需要进行十进制运算的场合，如财务计算、数据统计等，BCD 码也有广泛的应用。

- C 语言编写的程序在计算机上运行，需要对其源程序进行：预处理 > 编译 > 链接

**预处理阶段**

预处理是在正式编译之前由预处理器对源文件进行的处理。预处理器会根据源文件中的预处理指令，对源文件进行文本替换、宏展开、文件包含等操作。具体工作如下：

- **宏替换**：将源文件中定义的宏进行展开。例如，若定义了`#define PI 3.14159`，那么在源文件中所有出现`PI`的地方都会被替换为`3.14159`。
- **文件包含**：处理`#include`指令，将指定的头文件内容插入到源文件中。例如，`#include <stdio.h>`会将标准输入输出头文件的内容插入到当前源文件中。
- **条件编译**：根据`#ifdef`、`#ifndef`、`#if`等条件编译指令，决定哪些代码块会被保留，哪些会被忽略。这在跨平台编程时非常有用，可以根据不同的操作系统或编译器选择不同的代码实现。

**编译阶段**

编译阶段是将经过预处理的源文件转换为汇编代码的过程。编译器会对源文件进行词法分析、语法分析、语义分析、代码优化等操作，最终生成与目标机器相关的汇编代码。具体工作如下：

- **词法分析**：将源文件的字符流转换为词法单元（Token）序列。例如，将`int a = 10;`分解为`int`、`a`、`=`、`10`、`;`等词法单元。
- **语法分析**：根据词法单元序列构建语法树，检查代码是否符合 C 语言的语法规则。如果代码存在语法错误，编译器会报错。
- **语义分析**：对语法树进行语义检查，例如检查变量是否被正确声明、类型是否匹配等。
- **代码优化**：对代码进行优化，以提高程序的执行效率。例如，常量折叠、死代码消除等。
- **生成汇编代码**：根据优化后的中间代码生成目标机器的汇编代码。

注：在编译阶段通过**词法分析、语法分析**可以发现**全部语法错误**，通过**语义分析**可以分析部分语义错误。

**链接阶段**

链接阶段是将编译生成的多个目标文件和所需的库文件组合成一个可执行文件的过程。链接器会处理符号引用、地址分配等问题，确保程序能够正确运行。具体工作如下：

- **符号解析**：将目标文件中未定义的符号（如函数调用、全局变量引用等）与其他目标文件或库文件中定义的符号进行匹配。
- **地址分配**：为每个目标文件中的代码和数据分配内存地址。
- **重定位**：根据分配的内存地址，修改目标文件中的指令和数据，使其能够正确访问其他模块中的符号。
- **生成可执行文件**：将所有目标文件和库文件组合成一个可执行文件。

**磁盘与虚拟存储器**

磁盘不是虚拟存储器，但虚拟存储器通常要借助磁盘来实现。以下是具体解释：

- **磁盘**：是一种计算机外部存储设备，用于长期、大量地存储数据和程序。它以磁性介质为基础，通过磁头对磁盘表面进行读写操作，能永久保存数据，即使计算机断电，数据也不会丢失。
- **虚拟存储器**：是一种计算机系统的存储管理技术。它通过将一部分硬盘空间模拟成内存来使用，使得系统可利用的 “内存” 空间看似大于实际的物理内存。虚拟存储器的实现依赖于磁盘，当物理内存不足时，系统会把暂时不用的数据从内存转移到磁盘上的虚拟内存空间，需要时再从磁盘调回内存。

所以，磁盘只是虚拟存储器实现过程中用于扩展内存的存储介质，本身并不等同于虚拟存储器。

**并发进程与资源共享**

- **并发进程**：在多道程序设计环境下，系统中同时存在着多个进程，这些进程在宏观上是同时运行的，即都在向前推进，并非一个进程完全结束后另一个进程才开始。例如，在计算机系统中，一边进行视频播放（对应视频播放进程），一边进行文档编辑（对应文档编辑进程） ，这两个进程就是并发进程。
- **资源共享**：系统中的资源（如 CPU、内存、磁盘空间、打印机等）可供多个并发进程使用。但由于资源数量有限，多个进程可能会竞争同一资源。比如多个进程都需要使用打印机进行打印任务，就会产生对打印机资源的竞争，需要合理的机制来协调，避免冲突和死锁等问题。

**PV 操作与信号量机制**

- **信号量**：信号量是一个整型变量，它被用于控制多个进程对共享资源的访问。信号量分为两种：
  - **互斥信号量**：其初值通常为 1 ，用于实现进程间的互斥，即保证同一时刻只有一个进程能访问临界资源（一次仅允许一个进程使用的资源）。例如，多个进程要访问一个共享变量，使用互斥信号量来确保在某一时刻只有一个进程能对该共享变量进行读写操作。
  - **资源信号量**：初值为系统中某类资源的可用数量。比如系统中有 3 台打印机，那么对应打印机资源的信号量初值就设为 3 。
- **P 操作**：P 操作也叫 wait 操作，是申请资源的操作。具体执行过程是：先将信号量 S 的值减 1 ，即 S = S - 1 ；然后检查 S 的值，如果 S ≥ 0 ，说明有可用资源，该进程可以继续执行；如果 S < 0 ，表示资源已分配完，该进程会被阻塞，进入与该信号量相关的等待队列，等待其他进程释放资源。
- **V 操作**：V 操作也叫 signal 操作，是释放资源的操作。执行时将信号量 S 的值加 1 ，即 S = S + 1 ；接着检查 S 的值，如果 S > 0 ，说明没有进程在等待该资源，操作结束；如果 S ≤ 0 ，表示有进程在等待该资源，此时就从等待队列中唤醒一个进程，让其获得资源继续执行。

**信号量取值范围分析**

- 以资源信号量为例，假设系统中有 m 个资源，有 n 个进程竞争该资源。信号量的最大值就是资源的初始数量 m ，因为一开始资源还未被分配。
- 当所有资源都被分配出去，且还有进程在等待资源时，信号量会达到最小值。最小值为 m - n 。比如有 5 个资源，10 个进程竞争，当 5 个资源都分配出去后，还有 5 个进程在等待，此时信号量的值为 5 - 10 = - 5 。通过分析信号量的取值范围，可以判断系统中资源的分配情况以及进程的等待状态等。

**磁盘调度算法、磁盘扫描算法、移臂调度算法**

**应用场景**：都应用于计算机磁盘管理领域 。磁盘调度算法是广义概念，用于决定磁盘读写请求的处理顺序，以提升磁盘 I/O 性能；磁盘扫描算法是其中一类具体算法；移臂调度算法因磁盘读写数据时需移动磁头臂，通过调度磁头臂移动顺序优化磁盘访问，本质也是磁盘调度算法 。

**具体调度方式**：

- **磁盘调度算法**：包含多种，如先来先服务算法按请求先后顺序处理 ，简单公平但效率低；最短寻道时间优先算法优先处理离磁头近的请求，可减少寻道距离，但可能导致远处请求 “饥饿” 。
- **磁盘扫描算法（如 SCAN ）**：磁头在一个方向上按顺序处理请求 ，到达一端后反向，类似电梯运行，减少磁头频繁换向，提高效率，兼顾公平性。
- **移臂调度算法**：和磁盘调度算法紧密相关 ，像电梯调度算法（SCAN ）形式，从移动臂当前位置沿移动方向选最近柱面请求处理，该方向无请求则换向；单向扫描调度算法从 0 号柱面开始向里道扫描，到达最后柱面快速返回 0 号柱面且返回不服务。

**根本目的**：核心目标是减少磁盘寻道时间（磁头移动到目标磁道时间）、旋转延迟时间（目标扇区旋转到磁头下方时间），提升磁盘 I/O 吞吐量 ，使系统能快速响应磁盘读写请求。

无论是哪个算法，都是基于电梯调度算法的思想在计算上实现的。

**电梯调度算法**

这里是补充的知识点，学习一下思想，主要服务电梯运行。

**传统电梯调度算法**

- 先来先服务算法（FCFS）
  - **原理**：按照乘客请求乘坐电梯的先后次序进行调度 。比如乘客 A、B、C 依次按下电梯按钮，电梯就按 A - B - C 的顺序依次响应。
  - **特点**：公平简单，每个请求都能依次处理 ，不会出现某请求长期得不到满足的情况。但在高峰载荷大时，性能下降明显，比如多人在不同楼层同时请求，电梯可能频繁折返，空耗时间。
- 最短寻找楼层时间优先算法（SSTF）
  - **原理**：优先选择距离当前电梯位置最近的楼层请求进行服务 。若电梯在 5 楼，有 2 楼、8 楼、10 楼的请求，会先响应 8 楼请求（假设距离 5 楼最近）。
  - **特点**：重载荷时平均响应时间短 ，但会使某些远离当前电梯位置的请求长时间等待，出现 “饿死” 现象，且电梯易频繁改变运行方向。
- 扫描算法（SCAN）
  - **原理**：让电梯在最底层和最顶层之间连续往返运行 ，运行中只响应与当前运行方向相同的楼层请求。如电梯向上运行时，只响应向上的楼层请求，到顶层后再向下运行并响应向下的请求。
  - **特点**：对寻找楼层进行了优化，效率较高 ，减少了电梯不必要的来回移动。但它是非实时算法，对紧急请求响应可能不及时。
- LOOK 算法
  - **原理**：是 SCAN 算法的改进 。电梯同样在各楼层间运行，但当发现当前运行方向上不再有请求时，立即改变运行方向，无需像 SCAN 算法那样到达最底层或最顶层才改变。
  - **特点**：相比 SCAN 算法，能更灵活地调整运行方向 ，进一步提高运行效率，减少空驶时间。

**实时电梯调度算法**

- 最早截止期优先调度算法（EDF）
  - **原理**：优先响应请求队列中时限最早的请求 。比如乘客 A 要求在 5 分钟内到达楼层，乘客 B 要求在 3 分钟内到达，电梯先响应 B 的请求。
  - **特点**：简单直接 ，但可能导致电梯无规律地寻找楼层，使电梯吞吐率低，整体运行效率不高。
- SCAN - EDF 算法
  - **原理**：结合 SCAN 算法和 EDF 算法 。先按 EDF 算法选择下一个服务对象，对于相同时限的请求，再按 SCAN 算法服务。
  - **特点**：效率取决于相同时限请求的数量 ，在一定程度上平衡了实时性和运行效率，但效率提升有限。
- PI 算法
  - **原理**：将请求队列中的请求分成两个优先级 ，优先保证高优先级队列中的请求得到及时响应，高优先级队列为空时再响应低优先级队列请求。
  - **特点**：可满足不同重要程度的请求需求 ，但优先级划分标准需合理设定，否则可能导致低优先级请求等待过久。
- FD - SCAN 算法
  - **原理**：先从请求队列中找出时限最早 ，且从当前位置移动能满足其时限要求的请求，以此确定下一次 SCAN 的方向，并在运行过程中响应同方向且可经过的请求信号。
  - **特点**：一定程度兼顾实时性和运行方向的优化 ，但忽略了用 SCAN 算法响应其他请求的开销，不能确保服务对象时限最终都能满足。

- 在CPU中获取指令并进行分析是控制单元的任务。
- 流水线技术：指在程序执行时多条指令重叠进行操作的一种并行处理实现技术。
- 总线带宽指的是单位时间内通过总线传输的数据总量。
- 高速缓冲（Cache）：
  - 高速缓冲存储器是存在于主存与CPU之间的一级存储器，由静态存储（SRAM）组成，容量比较小，但速度比主存高得多，接近CPU。
  - Cache通常保存着一份内存存储器中部分内容得副本（拷贝），该内容副本是最近曾被CPU使用过得数据和程序代码。

- 表达式可采用后缀表式，如 a*(b-c)+d ，可以写成如下：

  - 首先先看运算顺序：(b-c) 可以写成 bc- 
  - 其次， a*(b-c) 可以写成 abc-\* 
  - 最后， a*(b-c)+d 可以写成 abc-\*d+ 

- 操作系统文件管理中为了实现按名存取，系统必须为每个文件设置用于描述和控制文件的数据结构，它至少要包括文件名和存放文件得物理地址，这个数据结构称为文件控制块（FCB），文件控制块的有序集合称为文件目录。

  综上，文件目录是由文件控制块组成的，专门用于文件的检索。

- 在操作系统进程管理中，进程调度方式是指某进程正在运行，当有更高优先级的进程到来时如何分配CPU。调度方式分为可剥夺和不可剥夺两种。

  - 可剥夺：指当有更高优先级的进程到来时，强行将正在运行进程的CPU分配给高优先级的进程。
  - 不可剥夺：指当有更高优先级的进程到来时，必须等待正在运行的进程自动释放占用的CPU，然后将CPU分配给高优先级的进程。


- 缺页中断、一般中断：
  - 缺页中断：在虚拟存储管理系统中，当进程访问的页面不在内存中时，操作系统产生的一种中断。
    - 产生原因：进程运行时，若要访问的页面未调入内存，就会触发缺页中断，如首次访问某程序模块或数据块，但是他们未被加载到内存中。也有可能是因为内存中的页面因置换算法被换出，后续再次访问该页面时也会引发缺页中断。
  - 一般中断：指计算机系统在运行过程中，由于出现各种不同的事件或情况，而暂停当前正在执行的程序，转去处理相应的事件，处理完成后再返回原程序继续执行的过程。
  - 二者区别：
    - 缺页中断是在指令执行期间产生并进行处理的。
    - 一般中断是在一条指令执行完，下一条指令开始执行前进行处理的。

- 正规式和正规集合：
  - 正规式，如：(ab|c)(0|1|2)
  - 上面正规式所表示的正规集合为：
    - 正规式 (ablc) 表示的正规集为 {ab,c}，正规式(0|1|2)表示的正规集为{0,1,2}，将{ab,c)与{0,1,2}进行链接运算，得：{ab0,ab1,ab2,c0,c1,c2}。



- 主存地址和高速缓存（Cache）地址之间的转换工作是通过硬件来进行的

- 若计算机中的地址总线宽度为 n 位，则最多允许直接访问主存器的物理空间大小位 2^n (单位：B)
- 计算机系统采用页式存储管理，假设地址长度为 32 位，其中页号占 n 位，页内地址占 32-n 位，则系统中页面总数位 2^n （单位：B），页面大小为 2^(32-n)（单位：B）

- 高速缓存存储器一般采用随机静态访问存储器（SRAM）技术

- 内存的段式管理的优缺点：

  - 支持程序的模块化设计和并行编程的要求
  - 使各段的程序修改互不影响、便于多道程序共享主存的某些段

  缺点：

  - 地址变换速度慢
  - 内存碎片多，浪费

- 嵌入式操作系统的主要特点：
  - 微型化
  - 可定制
  - 实时性
  - 可靠性
  - 易移植性

- 已经获得除CPU以外的所有运行所需要资源的进程处于就绪状态
- 完整的计算机软件是指：程序、数据和有关文档
- 系统抖动

  - 什么是：在请求分页存储管理中，从主存（DRAM）中刚刚换出（Swap Out）某一页面后（换出到Disk），根据请求马上又换入（Swap In）该页，这种反复换出换入的现象，称为系统抖动
  - 产生原因：主要原因置换算法不当。（根据原理去推）
- 从硬盘读取数据，主要包括3各方面的时间：

  - 寻道时间：即将磁头移动到相应的磁道
  - 旋转时间：即查找到某个磁道上相应扇区的时间
  - 读取数据的时间：即数据传输率
