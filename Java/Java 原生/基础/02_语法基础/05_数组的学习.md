# 数组的学习

前面我们学习过了如何创建数组，但是对于开发来说是远远不够的，这里紧接着数组的操作学习（常见任务，例如复制、排序和搜索数组），一点一点来。

首先，是数组的复制，官方文档中提到了`System`类和 `util.Arrays`，二者都有自己复制数组的方法，但有区别。

### System.arraycopy(Object src, int srcPos, Object dest, int destPos, int length)

```java
public static void arraycopy(Object src, int srcPos, Object dest, int destPos, int length)
```

这里使用注释的方式解释方法以及参数。

```java
/*
* src		原数组
* srcPos	原数组起始下标
* dest		目标数组
* destPos	目标数组起始下标
* length	复制长度
*/
public static void arraycopy(Object src, int srcPos, Object dest, int destPos, int length)
```

### java.util.Arrays

为了方便起见，Java SE在`util`包中写好了各种工具类，这里介绍`Arrays`数组，`Arrays`数组提供了多种执行数组

- `binarySearch()`：在数组中搜索特定值以获取放置它的索引。
- `equals()`：比较两个数组以确定它们是否相等。
- `fill()`：填充数组以在每个索引处放置特定值。
- `sort()`：按升序对数组进行排序。也可以使用 Java SE 8 中引入的 `parallelSort()` 方法并发完成。在多处理器系统上对大型数组进行并行排序比顺序数组排序更快。
- `stream()`：创建使用数组作为其源的流。
