## 什么是面向对象？

面向对象是一种编程范式，也就是一种编程方式。

## 为什么要用面向对象？

在最初，人们通过c语言进行编程，根据其特性，c语言所编程的方式叫做面向过程，又叫做面向计算机编程，但随着人们的开发，c++，Java等语言问世，摒弃了c语言的面向过程的编程范式，因为其太过繁琐，冗余，不易懂。通过对c语言的封装，便有了面向对象。

面向对象使得开发过程更加方便，代码较少冗余、繁琐。

在Java官网有对对象说明，如下：

对象是相关状态和行为的软件包。本节说明如何在对象中表示状态和行为，介绍数据封装的概念，并说明以这种方式设计软件的好处。

对象有两个共同特征：它们都具有 state 和 behavior。狗有状态（名字、颜色、品种、饥饿）和行为（吠叫、抓、摇尾巴）。自行车还具有状态（当前档位、当前踏板踏频、当前速度）和行为（换档、改变踏板踏频、应用刹车）。识别真实世界对象的状态和行为是开始考虑面向对象编程的好方法。

现在花点时间观察您附近区域的真实世界物体。对于您看到的每个对象，请问自己两个问题：“此对象可以处于什么可能的状态”和“此对象可以执行什么可能的行为？请务必写下您的观察结果。当您这样做时，您会注意到现实世界对象的复杂程度各不相同;您的 Desktop Lamp 可能只有两种可能的状态（开和关）和两种可能的行为（打开、关闭），但您的桌面收音机可能还有其他状态（开、关、当前音量、当前电台）和行为（打开、关闭、增加音量、降低音量、搜索、扫描和调谐）。您可能还会注意到，某些对象反过来也会包含其他对象。这些实际观察是了解面向对象编程世界的起点。

软件对象由状态和相关行为组成。对象将其状态存储在*字段*（某些编程语言中的变量）中，并通过*方法*（某些编程语言中的函数）公开其行为。方法对对象的内部状态进行作，并用作对象到对象通信的主要机制。隐藏内部状态并要求通过对象的方法执行所有交互称为*数据封装*，这是面向对象编程的基本原则。

以自行车为例：

通过赋予状态 （当前速度、当前踏板节奏和当前档位） 并提供更改该状态的方法，对象仍然可以控制允许外部世界如何使用它。例如，如果自行车只有 6 个档位，则换档方法可以拒绝任何小于 1 或大于 6 的值。

将代码捆绑到单个软件对象中具有许多好处，包括：

1. 模块化：可以独立于其他对象的源代码编写和维护对象的源代码。创建后，对象可以轻松地在系统内传递。
2. 信息隐藏：通过仅与对象的方法交互，其内部实现的细节对外界保持隐藏。
3. 代码重用：如果对象已存在（可能由其他软件开发人员编写），则可以在程序中使用该对象。这允许专家实现/测试/调试复杂的、特定于任务的对象，然后您可以信任这些对象在您自己的代码中运行。
4. 可插拔性和调试便利性：如果某个特定对象出现问题，您只需将其从应用程序中删除，然后插入其他对象作为替换对象即可。这类似于修复现实世界中的机械问题。如果螺栓断裂，您需要更换它，而不是整台机器。
