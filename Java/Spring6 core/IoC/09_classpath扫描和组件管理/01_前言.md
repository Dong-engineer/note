## 什么是 classpath 扫描

在 Java 开发中，**classpath 扫描**（是指通过程序自动遍历类路径（classpath）下的资源（如类文件、配置文件等），并根据预设规则筛选出符合条件的资源或类的过程。

## 什么是组件管理

在软件工程中，**组件管理**（Component Management）是指对软件系统中 “组件” 的全生命周期进行规划、组织、控制和维护的过程。其核心目标是通过规范化的管理，提升组件的可重用性、可靠性和一致性，从而简化开发流程、降低维护成本。

### 什么是组件

组件其实就是开发者书写 Bean ，当让并不是所有的 Bean 都是组件，Spring 为开发者提供了 `BeanPostProcessor、ApplicationContextAware` 等接口的实现类就可以认为是一个组件，组件就是为了解决开发者在实际开发中遇到了重复性的工作问题，开发者可以将其行为、特性封装成一个接口或类，帮助开发者完成这些重复性操作。

**当开发者书写好了组件还是需要手动去管理组件，组件的生命周期、组件的实例化等等，Spring 完全可以帮助开发者去管理这些组件，但前提是 Spring 的容器中得有该组件**。

那怎么将组件注册到 Spring 容器中呢？

classpath 扫描可以帮助开发者完成这些任务。
