# 计算机组成
正式学习计算机组成原理前，先认识计算机的核心元器件与组成结构。

## 冯·诺依曼五大核心部件
冯·诺依曼体系结构的计算机由五大核心部件构成，是计算机硬件的基础框架：
1. **运算器**：核心为ALU与通用寄存器，通常可将ALU直接默认为运算器主体
2. **控制器**：核心为CU与专用寄存器（PC、IR、MAR、MDR等），通常可将CU直接默认为控制器主体
3. **存储器**：即内存（主存），用于存放程序指令与运算数据
4. **输入设备**：键盘、鼠标等设备，负责将外界信号转换为二进制数据送入内存
5. **输出设备**：显示器等设备，负责接收并解析二进制数据，输出为人可识别的信息

## 系统总线
总线是计算机各部件之间传输信息的公共通道，通常分为3类：
- 地址总线：传输内存访问的地址信息
- 数据总线：传输指令与数据内容
- 控制总线：传输控制信号与时序信号

## 运算器详解
运算器的核心构成为算术逻辑单元（ALU）+ 通用寄存器堆。
- **ALU（算术逻辑单元）**：由加法器、多路选择器等组合逻辑电路构成，负责执行加减、与或等算术与逻辑运算，配套通用寄存器堆存放运算数据。
- **ACC（累加器）**：属于通用寄存器，负责存储运算数据；注意累加器不是加法器，加法器只负责运算不存储数据，累加器仅存储数据不进行运算。
- **MQ（乘商寄存器）**：属于通用寄存器，在乘、除运算时，用于存放操作数或运算结果。

### 4. 控制器详解
控制器的核心构成为控制单元（CU）+ 专用寄存器组。
- **CU（控制单元）**：由时序电路、译码器构成，负责解析指令、发出控制信号，协调各部件有序工作。

## CPU 四大专用寄存器
寄存器是CPU内部的高速存储单元，其中PC、IR、MAR、MDR是CPU最核心的四个专用寄存器，承担指令与数据的中转功能。

### PC（程序计数器，Program Counter）
- 功能：存储下一条将要执行的指令的内存地址。
- 工作逻辑：正常顺序执行时，CPU每取出一条指令，PC自动自增，指向内存中下一条指令；遇到跳转指令（如if判断跳转）时，CU会直接修改PC的值，使程序跳转至新的地址执行。

### IR（指令寄存器，Instruction Register）
- 功能：存放当前正在执行的指令本身。
- 注意：IR存储的是指令的具体内容，而非指令的内存地址。

### MAR（存储器地址寄存器，Memory Address Register）
- 功能：CPU与内存交互时，暂存目标存储单元的地址，是连接地址总线的中转站。
- 工作逻辑：
  1. CPU想要读写内存，必须先把内存地址放到MAR；
  2. MAR的输出直接连到地址总线，将地址发送给内存芯片，内存收到地址后明确要读写的存储单元；
  3. MAR只存地址，不存数据。

### MDR（存储器数据寄存器，Memory Data Register）
- 功能：CPU与内存之间传输数据/指令的中转站，连接数据总线。
- 工作逻辑：
  1. 读内存：内存把数据读出后，先放到MDR，CPU再从MDR中读取数据；
  2. 写内存：CPU要写入的数据，先放到MDR，再通过数据总线写入内存。
