# 流的中间操作

在前面讲述过 `map-filter-reduce` 规则，流的中间操作离不开这一规则。

结合 *05_Stream* 对于接口 `Stream` 的介绍，开发者对流的操作有了一定认识，在本文中会加深对流的中间操作的影响。

```java
// 过滤元素，保留满足条件的数据
Stream<T> filter(Predicate<? super T> predicate);

// 映射：T -> R，一对一转换
<R> Stream<R> map(Function<? super T, ? extends R> mapper);
// 映射：拆分流（一对多，如List拆成单个元素）
<R> Stream<R> flatMap(Function<? super T, ? extends Stream<? extends R>> mapper);

// 去重，基于equals()
Stream<T> distinct();
// 自然排序
Stream<T> sorted();
// 自定义比较器排序
Stream<T> sorted(Comparator<? super T> comparator);

// 截取前N个元素
Stream<T> limit(long maxSize);
// 跳过前N个元素
Stream<T> skip(long n);

// peek：调试打印，不改变流元素（仅消费元素）
Stream<T> peek(Consumer<? super T> action);
```

如上所示，一共是 9 个中间操作，这里将他们分为两大类：

- 无状态操作—— `filter()、map()、peek()`
- 有状态操作—— `sorted()、distinct()、limit()、skip()`
