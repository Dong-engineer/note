# 条件控制

## 概述

条件控制是 JavaScript 核心分支逻辑，根据布尔表达式结果执行不同代码块，MDN 定义 JS 标准条件语法包含：`if...else`、`else if`、三元运算符 `?:`、`switch`。

## if /if...else 语句

### 语法

```js
// 单if
if (condition)
  statement;

// 代码块
if (condition) {
  statements;
}

// if else
if (condition) {
  // 条件为真，执行
} else {
  // 条件为假，执行
}
```

- `condition`：任意 JS 表达式，会自动**隐式转换布尔值**
- 假值（falsy）：`false`、`0`、`""`、`null`、`undefined`、`NaN`
- 真值（truthy）：其余所有值（非空字符串、非 0 数字、对象、数组等）

### 示例

```js
const age = 18;

// 判断年龄是否大于等于 18
if (age >= 18) {
  console.log("成年");
} else {
  console.log("未成年");
}
```

## else if 多分支判断

用于多条件依次匹配，匹配成功即终止分支：

```js
const score = 85;
if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else if (score >= 60) {
  console.log("C");
} else {
  console.log("D");
}
```

## 三元条件运算符？:

唯一三目运算符，替代简单 if-else，MDN 归类为条件表达式

### 语法

```js
condition ? exprIfTrue : exprIfFalse
```

### 示例

```js
const age = 16;
const tip = age >= 18 ? "可上网" : "禁止上网";
console.log(tip);
```

> 注意：多层三元建议加括号提升可读性，不建议复杂业务嵌套过多三元。

## switch 多匹配分支

适合**固定值等值匹配**，对比 else if 更简洁，MDN 标准语法：

### 基础语法

```js
switch (expression) {
  case value1:
    statements1;
    break; // 阻断穿透，必备
  case value2:
    statements2;
    break;
  default:
    // 所有case不匹配时执行
    defaultStatements;
}
```

`expression` 是 JS 表达式，一般情况下 `expression` 表示为一个对象。

`switch` 会将 `expression` 对每一个 `case` 分支进行比对，比对成功，会执行 `case` 后的代码块。

### 关键特性

1. `case` 匹配使用**严格相等** **`===`**（区分类型）
2. 无 `break` 会发生**case 穿透**，连续执行后续 case 代码
3. `default` 可选，可放在任意位置，一般放末尾

### 示例

```js
const week = 3;
switch (week) {
  case 1:
    console.log("周一");
    break;
  case 2:
    console.log("周二");
    break;
  case 3:
    console.log("周三");
    break;
  default:
    console.log("未知星期");
}
```

### 穿透用法（合理场景）

```js
const month = 2;
switch (month) {
  case 1:
  case 2:
  case 3:
    console.log("第一季度");
    break;
}
```

## 最佳实践（MDN 推荐）

1. 所有分支代码统一使用 `{}` 代码块，避免单行语句歧义
2. 复杂多条件优先 `else if`；固定枚举值匹配优先 `switch`
3. 简单二选一逻辑使用三元运算符，复杂逻辑不嵌套三元
4. switch 务必添加 `break`，按需使用穿透
5. 条件表达式尽量简洁，避免超长复合判断，可提前提取变量

## 注意事项

1. 赋值 `=` 代替判断 `==`/`===`：`if(a = 1)` 永远为真
2. switch 宽松匹配误区：不会自动类型转换
3. 忽略假值转换：`if([])` 数组为真值，`if("")` 空字符串为假值
