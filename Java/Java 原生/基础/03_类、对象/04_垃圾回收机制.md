# 垃圾回收机制

某些面向对象语言要求您跟踪您创建的所有对象，并在不再需要它们时显式销毁它们。显式管理内存既乏味又容易出错。Java 平台允许您创建任意数量的对象（当然，受限于您的系统可以处理的对象），并且您不必担心销毁它们。Java 运行时环境在确定不再使用对象时删除这些对象。此过程称为垃圾回收。

当没有对该对象的更多引用时，该对象有资格进行垃圾回收。当变量超出范围时，通常会删除保存在变量中的引用。或者，您可以通过将变量设置为 special value 来显式删除对象引用。请记住，一个程序可以有多个对同一对象的引用;必须先删除对对象的所有引用，然后该对象才有资格进行垃圾回收。

Java 运行时环境有一个垃圾回收器，它会定期释放不再引用的对象使用的内存。当垃圾回收器确定时机合适时，它会自动执行其工作。
