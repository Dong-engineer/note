# 有无 https 证书

关于爬虫时遇见的网站是否含有 `https` 证书一问题，在本文档中会进行讨论。

## 一、如何查看目标网站是否含有 `https` 证书

就目前作者所接触到的网站来讲，大多数以 `https://` 开头的网站都是含有 `https` 证书，当然也可能有一些网站是 `http://` 开头，这些网站是不含有 `https` 证书的。

## 二、有无 `https` 对爬虫是否有影响

有无 `https` 证书对于开发者的影响是很小的。

### `https` 证书有何作用

有 `https` 证书证明了该网站的真实身份已经经过数字证书颁发机构（简称 CA）认证，客户端和服务端在通信时会更加安全，网站的可信度更高。

## 三、怎么应对

开发者在使用 `requests` 库爬虫时，其 `get()` 函数中的 `verify` 参数可控制是否开启 SSL 证书验证（即 `https` 证书验证），如下：

```python
import requests
response = requests.get("目标网址", verify=False)  # 关闭 SSL 证书验证，默认开启
```
