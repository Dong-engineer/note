# 自动装箱与拆箱

经过上一节的学习，其实开发者已经学会了拆箱。

## 装箱

装箱就是将八大基元数据类型转换成包装类。

如下：

```java
// 装箱
int i = 10;
Integer integer = Integer.valueOf(i);
```

除此之外，开发者无需手动调用`Integer.valueOf()`。

当遇到 `int`类型需要转换到`Integer`类型的时候，可以直接使用`int`类型，在运行的时候 Java 会自动帮助开发者装箱。

如下：

```java
public static void print(Integer num) {
    System.out.println(num);
}
public static void main(String[] args) {
    int a = 20;
    print(a); // 自动装箱：int -> Integer，等价于 print(Integer.valueOf(a));
}
```



## 拆箱

拆箱就是装箱反过来。

同样的拆箱，Java 也会帮助开发者自动进行拆箱。

```java
Integer a = 10; // 装箱
int b = a; // 拆箱（等价于 int b = a.intValue();）
```
