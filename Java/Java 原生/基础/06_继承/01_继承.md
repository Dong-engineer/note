# 继承

继承在前面的*对象*学习中用到过，当时并没有细说，这里开始继承真正的讲述。

**定义：从另一个类派生的类称为子类（也称为派生类、扩展类或子类）。派生子类的类称为超类（也称为基类或父类）。**

## Object

在*类*一章节的学习中讲述过`Object`，在 Java 的官方文档中是这样介绍的：*除了没有超类的* `Object` 之外，每个类都有一个且只有一个直接超类（单继承）。在没有任何其他显式超类的情况下，每个类都是  `Object` *的隐式子类。*

这句有一点不完善，假设现在又父类`A`，`B`继承了`A`，`A`没有继承任何父类，那么`A`隐式继承`Object`，所以`B`也就间接的继承了`Object`。

关于`Object`就这么多了，更多的API用法参考文档吧。

## 继承

继承是通过关键字 `extends` 来实现的。

如下：

```java
// 父类：动物
class Animal {
    private String name;
    private int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 公共方法
    public void eat() {
        System.out.println(name + "正在进食");
    }

    public void sleep() {
        System.out.println(name + "正在睡觉");
    }

    // Getter和Setter
    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }
}

// 子类：狗（继承自Animal）
class Dog extends Animal {
    private String breed; // 品种

    public Dog(String name, int age, String breed) {
        super(name, age); // 调用父类构造方法
        this.breed = breed;
    }

    // 重写父类方法
    @Override
    public void eat() {
        System.out.println(getName() + "（" + breed + "）正在啃骨头");
    }

    // 子类特有方法
    public void bark() {
        System.out.println(getName() + "（" + breed + "）正在汪汪叫");
    }
}

// 子类：猫（继承自Animal）
class Cat extends Animal {
    private boolean isLazy; // 是否懒惰

    public Cat(String name, int age, boolean isLazy) {
        super(name, age);
        this.isLazy = isLazy;
    }

    // 重写父类方法
    @Override
    public void sleep() {
        if (isLazy) {
            System.out.println(getName() + "是只懒猫，整天睡觉");
        } else {
            System.out.println(getName() + "只睡了一小会儿");
        }
    }

    // 子类特有方法
    public void scratch() {
        System.out.println(getName() + "正在抓沙发");
    }
}

// 测试类
public class Test17 {
    public static void main(String[] args) {
        Dog dog = new Dog("旺财", 3, "金毛");
        Cat cat = new Cat("咪咪", 2, true);

        // 调用继承的方法
        dog.eat();   // 输出：旺财（金毛）正在啃骨头
        dog.sleep(); // 输出：旺财正在睡觉

        // 调用子类特有方法
        dog.bark();  // 输出：旺财（金毛）正在汪汪叫

        // 多态调用
        Animal animal = cat;
        animal.sleep(); // 输出：咪咪是只懒猫，整天睡觉
        // animal.scratch(); // 错误：父类引用无法调用子类特有方法
    }
}
```

### super

在上面的代码中不难发现，在子类的构造方法中，使用到了关键字 `super` 。

 `super`  直接代表了父类，当开发者想要在子类调用父类的行为或字段，使用`super` 即可。

代码如下：

```java
// 基类：交通工具
class Vehicle {
    protected String brand;
    protected int year;

    public Vehicle(String brand, int year) {
        this.brand = brand;
        this.year = year;
    }

    public void start() {
        System.out.println(brand + "启动了");
    }

    public void displayInfo() {
        System.out.println("品牌：" + brand + "，年份：" + year);
    }
}

// 子类：汽车
class Car extends Vehicle {
    private int wheels = 4;  // 汽车默认4个轮子
    private String model;

    public Car(String brand, int year, String model) {
        super(brand, year);  // 1. 调用父类构造方法
        this.model = model;
    }

    @Override
    public void start() {
        super.start();  // 2. 调用父类被重写的方法
        System.out.println(model + "发出轰鸣声");
    }

    public void displayInfo() {
        super.displayInfo();  // 2. 调用父类被重写的方法
        System.out.println("型号：" + model + "，轮子数：" + wheels);
    }

    public void upgradeWheels(int newWheels) {
        this.wheels = newWheels;
        super.brand = "升级后的" + super.brand;  // 3. 访问父类属性
    }
}

// 测试类
public class SuperExample {
    public static void main(String[] args) {
        Car car = new Car("奔驰", 2023, "S级");
        
        car.start();
        /* 输出：
           奔驰启动了
           S级发出轰鸣声
        */
        
        car.displayInfo();
        /* 输出：
           品牌：奔驰，年份：2023
           型号：S级，轮子数：4
        */
        
        car.upgradeWheels(5);
        car.displayInfo();
        /* 输出：
           品牌：升级后的奔驰，年份：2023
           型号：S级，轮子数：5
        */
    }
}
```

#### 条件

使用 `super` 有一定的条件。

1. 权限修饰，即权限修饰符`public 、protected、private`。
2.  静态修饰，经过 `static` 关键字修饰所有成员、方法，都仅仅是属于其类本身的，不可以在子类中通过 `super` 使用。

## 私有成员

关于父类中的私有成员，上面已经做过讲述，子类是无法直接访问和直接继承的父类的方法或者字段的。

但是如果，父类中有 `public、protected` 的方法，子类是可以通过其方法间接访问或调用的。

## 向上转型和向下转型

在 Java 中，对象的类型由实例化它的类决定，但由于继承关系，一个对象可以同时被视为 “自身类型” 和 “父类类型”。
例如：

- 若`MountainBike`继承自`Bicycle`，`Bicycle`又继承自`Object`，则：
  `MountainBike`的对象 **既是** `MountainBike`类型，**也是** `Bicycle`类型和`Object`类型。

### 隐式转换（自动向上转型）

当把**子类对象**赋值给**父类引用**时，编译器会自动完成转换（无需手动操作），这称为 “向上转型”。

**示例**：

```java
// MountainBike 是 Bicycle 的子类，Bicycle 是 Object 的子类
MountainBike mb = new MountainBike();  // mb 的实际类型是 MountainBike

// 隐式转换：子类对象 → 父类引用
Bicycle bike = mb;    // 合法：MountainBike 是 Bicycle 的一种
Object obj = mb;      // 合法：MountainBike 是 Object 的一种
```

**原理：**

继承关系中，子类 “包含” 父类的所有特性，因此父类引用可以安全地指向子类对象。

### 显式转换（强制向下转型）

**当把父类引用赋值给子类引用时**，必须手动强制转换（需用`(子类类型)`声明），这称为 “向下转型”。

**示例**：

```java
Object obj = new MountainBike();  // 隐式转换：MountainBike → Object

// 错误！父类引用不能直接赋值给子类引用
MountainBike mb1 = obj;  // 编译失败：编译器不知道 obj 实际是 MountainBike

// 正确：显式强制转换
MountainBike mb2 = (MountainBike) obj;  // 合法：手动声明 obj 实际是 MountainBike
```

**风险**：强制转换时，编译器仅检查语法，**运行时才会验证对象实际类型**。如果父类引用指向的对象不是目标子类类型，会抛出`ClassCastException`。

```java
Object obj = new Bicycle();  // obj 实际是 Bicycle 类型
MountainBike mb = (MountainBike) obj;  // 运行时异常：Bicycle 不能转为 MountainBike
```

### 用`instanceof`避免转换异常

为了安全转换，可先用`instanceof`运算符判断对象实际类型，再进行强制转换。

**语法**：

```java
if (对象 instanceof 目标类型) {
    目标类型 变量 = (目标类型) 对象;  // 安全转换
}
```

**示例**：

```java
Object obj = new MountainBike();

if (obj instanceof MountainBike) {
    // 确认 obj 实际是 MountainBike 后再转换
    MountainBike mb = (MountainBike) obj;
    System.out.println("转换成功");
} else {
    System.out.println("不能转换为 MountainBike");
}
```

**作用**：`instanceof`在运行时检查对象的实际类型，避免因类型不匹配导致的`ClassCastException`。

### 总结

| 类型转换方向        | 转换方式     | 条件与风险                                                   |
| ------------------- | ------------ | ------------------------------------------------------------ |
| 子类 → 父类（向上） | 隐式转换     | 自动完成，无风险                                             |
| 父类 → 子类（向下） | 显式强制转换 | 必须手动声明，可能抛出`ClassCastException`，需用`instanceof`验证 |
