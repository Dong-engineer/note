# 循环

## 概述

循环用于重复执行代码块，MDN 规范 JS 五大循环体系： `for`、`while`、`do...while`、`for...in`、`for...of`；配套控制关键字 `break` / `continue`。

## while 循环

### 语法

```js
while (condition) {
  statements;
}
```

- 逻辑：条件为真则持续执行，每次循环前校验条件
- 风险：条件永远为真会造成**死循环**

### 示例

```js
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}
```

## do...while 循环

### 语法

```js
do {
  statements;
} while (condition);
```

特点：**至少执行一次**，无论条件真假

### 示例

```js
let i = 10;
do {
  console.log("至少执行一次");
  i++;
} while (i < 5);
```

## for 循环

### 语法

```js
for (initialization; condition; final-expression) {
  statements;
}
```

1. initialization：循环初始化（仅执行 1 次）
2. condition：每次循环前判断，false 终止
3. final-expression：每次循环结束后执行

### 示例

```js
for (let i = 0; i < 10; i++) {
  console.log(i);
}
```

### 灵活写法

三段均可省略，`for(;;)` 等价无限死循环：

```js
let i = 0;
for (; i < 5; ) {
  console.log(i);
  i++;
}
```

## 循环控制关键字 break /continue

### break

1. 终止当前整个循环，跳出循环体
2. 可配合标签跳出多层循环

```js
for (let i = 0; i < 10; i++) {
  if (i === 3) break;
  console.log(i); // 0,1,2
}
```

### continue

终止本次单次循环，直接进入下一轮条件判断

```js
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
  console.log(i); // 0,1,3,4
}
```

### 标签循环（多层循环跳出）

```js
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outer;
    console.log(i,j);
  }
}
```

## 补充

除以上循环之外，还有 `for in` 、`for of` 循环，这里不在介绍，后续学习集合时会讲述。
