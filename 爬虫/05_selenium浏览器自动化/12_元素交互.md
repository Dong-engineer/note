# 元素交互

关于元素交互，开发者有五种可进行的操作指令：

1. 点击指令
2. 输入键位指令
3. 清楚指令
4. 提交指令
5. 选择指令

## 点击指令（`click()`）

点击指令开发者只能通过元素对象来调用，即通过定位器 `find_element()` 获取元素后再通过元素对象调用 `click()` 。

```python
driver.get("https://www.selenium.dev/selenium/web/inputs.html")

check_input = driver.find_element(By.NAME, "checkbox_input")
check_input.click()
```

## 输入键位指令（`send_keys()`）

输入键位指令只能通过元素对象来调用。

```python
email_input = driver.find_element(By.NAME, "email_input")
email_input.clear()
    
email = "admin@localhost.dev"
email_input.send_keys(email)
```

## 清楚指令（`clear()`）

清楚指令只能通过可编辑、且可重置的元素来调用。

```python
email_input = driver.find_element(By.NAME, "email_input")
email_input.clear()
    
email = "admin@localhost.dev"
email_input.send_keys(email)

# 清楚输入框内容
email_input.clear()
```

## 选择指令（`select_by_value()`）

### 元素定位

该方法主要用于 `<select>` HTML 标签。

开发者应该通过 `find_element()` 获取 `<select>` 该标签元素，不可以获取 `<option>` 标签下的元素并试图对其进行点击操作。

```html
<select id="hobody" mutiple>
    <option value="BeiJing">北京</option>
    <option value="ShangHai">上海</option>
    <option value="ShenZhen">深圳</option>
    <option value="XiangGang">香港</option>
</select>
```

```python
import org.openqa.selenium.support.ui.Select
from selenium.webdriver.support.ui import Select

select_element = driver.find_element(By.ID, "city")
select = Select(select_element)
```

### 获取下拉框中的文本信息

```python
options = select.all_options
for option in options:
    print("选项文本信息：", option.text)
```

### 获取默认选中的 `<option>`

```python
default_option = select.first_selected_option
print(f"默认选项：{default_option.text}")
```

### 判断当前 `<select>` 是否为多选

```python
is_multiple = select.is_multiple
print("是否支持多选：", is_multiple)
```

### 获取当前已经选中的 `<option>`

```python
selected_options = select.all_selected_options
for option in selected_options:
	print(f"已选信息：{option}")
```

### `value` 属性匹配

```python
select = drive.find_element(By.ID, "hobody")
# 这里匹配的 HTML 标签中的 value 属性值
select.select_by_value("Beijing")
```

### 文本匹配

```python
select = drive.find_element(By.ID, "hobody")

select.select_by_visible_text("北京")
```

### 索引选择

```python
select = drive.find_element(By.ID, "hobody")
# selenium 官方是不建议使用索引匹配的，因为 select 标签下的选择元素会因开发者点击选择的缘故，其顺序也随之变化
select.select_by_index(0)
```

### 取消选择

```python
# 取消选择
select.deselect_by_value("BeiJing")

# 取消所欲选择
select.deselect_all()
```

## 注意事项

1. 选择指令只能应用于 `<select>` 标签，如果遇见其他形式的下拉选项框，开发者可以通过其他交互指令配合来完成任务。
2. 索引定位尽量避免使用。
3. 注意要等待元素。
