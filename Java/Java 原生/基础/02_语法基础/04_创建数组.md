# 创建数组

## 数组

*数组*是一个容器对象，它包含固定数量的单个类型的值。数组的长度是在创建数组时确定的。创建后，其长度是固定的。

```java
// int anArray[] 这是C++的写法
int[] anArray = new int[10]; // 这里就声明了一个固定长度为10的int类型数组

int[] anArray_1 = {
    100, 100, 100,
    100, 100, 100
} // 也可以通过{}直接声明数组内元素
```

知道什么是数组后，我们该如何访问其内部的值。

对于包含多个同类元素的变量，我们可以通过索引（下标）来访问其变量。

```java
anArray[0] = 100;
anArray[1] = 200;
anArray[2] = 300;
anArray[3] = 400;
anArray[4] = 500;
anArray[5] = 600;
anArray[6] = 700;
anArray[7] = 800;
anArray[8] = 900;
anArray[9] = 1000;
```

当然int类型的数组只能包含int类型元素。

同样的当我需要其他类型的数组，直接声明即可，如下：

```java
byte[] anArrayOfBytes;
short[] anArrayOfShorts;
long[] anArrayOfLongs;
float[] anArrayOfFloats;
double[] anArrayOfDoubles;
boolean[] anArrayOfBooleans;
char[] anArrayOfChars;
String[] anArrayOfStrings;
```

## 多维数组

还可以使用两组或多组括号（如 names）来声明数组的数组（也称为多维数组）。因此，每个元素都必须由相应数量的索引值访问。

如下为官方示列：

```java
class MultiDimArrayDemo {
    public static void main(String[] args) {
        String[][] names = {
            {"Mr. ", "Mrs. ", "Ms. "},
            {"Smith", "Jones"}
        };
        // Mr. Smith
        System.out.println(names[0][0] + names[1][0]);
        // Ms. Jones
        System.out.println(names[0][2] + names[1][1]);
    }
}
```

`names[0]`表示{"Mr. ", "Mrs. ", "Ms. "}，`names[1]`表示{"Smith", "Jones"}，所以`names[0][0]`就表示 "Mr." 。
