# 类

## 创建类

前面我们已经了解过面向对象，类和对象很相似，下面会使用具体的例子解释说明。

类可以说是对象的统一集合体，不同对象之间可能拥有统一特征，将拥有这些统一特征的抽象集合体被叫做类。

如下：

```java
// 这是一个自行车类，其包含了自行车拥有的统一特征的类
public class Bicycle {

    // 自行车所拥有的特征属性
    // 这里叫做属性或者字段、类成员变量
    public int cadence; // 脚踏
    public int gear; // 轮子
    public int speed; // 速度
    public String owner; // 拥有者

}
```

至此一个类就被创建好了，但是我们需要通过抽象的类具体到事物对象，Java 给出两种方式，如下：

```java
public class Bicycle {

    public int cadence;
    public int gear;
    public int speed;
    public String owner;
    
    // 这个叫做构造器，和普通的函数方法不一样，他没有返回值，且格式为 public 类名()
    // 仔细看可以发现小括号中含有参数，这中构造器，我们叫做有参构造器
    public Bicycle(int startCadence, int startSpeed, int startGear, String startOwner) {
        gear = startGear;
        cadence = startCadence;
        speed = startSpeed;
        owner = startOwner;
    }
    
    // 无参构造器
    public Bicycle() {
        
    }
}
```

`Bicycle`类的字段是public公有的，这样在其他域里面，可以直接访问`Bicycle`类的实例（对象）的字段、修改，这样是不可取的，在实际开发时我们将其字段定义为私有的，这样在其他域里面访问`Bicycle`类的实例（对象）的字段和修改字段需要一定的方式进行修改。

## set()和get()

Java提供了`set()`和`get()`来达成以上目的，如下：

```java
public class Bicycle {

    // 设为私有
    private int cadence;
    private int gear;
    private int speed;
    private String owner;
    
    public Bicycle(int startCadence, int startSpeed, int startGear, String startOwner) {
        gear = startGear;
        cadence = startCadence;
        speed = startSpeed;
        owner = startOwner;
    }
    
    // 无参构造器
    public Bicycle() {}
    
    // set
    public void setCadence(int newValue) {
        cadence = newValue;
    }
    
    // get
    public int getCadence() {
        return this.cadence;
    }
        
    public void setGear(int newValue) {
        gear = newValue;
    }
    
    public int getGear() {
        return this.gear;
    }
        
    public void setSpeed(int newValue) {
        speed = newValue;
    }
    
    public int getSpeed() {
        return this.speed;
    }
    
    public void setOwner(String newValue) {
        speed = newValue;
    }
    
    public int getOwner() {
        return this.owner;
    }
    
}
```

## this关键字

但是，在实际开发时应遵守开发规则：

1. 在有参构造器的参数中，我们应该将参数名称和其对应的字段名称设为一样。
2. 在`set()`方法中，所接受的参数名称应该和其对应的字段名称设为一样。
3. 在书写`set()和get()`时，我们应该以`set或者get`开头，后接 字段名（首字母大写），如：`setCadence()`。

如果按以上做就会使得代码有歧义，如有参构造器：

```java
// 这会报错
public Bicycle(int cadence, int speed, int gear, String owner) {
    gear = gear;
    cadence = cadence;
    speed = speed;
    owner = owner;
}
```

仔细观察就会发现，有参构造器接受的参数`cadence`等等，在其域里面别分别赋值给对应的字段，但是字段在该域里面名称冲突。

**Java提供了`this`关键字**，**来代表当前类的隐藏副本对象**，如下：

```java
public class Bicycle {

    private int cadence;
    private int gear;
    private int speed;
    private String owner;
    
    public Bicycle(int cadence, int speed, int gear, String owner) {
        this.gear = gear;
        this.cadence = cadence;
        this.speed = speed;
        this.owner = owner;
    }
    
    // 无参构造器
    public Bicycle() {}
    
    // set
    public void setCadence(int cadence) {
        this.cadence = cadence;
    }
    
    // get
    public int getCadence() {
        return this.cadence;
    }
        
    public void setGear(int gear) {
        this.gear = gear;
    }
    
    public int getGear() {
        return this.gear;
    }
        
    public void setSpeed(int speed) {
        this.speed = speed;
    }
    
    public int getSpeed() {
        return this.speed;
    }
    
    public void setOwner(String speed) {
        this.speed = speed;
    }
    
    public int getOwner() {
        return this.owner;
    }

}
```

## 函数

自行车肯定有其自己的行为特征，将其行为特征定义为函数，如下：

```java
public class Bicycle {

    private int cadence;
    private int gear;
    private int speed;
    private String owner;
    
    public Bicycle(int cadence, int speed, int gear, String owner) {
        this.gear = gear;
        this.cadence = cadence;
        this.speed = speed;
        this.owner = owner;
    }
    
    // 无参构造器
    public Bicycle() {}
    
    // set
    public void setCadence(int cadence) {
        this.cadence = cadence;
    }
    
    // get
    public int getCadence() {
        return this.cadence;
    }
        
    public void setGear(int gear) {
        this.gear = gear;
    }
    
    public int getGear() {
        return this.gear;
    }
        
    public void setSpeed(int speed) {
        this.speed = speed;
    }
    
    public int getSpeed() {
        return this.speed;
    }
    
    public void setOwner(String speed) {
        this.speed = speed;
    }
    
    public int getOwner() {
        return this.owner;
    }
    
    // 行为特征
    // 格式：访问机制 返回值类型 函数名([参数类性 参数名]){}
	public void moving() {
        System.out.println("自行车正在运动");
    }
}
```

有了行为，该怎么调用自行车的行为呢，或者访问其属性，下节会讲述到。

## Object

这里应该放到**继承**来讲述的，但是后面有些内容需要用到其一定的知识。

`Object`是Java源码中一个类，**这个类请记住它是所有类的父类，更直白一点可以说它是所有类（包括自定义的类）的祖宗**。

Java规定了所有的类都隐式继承`Object`。

在`Object`中有常用的三个方法，`toString()、equals()、hashCode()`。

本节就到此为止，多的后面自然会学到。
