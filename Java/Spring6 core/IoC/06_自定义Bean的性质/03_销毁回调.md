# 销毁回调

同初始化回调一样，具体的发生时间在 *01_Bean的生命周期* 中已经声明。

Spring 是这样描述的：实现 `org.springframework.beans.factory.DisposableBean` 接口可以让Bean在包含它的容器被销毁时获得一个回调。`DisposableBean` 接口指定了一个方法。

## `destroy()`

这是 Spring 的`org.springframework.beans.factory.DisposableBean` 接口提供的方法。

如果开发者想要实现销毁回调，那么就要实现`org.springframework.beans.factory.DisposableBean` 接口，和初始化回调一样。这里不再书写代码。

同样的 Spring 不建议开发者这样做。

### 基于XML文件的销毁回调

同样使用 *初始化回调* 中的例子

```java
public class User {
	

    public User() {
        
    }
    
    // 初始化方法
    public void initUser() {
        System.out.println("User对象已被创建");
    }
    
    // 销毁方法
    public void destroyUser() {
        System.out.println("User对象已被创建");
    }

}
```

```xml
<bean id="user" class="xxx.User" intit-method="intitUser" destroy-method="destroyUser"/>
```

### 基于注解

```java
public class User {
	

    public User() {
        
    }
    
    // 初始化方法
    @PostConstruct
    public void initUser() {
        System.out.println("User对象已被创建");
    }
    
    // 销毁方法
    @PreDestroy
    public void destroyUser() {
        System.out.println("User对象已被创建");
    }

}
```
