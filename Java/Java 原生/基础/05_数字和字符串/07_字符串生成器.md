# 字符串生成器

字符串生成器，即`StringBuilder`类。

和`String`类似，但与其不同的是`String`，`StringBuilder`不可被修改。

## `StringBilder`

准确的来说`StringBuilder`叫做字符序列，`StringBilder`有一定的容量。

```java
StringBuilder sb = new StringBuilder(); // 初始容量16
```

```java
StringBuilder sb = new StringBuilder(100); // 初始容量100
```

在学习*字符串*的时候，知道字符串是不可以修改，当开发者在初始化一个字符串后，后面想要修改其变量则需要重新赋，那也就意味着需要重新创建一对象或者说在开辟一片新的空间用来存储新的字符串。

故而 Java 提供了 `StringBuilder` ，以方便开发者来对字符串进行修改。

> *还有一个* `StringBuffer` *类，它与* `StringBuilder` *类完全相同，不同之处在于它是线程安全的，因为它的方法已同步。除非你绝对需要一个线程安全的类，否则你不需要使用* `StringBuffer`]*。*

## `StringBuilder` 和 `+` 的差异

| **对比维度**   | `+` 运算符                                                   | `StringBuilder`                                              |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **底层原理**   | 编译期会被自动转换为`StringBuilder`（或`StringBuffer`）的`append()`操作，但每次拼接都会创建新的`StringBuilder`对象（循环中尤为明显）。 | 显式使用可变字符序列，所有操作在同一个对象上完成，避免频繁创建对象。 |
| **性能表现**   | - 单次拼接性能接近`StringBuilder`（编译期优化后）。 - 循环或多次拼接时性能极差（每次循环创建新对象，触发多次数组复制和垃圾回收）。 | - 多次拼接（尤其是循环中）性能远超`+`运算符，因为始终在一个对象上操作，仅需少数几次扩容。 |
| **线程安全性** | 无（依赖底层`StringBuilder`，非线程安全）。                  | 非线程安全（若需线程安全，需用`StringBuffer`）。             |
| **适用场景**   | 1. 少量、简单的字符串拼接（如固定格式的字符串）。 2. 代码可读性优先，拼接逻辑简单时。 | 1. 循环中拼接字符串（如遍历集合拼接结果）。 2. 大量、复杂的字符串拼接（如动态 SQL、日志构建）。 |
| **代码示例**   | `java String a = "Hello"; String b = a + " World"; // 编译后等价于new StringBuilder(a).append(" World").toString()` | `java StringBuilder sb = new StringBuilder("Hello"); sb.append(" World"); String result = sb.toString();` |
| **内存开销**   | 每次拼接创建新的`String`和`StringBuilder`对象，内存开销大。  | 仅在扩容时创建新数组，内存开销小，且可通过预设容量进一步优化。 |

### 补充

```java
// 性能极差！每次循环创建新的StringBuilder
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i; 
}
```

## `StringBuilder`常用方法

### 一、常用构造方法

| **构造方法签名**                  | **描述**                                                     |
| --------------------------------- | ------------------------------------------------------------ |
| `StringBuilder()`                 | 创建一个空的`StringBuilder`，初始容量默认为 **16 个字符**。  |
| `StringBuilder(int capacity)`     | 创建一个空的`StringBuilder`，并指定初始容量为`capacity`。    |
| `StringBuilder(String str)`       | 创建一个包含指定字符串`str`内容的`StringBuilder`，初始容量为`str.length() + 16`。 |
| `StringBuilder(CharSequence seq)` | 创建一个包含指定字符序列`seq`内容的`StringBuilder`，初始容量为`seq.length() + 16`。 |

### 二、字符串构建方法

| **方法签名**                              | **描述**                                                     |
| ----------------------------------------- | ------------------------------------------------------------ |
| `append(T value)`                         | 追加任意类型的数据（如`String`、`int`、`char`等），返回当前对象本身。 |
| `insert(int offset, T value)`             | 在指定位置`offset`插入任意类型的数据，返回当前对象本身。     |
| `delete(int start, int end)`              | 删除从`start`到`end-1`的字符，返回当前对象本身。             |
| `deleteCharAt(int index)`                 | 删除指定索引位置的字符，返回当前对象本身。                   |
| `replace(int start, int end, String str)` | 用`str`替换从`start`到`end-1`的字符，返回当前对象本身。      |

### 三、字符串修改方法

| **方法签名**                    | **描述**                                                     |
| ------------------------------- | ------------------------------------------------------------ |
| `reverse()`                     | 反转字符串内容，返回当前对象本身。                           |
| `setCharAt(int index, char ch)` | 将指定索引位置的字符设置为`ch`。                             |
| `setLength(int newLength)`      | 设置字符串长度。若`newLength`大于当前长度，尾部补`\0`；若小于，则截断字符串。 |

### 四、字符串查询方法

| **方法签名**                    | **描述**                                              |
| ------------------------------- | ----------------------------------------------------- |
| `charAt(int index)`             | 返回指定索引位置的字符。                              |
| `indexOf(String str)`           | 返回子字符串`str`第一次出现的索引，未找到返回 - 1。   |
| `lastIndexOf(String str)`       | 返回子字符串`str`最后一次出现的索引，未找到返回 - 1。 |
| `substring(int start)`          | 返回从`start`开始到末尾的子字符串（类型为`String`）。 |
| `substring(int start, int end)` | 返回从`start`到`end-1`的子字符串（类型为`String`）。  |
| `length()`                      | 返回当前字符串的长度（字符数）。                      |
| `capacity()`                    | 返回当前内部数组的容量。                              |

### 五、转换方法

| **方法签名**    | **描述**                              |
| --------------- | ------------------------------------- |
| `toString()`    | 将`StringBuilder`转换为`String`对象。 |
| `toCharArray()` | 将内容转换为字符数组`char[]`。        |

### 六、容量管理方法

| **方法签名**              | **描述**                                   |
| ------------------------- | ------------------------------------------ |
| `ensureCapacity(int min)` | 确保容量至少为`min`，不足则扩容。          |
| `trimToSize()`            | 将容量调整为当前字符串长度，减少内存占用。 |
