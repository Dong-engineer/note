# 创建变量并命名

以下是个人理解简短的说一下：

类名：Class关键字后所跟字段名就是类名，当你想要声明一个类名可以进行以下操作：

```java
public Class A {
	
}
```

A就是类名，通过类名我们可以声明变量，在Java官方文档中叫做实例变量 ，如下：

```java
public Class B {
	private A a;
}
```

以上代码需要一定面向对象的思维理解，以上代码我们可以理解为B类中声明了一个A类的且变量名叫做a的属性。

以下为官方介绍

Java 编程语言定义了以下类型的变量：

- **实例变量 （非静态字段）**从技术上讲，对象将其各个状态存储在 “非静态字段” 中，即在没有关键字声明的字段中。非静态字段也称为实例变量，因为它们的值对于类的每个实例（换句话说，对于每个对象）都是唯一的;一辆自行车的 独立于另一辆自行车。`static``currentSpeed``currentSpeed`
- **类变量 （静态字段）**类变量是使用修饰符声明的任何字段;这告诉编译器，无论该类已实例化多少次，都恰好存在此变量的一个副本。定义特定类型自行车的齿轮数的字段可以标记为，因为从概念上讲，相同的齿轮数将应用于所有实例。该代码将创建这样一个字段。此外，可以添加关键字以指示齿轮的数量永远不会改变。`static``static``static int numGears = 6;``static``final`
