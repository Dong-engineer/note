# 格式化输出

输出在前面的章节已经了解过，也就是`System.out.println()`或者`System.out.print()`。

Java 为了使开发者能更加灵活输出，除了上面提及的两种输出，在 `java.io`中有一个`PrintStream`，提供给开发者使用。

# `PrintStream`

`PrintStream`该类提供了两种输出方式，这些方法用于替换`print`和`println`，且这两种方式之间等效：

1. format()
2. printf()

二者的用法一模一样，底层实现原理也一样，所以不再分开讲述。

### 怎么使用

开发者平常使用的`System.out`就是`PrintStream`类的对象，所以直接通过`System.out`调用即可。

如下：

```java
String name = "Alice";
int age = 25;
double height = 1.65;

// 格式化输出字符串、整数和浮点数
System.out.printf("姓名：%s，年龄：%d，身高：%.2f米%n", name, age, height);

// 格式化日期
java.util.Date date = new java.util.Date();
System.out.printf("当前时间：%tF %tT%n", date, date);
```

### 占位符

在上面的代码中可以发现在一段文字当中有很多的`%`符号后面紧跟一个或做个字母，在 Java 官方的文档中这个叫做 converters(转换器)，也叫做占位符。

| 转换符 / 标志 | 说明                                                         |
| ------------- | ------------------------------------------------------------ |
| d             | 十进制整数。                                                 |
| f             | 浮点数。                                                     |
| n             | 适合运行应用程序的平台的换行符。你应该始终使用`%n`，而不是`\n`。 |
| tB            | 日期和时间转换 —— 特定于区域设置的月份全称。                 |
| td, te        | 日期和时间转换 —— 两位数的月份中的某一天。td 会根据需要添加前导零，te 不会。 |
| ty, tY        | 日期和时间转换 ——ty = 两位数的年份，tY = 四位数的年份。      |
| tl            | 日期和时间转换 ——12 小时制的小时数。                         |
| tM            | 日期和时间转换 —— 两位数的分钟数，必要时带前导零。           |
| tp            | 日期和时间转换 —— 特定于区域设置的上午 / 下午（小写）。      |
| tm            | 日期和时间转换 —— 两位数的月份，必要时带前导零。             |
| tD            | 日期和时间转换 —— 日期格式为`%tm%td%ty`。                    |

| 符号（配合上面的使用） | 说明                                          |
| ---------------------- | --------------------------------------------- |
| +                      | 包含符号，无论正负。                          |
| 08                     | 宽度为 8 个字符，必要时带前导零。             |
| ,                      | 包含特定于区域设置的分组字符。                |
| -                      | 左对齐。                                      |
| .3                     | 小数点后保留 3 位。                           |
| 10.3                   | 宽度为 10 个字符，右对齐，小数点后保留 3 位。 |

如下代码：

```java
long n = 461012;
System.out.format("%d%n", n);      //  -->  "461012"
System.out.format("%08d%n", n);    //  -->  "00461012"
System.out.format("%+8d%n", n);    //  -->  " +461012"
System.out.format("%,8d%n", n);    // -->  " 461,012"
System.out.format("%+,8d%n%n", n); //  -->  "+461,012"

double pi = Math.PI;

System.out.format("%f%n", pi);       // -->  "3.141593"
System.out.format("%.3f%n", pi);     // -->  "3.142"
System.out.format("%10.3f%n", pi);   // -->  "     3.142"
System.out.format("%-10.3f%n", pi);  // -->  "3.142"
System.out.format(Locale.FRANCE,
                  "%-10.4f%n%n", pi); // -->  "3,1416"

Calendar c = Calendar.getInstance();
System.out.format("%tB %te, %tY%n", c, c, c); // -->  "May 29, 2006"

System.out.format("%tl:%tM %tp%n", c, c, c);  // -->  "2:34 am"

System.out.format("%tD%n", c);    // -->  "05/29/06"
```

## DecimalFormat 类

可以使用 `java.text.DecimalFormat` 类来控制前导零和尾随零、前缀和后缀、分组（千位）分隔符和小数分隔符的显示。

这是一个能让你更加灵活控制数字输出格式的类，但同样的他会减少代码的可读性。

```java
import java.text.*;

public class DecimalFormatDemo {

   static public void customFormat(String pattern, double value ) {
      DecimalFormat myFormatter = new DecimalFormat(pattern);
      String output = myFormatter.format(value);
      System.out.println(value + "  " + pattern + "  " + output);
   }

   static public void main(String[] args) {

      customFormat("###,###.###", 123456.789);
      customFormat("###.##", 123456.789);
      customFormat("000000.000", 123.78);
      customFormat("$###,###.###", 12345.67);  
   }
}

```
