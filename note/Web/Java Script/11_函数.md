# 函数

在 `JavaScript` 中，开发者想要声明一个函数可以使用关键字 `function`，示例如下：

```js
// 这段代码表示，声明了一个名为 sum 的函数，接收两个参数，一个 one，一个 two
// 返回结果为 one + two
function sum(one, two) {
    return one + two
}
```

## 函数定义方式

### 函数声明

使用 `function` + 函数名 进行定义，可以在声明代码之前调用。

```js
function sum(one, two) {
    return one + two
}
```

### 函数表达式

将函数赋值给变量，分为匿名函数表达式、具名函数表达式。**必须先定义再调用**。

```js
// 匿名函数表达式
const sum = function(one, two) {
    return one + two
}

// 具名函数表达式，函数内部可以通过名称自引用，便于调试堆栈
const sum = function fn(one, two) {
    return one + two
}
```

### Function 构造函数（不建议学习）

运行时通过字符串动态创建函数，性能较差，存在安全隐患，日常开发不推荐使用。

```js
const sum = new Function('one', 'two', 'return one + two')
```

## 值传递

在高级编程语言中，函数接收参数的方式有两种，一种为值传递，一种为引用传递。 **JavaScript 中所有参数传递全部为值传递，不存在引用传递。**

- 基本类型（字符串、数字、布尔、`null`、`undefined`、`BigInt`、`Symbol`）：传递变量值的副本。函数内部修改形参，不会影响外部原始变量。
- 引用类型（对象、数组、函数）：变量存储的是堆内存地址。传参时复制**地址副本**。
  - 通过地址修改对象内部属性、数组元素，外部可以观察到变更；
  - 直接对形参重新赋值新对象 / 数组，只会修改副本地址，外部变量不受影响。

```js
function modify(obj) {
  obj.name = "新名字";       // 修改内部属性，外部生效
  obj = { name: "新对象" };  // 形参重新赋值，外部无效
}
const user = { name: "原始名字" };
modify(user);
console.log(user.name); // 新名字
```

## 调用函数

函数定义仅保存代码逻辑，**只有调用时代码才会执行**。 基础调用语法：`函数名(实参)`；定义时声明的变量为形参，调用时传入的数据为实参。

```js
sum(1, 2)
```

## 函数作用域

作用域控制变量的可访问范围。

1. 在函数内部声明的变量属于**局部变量**，仅函数内部可以访问；
2. 全局作用域中的变量，在任意函数内都可以访问；
3. 函数支持嵌套定义，内层函数可以访问外层函数变量；外层函数无法访问内层函数变量；
4. 多层嵌套形成**作用域链**；当内外存在同名变量时，内层变量优先生效，屏蔽外层同名变量。

```js
function outer() {
  const msg = "外层变量";
  function inner() {
    console.log(msg); // 可以访问外层变量
  }
  inner();
}
```

## 闭包

当一个嵌套内部函数，依然可以访问外层函数作用域变量，即便外层函数执行完毕，该环境依然保留，这种组合称为闭包。

闭包核心特点：

1. 内部函数保留外层函数的作用环境；
2. 每次执行外层函数，都会生成独立的闭包环境，各组变量互不干扰；
3. 只要闭包持续被外部引用，外层作用域变量不会被垃圾回收，滥用容易引发内存占用问题。

```js
function makeCounter() {
  let count = 0;
  // 返回内部函数，形成闭包
  return function() {
    count++;
    return count;
  }
}
const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

## 函数的 arguments 对象

在普通函数内部，存在一个类数组对象 `arguments`，保存调用时传入的所有实参。

- 通过 `arguments[索引]` 获取对应参数；`arguments.length` 获取传入参数数量；
- `arguments` 只是类数组，不具备数组所有原生方法；
- **箭头函数不存在 arguments 对象**。

```js
function test() {
  console.log(arguments[0]);
  console.log(arguments.length);
}
test(10, 20, 30);
```

```js
function test(...rest) {
  console.log(rest); // 数组
}
```

### 补充

**默认参数**：形参可以设置默认值，仅当传入 `undefined` 时默认值生效，`null`、0 等不会触发默认值。

```js
function multiply(a, b = 1) {
  return a * b;
}
```

## 箭头函数

语法：`() => {}`

```js
// 单个参数，可省略括号
const square = n => n * n;
// 多参数 / 无参数，必须书写括号
const add = (a, b) => a + b;
// 多行代码需要大括号，并且手动书写 return
const calc = (a, b) => {
  const res = a + b;
  return res;
};
```

### 箭头函数关键特性

1. 不绑定独立 `this`，会继承外层作用域的 `this`；
2. 没有 `arguments`、`super`、`new.target`；
3. 不能作为构造函数，禁止使用 `new` 调用；
4. 没有原型 `prototype`；

适用场景：回调函数、简短工具函数。 不适合：对象方法、需要使用 `this` 的构造函数。

#### 无单独的 this

```js
// 不绑定独立this，继承外层作用域this
const person = {
  name: "小明",
  sayNormal: function () {
    // 普通函数：this指向person
    setTimeout(function () {
      console.log(this.name); // undefined，this指向window(非严格模式)
    }, 100);

    // 箭头函数：继承外层sayNormal的this（person）
    setTimeout(() => {
      console.log(this.name); // 小明
    }, 100);
  }
};
person.sayNormal();
```

#### 不存在 argments

```js
// 箭头函数不存在 arguments
const normalFn = function () {
  console.log(arguments); // [10,20] 有效
};
normalFn(10, 20);

const arrowFn = () => {
  // console.log(arguments); // 报错：arguments未定义
};
arrowFn(10, 20);

// 箭头函数获取参数请使用剩余参数 ...rest，不一定是 rest，也可以是 ...args，必须有 ...
const arrowRest = (...rest) => {
  console.log(rest); // [10,20]
};
arrowRest(10, 20);
```

#### 不能使用 new 当做构造函数

```js
// 不能使用 new 当做构造函数
const Animal = () => {};
// const cat = new Animal();
// Uncaught TypeError: Animal is not a constructor
```

#### 没有 prototype

```js
// 箭头函数没有 prototype
function NormalFunc() {}
console.log(NormalFunc.prototype); // {constructor: ƒ}

const ArrowFunc = () => {};
console.log(ArrowFunc.prototype); // undefined
```
