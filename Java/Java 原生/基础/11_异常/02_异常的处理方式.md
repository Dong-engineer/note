# 异常处理的方式

上节学习了异常，遇到了异常肯定是要解决的，但是开发者不可能完美得到预想到未来整个系统会报什么样的错误，且具体的错误是什么样的，于是 Java 提供了 `try...catch` 来进行捕获异常。

## `try..catch`

### 单个catch块

```java
try {
    // 可能抛出异常的代码
} catch (ExceptionType e) {
    // 处理异常
}
```

### 多个catch块

```java
try {

} catch (ExceptionType name) {

} catch (ExceptionType name) {

}
```

在有多个catch块的情况下，每一个catch块都是一个捕获异常的一个程序。

但是**这种情况下不允许父类和子类同时出现**，如下：

```java
try {

} catch (IOException ioe) {
    
} catch (FileNotFoundException fnfe) {
    
}
```

`IOException` 是 `FileNotFoundException` 的父类型，因此第二个 catch 无法捕获异常。

### 单个catch块捕获多个异常

```java
catch (IOException | SQLException ex) {

}
```

异常类型之间用 `|` 分隔开即可。

## 为什么捕获异常

在程序的运行中，如果不去预测异常可能会发生在哪里，或者更干脆一点不去捕获异常，那么程序会因异常的向上抛出，直至栈顶 `main()` 方法，整个程序的运行会因此终止崩溃。

所以 Java 是倡导程序员去预想异常可能发生的位置，使用 `try{}` 代码块尝试，再使用 `catch(可能发生异常的类型 异常变量){}` 代码块去捕获。
