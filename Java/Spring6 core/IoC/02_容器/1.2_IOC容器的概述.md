# 1.2 IOC 容器概述

`org.springframework.context.ApplicationContext` 接口代表 Spring IoC 容器，负责实例化、配置和组装 Bean。容器通过读取配置元数据来获得关于要实例化、配置和组装哪些对象的指示。配置元数据以 XML、Java 注解或 Java 代码表示。它可以让你表达构成你的应用程序的对象以及这些对象之间丰富的相互依赖关系。

Spring提供了几个接口实现类，如下：（常用的两个）

`ClassPathXmlApplicationContext`、`FileSystemXmlApplicationContext`

XML 一直是配置元数据的传统格式，但你可以通过提供少量的 XML 配置来指示容器使用 Java 注解或代码作为元数据格式，以声明性地启用对这些额外元数据格式的支持。以后会有代码解释。

## 元数据 —— 工厂加工所需的模具

元数据，即 XML 配置文件、注解的数据等等统称为元数据，Spring 就是根据这些模具来进行加工对象的。

## Spring —— 一座巨型工厂

Spring 就是一座巨型工厂，开发者只需要通过配置文件定义好所需对象的数据模板即可，该对象是如何创建具体细节，开发者无需关心。

## IoC 容器 —— 工厂的仓库

开发者要想获取对象，那么开发者必须要先初始化 IoC 容器，这个容器初始化时，其里面存储的对象（后面称作做 Bean ）同样也会被初始化并被存放至该仓库中。

Spring 提供了接口和函数（如：`getBean()`），允许开发者通过这些接口和函数从仓库中拿取其已经加工好的 Bean 对象。
