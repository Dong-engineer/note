# 类型推断

类型推断是 Java 编译器查看每个方法调用和相应声明以确定使调用适用的类型参数（或参数）的能力。推理算法确定参数的类型，以及分配或返回结果的类型（如果可用）。

仔细阅读上节内容其实对类型推理多少有点理解了。即编译器根据代码上下文对泛型进行推断，从而得知后续泛型所接收的类型是什么。

```java
public static void main(String[] args) {
    GenericMethodExample example = new GenericMethodExample();
    String[] strArray = {"Java", "Python"};
    example.printArray(strArray);
}
```

这里就是根据上文创建了一个 `String` 类型的数组，在下文就无需再显示声明泛型了。

在创建对象时也是如此：

```java
public static void main(String[] args) {
    
    MyClass<Integer> myClass = new MyClass<>();
    myClass.add(1);
    myClass.add(2);
    
    int i = myClass.get(1);
    int a = myClass.get(2);

}
```

在上一节中使用的是 `MyClass<Integer> myClass = new MyClass<Integer>();` 显示声明了泛型类型，但有了类型推断就无需在对其进行显示声明。

但是 Java 不允许 `MyClass<Integer> myClass = new MyClass();`  这样做，这样做是对泛型类型的引用创建了原始数据类型，这里会发生警告，在运行时很有可能发生类型转换错误。
