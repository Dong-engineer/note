# 详细了解类

## 方法返回值

前面已经学习方法（也就是函数）返回值，在方法的末尾使用 `return` 返回某一数据类型的值。

```java
public int totalDistance(int time) {
    // 返回 速度 * 时间
    reutrn this.getSpeed() * time + "km";   
}
```

**但是，方法返回的是一个具体类型的值，在实际开发中，一定要记住始终面向抽象编程，所以实际开发的时候需要返回一个抽象类或者接口（不用在意什么是接口，面向抽象编程，后面会学到的，但请学习者记住），在开发时我们称作 *协变返回数据类型* **

这里先做了解，因为类的继承暂时没学到，看不懂可以先跳过。如下：

```java
public class CovariantReturnTypeExample {
    public static void main(String[] args) {
        // 创建父类和子类对象
        Shape parentShape = new Shape();
        Circle childCircle = new Circle();
        
        // 调用方法并获取结果
        Shape parentResult = parentShape.create(); // 返回Shape类型
        Circle childResult = childCircle.create(); // 返回Circle类型
        
        // 输出结果
        System.out.println("Parent result type: " + parentResult.getClass().getName());
        System.out.println("Child result type: " + childResult.getClass().getName());
    }
}

// 基类 Shape
class Shape {
    // 基类方法返回Shape类型
    public Shape create() {
        System.out.println("Creating a Shape...");
        return new Shape();
    }
}

// 子类 Circle 继承自 Shape
class Circle extends Shape {
    // 重写方法，返回类型为Circle（Shape的子类）
    @Override
    public Circle create() {
        System.out.println("Creating a Circle...");
        return new Circle();
    }
}
```

## 类的访问控制

前面对访问控制有一点讲解，如：`private`，前面在创建类的时候，刚开始用的时`public`，后来希望其他成员（比如：某一个类对象），不能直接访问 `Bicycle` 类的成员变量，所以后面给他定义成了 `private`。

除了`private、public`，还有 `protected`，这三个关键字不仅仅控制类的成员变量的访问，还控制类本身以及其方法、等等的访问。具体这三个访问修饰符区别如下：

| 访问修饰符  | 同一个类 | 同一个包的子类 | 同一个包的非子类 | 不同包的子类 | 不同包的非子类 |
| :---------- | :------- | -------------- | ---------------- | ------------ | -------------- |
| `public`    | ✅        | ✅              | ✅                | ✅            | ✅              |
| `protected` | ✅        | ✅              | ✅                | ✅            | ❌              |
| 默认        | ✅        | ✅              | ✅                | ❌            | ❌              |
| `private`   | ✅        | ❌              | ❌                | ❌            | ❌              |

### 说明：

1. **`public`**：所有类都可以访问
2. `protected`：
   - 同一个包内的类可以访问
   - 不同包的子类可以通过继承访问（需通过子类对象调用）
   - \* 注：不同包的子类只能通过自身实例访问，无法通过父类实例访问
3. 默认（无修饰符）：
   - 只能被同一个包内的类访问
   - 也称为包访问权限
4. `private`：
   - 只能被当前类内部访问
   - 对其他任何类都是不可见的

### 示列代码

```java
package com.example.base;

public class BaseClass {
    public int publicField;
    protected int protectedField;
    int defaultField;      // 默认访问修饰符
    private int privateField;
    
    public void publicMethod() {}
    protected void protectedMethod() {}
    void defaultMethod() {}  // 默认访问修饰符
    private void privateMethod() {}
}
```

```java
package com.example.same; // 同一个包

public class SamePackageClass {
    public void access(BaseClass obj) {
        obj.publicField = 1;      // 允许
        obj.protectedField = 2;   // 允许
        obj.defaultField = 3;     // 允许
        // obj.privateField = 4;   // 错误：无法访问
    }
}
```

```java
package com.example.diff; // 不同包

public class SubClass extends BaseClass {
    public void access() {
        publicField = 1;        // 允许
        protectedField = 2;     // 允许
        // defaultField = 3;     // 错误：无法访问不同包中的默认成员
        // privateField = 4;     // 错误：无法访问
    }
}
```

### 为什么需要这些访问修饰符？

这些可以说是编程思维，慢慢学，不懂正常，先了解。

- **封装性**：隐藏内部实现细节，只暴露必要接口。
- **安全性**：防止外部随意修改敏感数据（如 `private` 字段）。
- **可维护性**：明确访问边界，降低代码耦合度。
