# 注解

本节讲述注解是什么，其语法什么样，底层原理怎么做的，为什么使用注解。

## 什么是注解

Java 注解是 JDK 5.0 引入的一种元数据形式，它为代码提供了一种附加的、结构化的、且与业务逻辑分离的信息表达方式。注解本质是一种特殊的接口，其底层实现基于 Java 反射机制。

**语法**：`@ + 表示字符串`

如：`@Override`

## 注解原理

从底层来看，Java 注解是通过以下方式实现的：

1. **注解接口的定义**：注解在编译后会被转换为继承自`java.lang.annotation.Annotation`的接口。
2. **编译时处理**：编译器会在编译时将注解信息写入 class 文件的常量池和属性表中。
3. **运行时反射**：通过反射 API（如`Class.getAnnotations()`），可以在运行时获取注解信息。
4. **AnnotationInvocationHandler**： JVM 在运行时会为注解创建一个动态代理实例，通过这个代理类来处理注解的访问逻辑。

代码如下：

```java
import java.lang.annotation.*;
import java.lang.reflect.*;

// 1. 定义注解接口（后面会讲述），这里先知道这是定义了一个名为 MyAnnotation 的注解
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@interface MyAnnotation {
    String value() default "default";
    int priority() default 1;
}

// 2. 使用注解
class MyClass {
    
    @MyAnnotation(value = "Hello", priority = 100)
    public void annotatedMethod() {
        
    }
    
}

public class AnnotationPrincipleDemo {
    public static void main(String[] args) throws Exception {
        // 3. 通过反射获取注解信息
        // Method是反射中的，暂时没学
        // 这里先知道获取了其指定方法名的 Method 类型的对象
        Method method = MyClass.class.getMethod("annotatedMethod");
        // 获取注解的实例对象
        MyAnnotation annotation = method.getAnnotation(MyAnnotation.class);
        
        // 输出注解属性值
        System.out.println("反射读取注解:");
        System.out.println("value: " + annotation.value());
        System.out.println("priority: " + annotation.priority());
        
        // 4. 模拟JDK动态代理实现注解
        System.out.println("\n模拟注解代理实现:");
        InvocationHandler handler = new AnnotationInvocationHandler(
            MyAnnotation.class,
            new Object[]{
                "Proxy Value",  // 对应value属性
                200             // 对应priority属性
            }
        );
        
        MyAnnotation proxyAnnotation = (MyAnnotation) Proxy.newProxyInstance(
            MyAnnotation.class.getClassLoader(),
            new Class<?>[]{MyAnnotation.class},
            handler
        );
        
        System.out.println("代理注解 value: " + proxyAnnotation.value());
        System.out.println("代理注解 priority: " + proxyAnnotation.priority());
    }
}

// 5. 模拟JDK内部的AnnotationInvocationHandler
class AnnotationInvocationHandler implements InvocationHandler {
    private final Class<? extends Annotation> annotationType;
    private final Object[] attributeValues;
    
    public AnnotationInvocationHandler(Class<? extends Annotation> annotationType, Object[] attributeValues) {
        this.annotationType = annotationType;
        this.attributeValues = attributeValues;
    }
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        // 处理注解方法调用
        String methodName = method.getName();
        
        // 模拟注解的hashCode()、equals()和toString()方法
        if (methodName.equals("hashCode")) {
            return 0; // 简化实现
        } else if (methodName.equals("equals")) {
            return args[0] instanceof MyAnnotation;
        } else if (methodName.equals("toString")) {
            return "@" + annotationType.getName() + "(value=" + attributeValues[0] + ")";
        }
        
        // 返回注解属性值
        for (Method m : annotationType.getDeclaredMethods()) {
            if (m.getName().equals(methodName)) {
                int index = getMethodIndex(m);
                return attributeValues[index];
            }
        }
        
        throw new UnsupportedOperationException("Method not found: " + methodName);
    }
    
    private int getMethodIndex(Method method) {
        // 实际实现中需要根据方法名称和参数类型确定索引
        return method.getName().equals("value") ? 0 : 1;
    }
}
```

以上代码很多核心接口没有讲述到，因为那是反射的内容，在后续会讲解，注解是基于反射的机制来实现的。

## 为什么使用注解

使用注解的主要优势包括：

1. **减少样板代码**：如通过`@Override`自动检查方法重写。
2. **提高代码可读性**：声明式地表达代码意图（如`@Deprecated`）。
3. **实现编译时检查**：通过自定义注解和编译期处理器实现静态代码分析。
4. **简化配置管理**：替代 XML 或 properties 配置文件（如 Spring 框架的`@Component`）。
5. **自动化测试和部署**：JUnit 的`@Test`和 Maven 的`@Plugin`注解。
