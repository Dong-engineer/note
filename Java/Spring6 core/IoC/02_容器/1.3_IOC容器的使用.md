# 1.3容器的使用

本文内容讲述配置元数据的方式基于XML文件来进行的。

## 1.3.1 配置元数据

元数据：即作为开发者告诉 Spring IOC 容器在应用中实例化、配置和组装对象的数据。

上面说过，XML是传统的配置元数据的方式。但基于XML的元数据并不是配置元数据的唯一允许形式。Spring IoC容器本身与这种配置元数据的实际编写格式是完全解耦的。如今，许多开发者为他们的Spring应用程序选择 `基于Java的配置`。

首先创建一个类，如下：

```java
package com.Dong.FirstSpring;

public class User {
    /**
    * 无参构造方法
    **/
    public User(){
        System.out.println("无参数构造函数执行成功！");
    }
    
    /**
    * 打印输出I am a User
    **/
    public void outPut() {
        System.out.println("I am a User");
    }
    
}
```

然后，在Spring工程中的resources文件下创建bean.xml文件来配置元数据。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">

    <!--
    bean标签：完成类的创建
    属性：id ——> 唯一标识、class ——> 要创建对象的类的文件路径(包名+类名)
    -->
    <bean id="user" class="com.Dong.FirstSpring.User"> </bean>
</beans>
```

最后，创建测试类。

这里整体分三步：

1. 实例化容器
2. 创建Bean对象
3. 测试对象方法

```java
package com.Dong.FirstSpring;

import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

public class TestUser {
    public static void main(String[] args) {
		// 加载spring配置文件 —> 对xml文件进行解析操作 ——> 获取xml文件中的标签和属性值
		// 这里声明了一个ApplicationContext类，但是new的是ClassPathXmlApplicationContext对象，高内聚，低耦合
        /*
        *   这里会使用反射创建一个User对象，默认调用其无参构造方法
        *   如下：
        *   Class clazz = Class.forName("com.spring_haha.User");
        *   Object obj = clazz.newInstance();   //这里 newInstance()的用法忘了去百度,且该方法是过时的方法，被抛弃，下面会讲述新的方法
        *
        *   新的方式：
        *   User user = (User)clazz.getDeclaredConstructor().newInstance();
        *
        *   创建好的对象最终会储存到DefaultListableBeanFactory类下的一个Map集合容器里 ——> beanDefinitionMap
        *   Map特点是键值对，Map<String,BeanDefinition>，而我们在xml文件中声明的id
        * */
        ApplicationContext context =
                new ClassPathXmlApplicationContext("bean.xml");
        System.out.println("--------");
		// 使用getBean()来获取所创建的对象，根据id来创建
		// 这里获取对象默认是Object类型的，需要强转
        User user = (User)context.getBean("user");
        
        //测试，调用user的方法
        System.out.println(user);
        user.outPut();
        System.out.println("成功！！！");
    }
}

```

## 1.3.2 关于有无参数构造方法配置元数据

1.2.1里面知道如何配置元数据，接下来了解如何配置含有构造方法类的元数据。

首先，创建Person类。

```java
package com.Dong.SpringIOC;

public class Person{
    private String name;
    private int age;

    public Person() {
        System.out.println("1 ——>无参调用成功...");
    }
    public Person(String name,int age) {
        System.out.println("1 ——>有参调用成功...");
        this.name=name;
        this.age=age;
    }

    /**
     * @Description 初始化方法
     * @Param [none]
     **/
    public void initMethod() {
        System.out.println("4 ——>bean对象的初始化，调用指定的初始化方法");
    }
    /**
     * @Description 销毁方法 destroy 析构;毁灭
     * @Param []
     **/
    public void destroyMethod() {
        System.out.println("7 ——>bean对象的销毁");
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        System.out.println("2 ——>给属性设置值");
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }

    public void Run() {
        System.out.println("Run...Run...Run...Run...Run...！！！");
    }

    @Override
    public String toString() {
        return this.getName()
                + ":"
                +"{name:" + name
                + ", "
                +"age:" + age
                + "}";
    }
}

```

然后，配置XML文件。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
    
    <!--person类型-->
    <bean id="person" class="com.Dong.SpringIOC.Person"> </bean>

    <!--注：这里之前说过会调用bean标签对应的类的无参构造方法-->
    <bean id="person1" class="com.Dong.SpringIOC.Person">
        <!--这里会调用属性的setter方法，如果属性没有setter方法会报错-->
        <property name="name" value="Dong"> </property>
        <property name="age" value="20"> </property>
    </bean>

    <!--构造器注入-->
    <bean id="person2" class="com.Dong.SpringIOC.Person">
        <!--这里使用了constructor-arg标签，表示调用了Person的有参构造方法-->
        <constructor-arg name="name" value="DDong"> </constructor-arg>
        <constructor-arg name="age" value="18"> </constructor-arg>
    </bean>
</beans>
```

最后，创建测试类。

```java
package com.Dong.SpringIOC;

import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

//测试通过IoC容器以不同的方式进行创建对象
public class TestPerson_01 {
    public static void main(String[] args) {
        ApplicationContext context = new
                ClassPathXmlApplicationContext("ioc_00.xml");
        //根据bean标签的Id来创建
        Person person=(Person) context.getBean("person");
        System.out.println("根据bean标签的Id来创建：");
        person.Run();
        System.out.println("--------------------------------");
        //根据类型来创建
        System.out.println("根据类型来创建：");
        Person person1=context.getBean(Person.class);
        person1.Run();
        System.out.println("--------------------------------");
        //根据Id和类型创建
        System.out.println("根据Id和类型创建：");
        Person person2=context.getBean("person",Person.class);
        person2.Run();
    }
}

```

## 1.3.3 关于非简单数据类型的配置

这里不在测试，直接用XML看如何配置非简单数据类型。

简单类型里面包含了八大基本数据类型，但是在 Spring 源码中判断了什么是简单数据类型，后面再Bean的章节中详细介绍。

我们以部门和员工为例：

假设我们有两个类：一个Department类，一个Employee类。

Employee类中含有一个属性是Department类的。

Department类中含有Employee类的集合（在数据结构里面叫做列表）。

### Array

```xml
<array id="name_arr">
    <value>tom</value>
    <value>jerry</value>
</array>
```



### List

```xml
<!-- Employee_bean -->
<bean id="employee" class="com.Dong.SpringIOC.Employee">
    <property name="name" value="路飞"> </property>
    <property name="age" value="21"> </property>
    <property name="department" ref="department"> </property>
</bean>

<bean id="employee1" class="com.Dong.SpringIOC.Employee">
    <property name="name" value="索隆"> </property>
    <property name="age" value="22"> </property>
    <property name="department" ref="department"> </property>
</bean>

<!-- Department_bean -->
<bean id="department" class="com.Dong.SpringIOC.Department">
    <property name="name" value="卫生部"> </property>
    <property name="employee">
        <list>
            <ref bean="employee"></ref>
            <ref bean="employee1"></ref>
        </list>
    </property>
</bean>
```

上面应注意：<ref/>标签的使用，和<list></list>是如何使用的。

### 外部创建List集合和Map集合

```xml
<!--外部集合-->
<!--教师集合-->
<util:map id="map">
    <entry value-ref="teacher1" key="0001"/>
    <entry value-ref="teacher2" key="0002"/>
</util:map>

<!--课程集合-->
<util:list id="list">
    <ref bean="lesson1"/>
    <ref bean="lesson2"/>

<!--课程类-->
<bean id="lesson1" class="com.Dong.SpringIOC.StudentSystem.Lesson">
    <property name="lname" value="计算机科学"> </property>

    <property name="lname" value="高数导论"> </property>
    <property name="teacherMap" ref="map"> </property>
</bean>

<!--教师类-->
<bean id="teacher1" class="com.Dong.SpringIOC.StudentSystem.Teacher">
    <property name="tid" value="0001"> </property>
    <property name="tname" value="西瓜老师"> </property>

<bean id="teacher2" class="com.Dong.SpringIOC.StudentSystem.Teacher">
    <property name="tid" value="0002"> </property>

```

## 1.3.4 跨越多个XML文件

让Bean的定义跨越多个XML文件可能很有用。通常情况下，每个单独的XML配置文件代表了你架构中的一个逻辑层或模块。

使用一个或多个 `<import/>` 元素的出现来从另一个或多个文件中加载Bean定义。

```xml
<beans>
    <import resource="services.xml"/>
    <import resource="resources/messageSource.xml"/>
    <import resource="/resources/themeSource.xml"/>

    <bean id="bean1" class="..."/>
    <bean id="bean2" class="..."/>
</beans>
```
