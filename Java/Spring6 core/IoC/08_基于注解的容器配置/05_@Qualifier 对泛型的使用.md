# @Qualifier 对泛型的使用

@Qualifier 对泛型的使用，开发者经过上一节的学习多少对其已经有了解，本节还是会再明确说明一下的，还会补充一些新的内容。

在上节并没有讲述 @Qualifier 对数组、集合等容器类型的自动注入，因为他们的注入逻辑是和泛型一样的。

## @Qualifier 对泛型的自动注入

**开发者看到这里应该并没有忘记 `@Qualifier` 是一个过滤器，如果对泛型或者数组、集合进行使用，Spring 会将 Bean 的限定符匹配成功的 Bean 进行类型筛选，然后将其注入进去**。

### 注入原理

注入原理和 `@Primary` 大部分是一样的。

无参数化类型泛型会因 Java 的泛型擦除机制，从而导致 Spring 注入的 Bean 是 `Object` 类型。

有参数化类型泛型，Spring 为解决擦除机制问题带来的问题，Spring 提供了类型保留机制，Spring 会保留参数化类型的类，然后对过滤后的 Bean 进行类型筛选，匹配成功的 Bean 会进行自动注入。

## 泛型和自动注入的搭配使用

`@Qulifier` 是一个过滤器，但是经过大量对 Java 的学习了解，泛型又何尝不是一种过滤呢？而且泛型还避免了类型转换错误（当然前提是开发者没有绕过编译检查）。

所以 Spring 在文档中说到，当开发者需要使用自动注入（`@Autowired`）时，也可搭配泛型使用从而达到过滤 Bean 的目的。
